Finestra [Impostazioni IPv6]

Impostare un indirizzo IPv6.
Configurazione IPv6

Selezionare un metodo per impostare un indirizzo IPv6 per uno scanner.

  • Automatico

    Un indirizzo IP viene assegnato automaticamente a uno scanner dal server DHCP.

    Questa è l'impostazione predefinita di fabbrica.

  • Manuale

    Assegnare un indirizzo IP manualmente.

  • Disabilita

    Disabilitare le impostazioni dell'indirizzo IPv6.

Casella di spunta [Ricevi pacchetto RA]

Questa casella di spunta viene visualizzata quando si seleziona [Manuale] in [Configurazione IPv6].

Selezionare la casella per abilitare un indirizzo IPv6 che è stato generato automaticamente.

È possibile selezionare un indirizzo IPv6 che è stato generato automaticamente in [Indirizzo IP] in [IPv6] nella finestra [Programma di impostazione dell'indirizzo IP].

La casella di spunta è selezionata come impostazione predefinita di fabbrica.

Indirizzo IP

Inserire un indirizzo IP per uno scanner quando si seleziona [Manuale] in [Configurazione IPv6].

Lunghezza prefisso di sottorete

Inserire una lunghezza prefisso di sottorete per l'indirizzo IP quando si seleziona [Manuale] in [Configurazione IPv6].

È possibile inserire un valore compreso tra 3 e 128.

Gateway predefinito

Inserire un gateway predefinito per l'indirizzo IP quando si seleziona [Manuale] in [Configurazione IPv6].

Tasto [OK]

Chiude la finestra.

Le modifiche sono applicate alla finestra [Programma di impostazione dell'indirizzo IP].

Tasto [Annulla]

Chiude la finestra.

Le modifiche non sono applicate alla finestra [Programma di impostazione dell'indirizzo IP].
