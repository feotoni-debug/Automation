Modifica dell'indirizzo IP per uno scanner

Questa sezione descrive come usare il Programma di impostazione dell'indirizzo IP per modificare l'indirizzo IP per uno scanner.

L'indirizzo IP è visualizzato nell'elenco scanner nella finestra [Programma di selezione dello scanner].

L'indirizzo IPv4 o l'indirizzo IPv6 viene assegnato automaticamente a uno scanner come impostazione predefinita di fabbrica.

Ad esempio, usare il Programma di impostazione dell'indirizzo IP per modificare l'indirizzo IP di uno scanner nei casi seguenti.

  • Quando non si trova uno scanner nel Programma di selezione dello scanner

  • Quando si collega uno scanner a una rete che non utilizza un server DHCP

  • Per impostare un indirizzo IP fisso per uno scanner

  1. Collegare uno scanner a un computer con il cavo USB in dotazione con lo scanner.
  2. Accendere lo scanner.

    Per dettagli, consultare la Guida dell'operatore dello scanner.

  3. Avviare il Programma di impostazione dell'indirizzo IP.

    Per dettagli, consultare Avvio del Programma di impostazione dell'indirizzo IP.

    Si visualizza la finestra di accesso del Programma di impostazione dell'indirizzo IP.

    Quando non è impostata una password amministratore per lo scanner, si visualizza Finestra [Programma di impostazione dell'indirizzo IP]. Passare al punto 5.

  4. Inserire la password amministratore per uno scanner e cliccare il tasto [Accesso].

    Per dettagli sulla password amministratore predefinita di fabbrica, consultare la Guida dell'operatore dello scanner.

    Si visualizza Finestra [Programma di impostazione dell'indirizzo IP].

  5. Selezionare un metodo per impostare un indirizzo IP.

    • Indirizzo IPv4

      Selezionare un metodo per impostare un indirizzo IP per uno scanner in [Configurazione IPv4] in [Rete].

      • Quando si seleziona [Automatico]

        Passare al punto 6.

      • Quando si seleziona [Manuale]

        Inserire i numeri appropriati in [Indirizzo IP], [Maschera di sottorete] e [Gateway predefinito].

    • Indirizzo IPv6

      1. Cliccare il tasto [Impostazioni IPv6] in [IPv6] in [Rete].

      2. Selezionare un metodo per impostare un indirizzo IP per uno scanner in [Configurazione IPv6] in Finestra [Impostazioni IPv6].

        • Quando si seleziona [Automatico] o [Disabilita]

          Cliccare il tasto [OK] e passare al punto 6.

        • Quando si seleziona [Manuale]

          Inserire i numeri appropriati in [Indirizzo IP], [Lunghezza prefisso di sottorete] e [Gateway predefinito].

      3. Cliccare il tasto [OK].

  6. Cliccare il tasto [OK].
  7. Scollegare il cavo USB dallo scanner.
