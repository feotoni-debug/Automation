Avvio del Programma di selezione dello scanner

Questa sezione descrive come avviare il Programma di selezione dello scanner.

Procedura di avvio

  • Per Windows 10/Windows Server 2016/Windows Server 2019/Windows Server 2022

    Selezionare il menu [Start] → [fi Series] → [Programma di selezione dello scanner for fi Series].

  • Per Windows 11/Windows Server 2025

    Selezionare il menu [Start] → [Tutte le App] → [fi Series] → [Programma di selezione dello scanner for fi Series].

CONSIGLIO

È anche possibile avviare il Programma di selezione dello scanner cliccando il tasto [Selezioni uno scanner] nella finestra [Programma di impostazione dell'indirizzo IP].
