Impossibile eseguire una scansione premendo il tasto di scansione sullo scanner

Controllare quanto segue:

  • Lo scanner è selezionato nel Programma di selezione dello scanner?

  • Button Event Manager è stato avviato?

  • [Guarda evento pulsante] è selezionato nel menu di Button Event Manager?

  • Le impostazioni per il tasto sullo scanner sono corrette?

  • Lo scanner è in uso da un altro computer?

Lo scanner è selezionato nel Programma di selezione dello scanner?

Soluzione

In Finestra [Programma di selezione dello scanner], controllare che lo scanner sia selezionato.

Button Event Manager è stato avviato?

Soluzione

Controllare che Button Event Manager sia stato avviato.

Quando Button Event Manager è stato avviato, si visualizza nell'area di notifica all'estrema destra della barra delle attività.

Per dettagli su come avviare Button Event Manager, consultare Avvio di Button Event Manager.

[Guarda evento pulsante] è selezionato nel menu di Button Event Manager?

Soluzione

Avviare Button Event Manager e fare clic destro su nell'area di notifica all'estrema destra della barra delle attività per visualizzare Menu di Button Event Manager. Controllare che [Guarda evento pulsante] sia selezionato.

Per dettagli su come avviare Button Event Manager, consultare Avvio di Button Event Manager.

Le impostazioni per il tasto sullo scanner sono corrette?

Soluzione

  • In Finestra [Impostazioni dei tasti] di Button Event Manager, controllare che l'impostazione dei tasti sia corretta.

  • Controllare che l'applicazione di scansione delle immagini specificata per il tasto sullo scanner sia in esecuzione sul computer.

Lo scanner è in uso da un altro computer?

Soluzione

Quando lo stesso scanner è stato selezionato da più computer utilizzando il Programma di selezione dello scanner, selezionare [Guarda evento pulsante] sul menu di Button Event Manager solo sul computer dal quale si intende utilizzare lo scanner.

Se non è possibile avviare una scansione dopo aver eseguito le azioni sopra, procedere come segue:

  • Uscire dall'applicazione di scansione delle immagini che risiede nell'area di notifica all'estrema destra della barra delle attività

  • Spegnere e riaccendere lo scanner
