È stato impostato un server proxy per l'impostazione proxy WinHTTP?

Soluzione

Modificare le impostazioni proxy WinHTTP in modo da poter accedere allo scanner dal computer.

Modificare le impostazioni proxy WinHTTP con la procedura seguente.

  1. Avviare la finestra del prompt dei comandi come utente con privilegi di amministratore su un computer.

  2. Eseguire il comando seguente per controllare il nome del server proxy e i numeri di porta da usare.

    netsh winhttp show proxy

    CONSIGLIO

    Il nome del server proxy e i numeri di porta da usare saranno visualizzati come segue.

    "Nome del server proxy: Numeri di porta"

  3. Eseguire uno dei comandi seguenti.

    • Quando è già stato impostato un server proxy

      Configurare l'impostazione il modo che il computer possa accedere allo scanner senza usare il server proxy.

      netsh winhttp set proxy proxy-server="XXXXXX:YYYY" bypass-list=ZZZ.ZZZ.ZZZ.ZZZ

      XXXXXX: Nome del server proxy

      YYYY: Numeri di porta da usare

      ZZZ.ZZZ.ZZZ.ZZZ: Indirizzo IP dello scanner (*1)(*2)

    • Quando il server proxy non è stato impostato

      Ripristinando le impostazioni, il computer potrebbe essere in grado di accedere allo scanner.

      netsh winhttp reset proxy
*1:

è possibile controllare l'indirizzo IP dello scanner sullo schermo tattile o sul pannello di comando dello scanner o nel Programma di impostazione dell'indirizzo IP.
*2:

Il formato dell'indirizzo IPv4 è qui utilizzato come esempio.

Per un indirizzo IPv6, è utilizzato il formato seguente.

ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ
