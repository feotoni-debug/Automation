تغيير عنوان IP لماسحة ضوئية

يوضح هذا القسم كيفية استخدام أداة تعيين عنوان IP لتغيير عنوان IP لماسحة ضوئية.

يتم عرض عنوان IP في قائمة الماسحات الضوئية في نافذة [أداة تحديد الماسحة].

يتم تخصيص عنوان IPv4 او عنوان IPv6 تلقائيًا للماسحة كإعداد المصنع الافتراضي.

على سبيل المثال، استخدم أداة تعيين عنوان IP لتغيير عنوان IP الخاص بالماسحة في الحالات التالية.

  • عندما لا تعثر الماسحة على أداة تحديد الماسحة

  • عند توصيل ماسحة بشبكة لا تستخدم خادم DHCP

  • عندما تريد تعيين عنوان IP ثابت لماسحة ضوئية

  1. قم بتوصيل ماسحة ضوئية بجهاز الكمبيوتر باستخدام كبل USB المُرفق مع الماسحة الضوئية.
  2. قم بتشغيل الماسحة الضوئية.

    لمعرفة التفاصيل، راجع دليل المشغل الخاص بالماسحة لديك.

  3. ابدأ تشغيل أداة تعيين عنوان IP.

    لمعرفة التفاصيل، راجع بدء تشغيل أداة تعيين عنوان IP.

    تظهر نافذة تسجيل الدخول لأداة تعيين عنوان IP.

    عند عدم تعيين كلمة مرور المسؤول للماسحة، تظهر نافذة [أداة تعيين عنوان IP]. تابع إلى الخطوة 5.

  4. أدخل كلمة مرور المسؤول لماسحة، وانقر فوق زر [تسجيل الدخول].

    لمعرفة التفاصيل حول كلمة مرور المسؤول الافتراضية في إعدادات المصنع، راجع دليل المشغل الخاص بالماسحة.

    تظهر نافذة [أداة تعيين عنوان IP].

  5. حدّد طريقة لتعيين عنوان IP.

    • عنوان IPv4

      حدّد طريقة لتعيين عنوان IP لماسحة ضوئية في [تكوين IPv4] من [الشبكة].

      • عندما تحدد [تلقائي]

        تابع إلى الخطوة 6.

      • عندما تحدد [يدوي]

        أدخِل الأرقام المناسبة في [عنوان IP]، و[قناع الشبكة الفرعية] و[البوابة الافتراضية].

    • عنوان IPv6

      1. اضغط على زر [إعدادات IPv6] من [IPv6] ضمن [الشبكة].

      2. حدّد طريقة لتعيين عنوان IP لماسحة ضوئية في [تكوين IPv6] في نافذة [إعدادات IPv6].

        • عندما تحدد [تلقائي] أو [تعطيل]

          انقر على زر [موافق]، وتابع إلى الخطة 6.

        • عندما تحدد [يدوي]

          أدخِل الأرقام المناسبة في [عنوان IP]، و[طول بادئة الشبكة الفرعية] و[البوابة الافتراضية].

      3. انقر على زر [موافق].

  6. انقر على زر [موافق].
  7. افصل كبل USB من الماسحة الضوئية.
