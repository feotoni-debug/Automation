Fenster [Schaltflächeneinstellungen]

Legen Sie eine Bildscananwendung fest, die gestartet werden soll, wenn eine Taste am Scanner betätigt wird.
Wählen Sie ein Ereignis aus

Wählen Sie in der Tastenliste eine Taste aus, um eine Bildscananwendung festzulegen, die gestartet werden soll, wenn eine Taste am Scanner betätigt wird.

TIPP

  • Die in der Tastenliste angezeigten Tastenbezeichnungen variieren abhängig vom Scannermodell.

    Ausführliche Informationen finden Sie im Bedienungshandbuch des Scanners.

  • Wenn Sie mit Button Event Manager eine Bildscananwendung für die Scan-Taste eines Scanners festlegen, beachten Sie Folgendes.

    • Wenn PaperStream ClickScan ausgeführt wird

      Unabhängig von möglichen Einstellungen, die mit Button Event Manager für die Scan-Taste konfiguriert wurden, wird ein Scan mit PaperStream ClickScan ausgeführt, wenn die Scan-Taste am Scanner betätigt wird.

      Um eine andere Bildscananwendung zu starten (indem die Scan-Taste am Scanner betätigt wird), beenden Sie PaperStream ClickScan. Ausführliche Informationen finden Sie in der PaperStream ClickScan Hilfe.

    • Wenn PaperStream ClickScan nicht ausgeführt wird und PaperStream Capture installiert ist

      PaperStream Capture wird automatisch für die Scan-Taste eines Scanners festgelegt.

      Wenn Sie PaperStream Capture nicht für die Scan-Taste eines Scanners festlegen, wählen Sie [Keine] oder [Folgendes Programm ausführen] unter [Vorgang].

      Ausführliche Informationen zum Festlegen einer Taste am Scanner finden Sie unter Konfigurieren der Einstellungen für die Tasten am Scanner.

Vorgang
[PaperStream Capture] starten

Wählen Sie diese Option, um PaperStream Capture zu starten.

Dokumentprofilnamen werden abhängig vom verwendeten Scanner im Touchscreen oder im Bedienfeld angezeigt.

Ausführliche Informationen finden Sie in der PaperStream Capture Hilfe.

Folgendes Programm ausführen

Wählen Sie diese Option, um ein Programm Ihrer Wahl auszuführen.

Legen Sie den Pfad eines auszuführenden Programms fest.

Schaltfläche [Durchsuchen]

Zeigt das Fenster [Eine Anwendung wählen] an.

Legen Sie ein auszuführendes Programm fest.

Parameter

Bis zu 255 Zeichen können als Parameter festgelegt werden.

Ausführliche Informationen zu den Parametern finden Sie in der Anleitung zu dem auszuführenden Programm.

Keine

Wählen Sie diese Option, um kein Programm auszuführen.

Schaltfläche [OK]

Schließt das Fenster.

Die Änderungen werden gespeichert.

Schaltfläche [Abbrechen]

Schließt das Fenster.

Die Änderungen werden nicht gespeichert.
