Menü von Button Event Manager

Die folgenden Menüelemente werden angezeigt, wenn Sie auf im Infobereich rechtsklicken, der sich ganz rechts in der Task-Leiste befindet.
Das Knopfereignis ansehen

Erkennt die Abwärtsbewegung einer Taste am Scanner.

Wenn dies nicht ausgewählt ist, wird die Bildscananwendung, die Sie im Fenster [Schaltflächeneinstellungen] festgelegt haben, nicht gestartet, wenn die Taste am Scanner betätigt wird.

WICHTIG

Wenn derselbe Scanner von mehreren Computern mit dem Scanner-Auswahltool ausgewählt wurde, wählen Sie [Das Knopfereignis ansehen] nur auf dem Computer, mit dem Sie den Scanner verwenden möchten.

TIPP

Um Software Operation Panel durch Drücken der Scantaste am Scanner zu starten, wählen Sie [Das Knopfereignis ansehen] aus.

Ausführliche Informationen zum Betrieb (Funktionieren) eines Scanners, wenn die Scantaste am Scanner gedrückt wird, finden Sie im Bedienungshandbuch des Scanners.

Dieses Tool beim Anmelden starten

Wenn diese Option ausgewählt ist, wird Button Event Manager gestartet, wenn Sie sich bei Windows anmelden.

Wenn Button Event Manager gestartet wurde, wird im Infobereich ganz rechts in der Taskleiste eine Benachrichtigungsmeldung angezeigt.

Konfigurieren der Schaltflächeneinstellungen

Legen Sie eine Bildscananwendung fest, die gestartet werden soll, wenn eine Taste am Scanner betätigt wird.

Das Fenster [Schaltflächeneinstellungen] wird angezeigt.

Hilfe

Zeigt die Hilfe an.

Über

Zeigt die Versionsinformationen an.

Beenden

Beendet Button Event Manager.
