Zertifikateinstellungen-Fenster

Ein Client-Zertifikat und ein CA-Zertifikat können festgelegt werden.
Registerkarte [Client-Zertifikate]/Registerkarte [CA-Zertifikate]

Wählen Sie entsprechend dem Zertifikat, das Sie registrieren oder verschieben möchten, eine der folgenden Optionen aus.

Wenn das Zertifikat registriert wurde, werden die Informationen des Zertifikats angezeigt.

Schaltfläche [Registrieren]

Registriert Zertifikate beim Server.

Beim Scanner kann ein Zertifikat für jeden Zertifikatstyp registriert werden.

Wenn bereits Zertifikate registriert sind, werden die vorhandenen Zertifikate überschrieben.

Wenn die Registerkarte [Client-Zertifikate] ausgewählt ist, wird das Fenster [Anmeldung des Zertifikats] (Client-Zertifikate) angezeigt.

Wenn die Registerkarte [CA-Zertifikate] ausgewählt ist, wird das Fenster [Anmeldung des Zertifikats] (CA-Zertifikate) angezeigt.

Schaltfläche [Details]

Zeigt detaillierte Informationen zu den auf dem Scanner registrierten Zertifikaten an.

Durch Anklicken dieser Schaltfläche wird das Fenster [Zertifikatsdetails] angezeigt.

Schaltfläche [Entfernen]

Entfernt ein Zertifikat, das beim Scanner registriert ist.

Schaltfläche [Zurück]

Bringt Sie zum Fenster [Registrierungstool für das Zertifikat] zurück.
