Fenster [Tool zum Festlegen der IP-Adresse]

Ändern Sie die Netzwerkeinstellungen des Scanners.
Scannername

Geben Sie einen Scannernamen mit bis zu 64 Zeichen ein.

Folgende Zeichen sind zulässig:

  • Alphanumerische Zeichen

  • - (Bindestrich)

  • _ (Unterstrich)

  • Leerzeichen

    Beachten Sie, dass Leerzeichen am Anfang und Ende eines Namens gelöscht werden.

Die werkseitige Standardeinstellung ist der Modellname und die Seriennummer des Scanners (Modellname - Seriennummer).

TIPP

  • Die Seriennummer des Scanners ist auf dem Typenschild des Produktes aufgedruckt.

    Ausführliche Informationen finden Sie im Bedienungshandbuch des Scanners.

  • Wenn Sie [Dynamische DNS] in den Scanner-Einstellungen aktivieren, geben Sie einen Scannernamen mit einer maximalen Länge von 63 Zeichen ein.

    Ausführliche Informationen zum Dynamischen DNS finden Sie im Bedienungshandbuch des Scanners.

    Es wird empfohlen, keine der folgenden Zeichen halber Breite zu verwenden, wenn ein Scannername auf dem DNS-Server registriert wird, weil diese Zeichen in "-" (Bindestrich) umgewandelt werden.

    • _ (Unterstrich)

    • Leerzeichen
