Fenster [Scanner-Auswahltool]

Wählen Sie unter den Scannern, die mit einem Netzwerk verbunden sind, einen Scanner aus, den Sie über Ihren Computer verwenden möchten.
Möchten Sie einen Scanner über eine Anwendung bedienen?

Zeigt die Hilfe an.

Scannerliste

Zeigt die Informationen zu den Scannern an, die gefunden wurden.

Wenn Sie das Scanner-Auswahltool starten, sucht dieses Tool automatisch nach Scannern innerhalb des Suchbereichs, der für [Suchmethode für den Scanner] eingestellt ist, und zeigt Modellnamen, Scannernamen sowie IP-Adressen der gefundenen Scanner an.

Klicken Sie auf den Namen eines Scanners, den Sie über den Computer verwenden möchten, um das Kontrollkästchen zu aktivieren. Sie können nur einen Scanner auswählen.

Wenn bereits ein Scanner ausgewählt wurde, wird der Scanner oben in der Scannerliste angezeigt.

Wenn Sie keinen mit dem Netzwerk verbundenen Scanner verwenden, klicken Sie auf den Namen des ausgewählten Scanners, um das Häkchen zu löschen.

TIPP

  • Sie können auch auf einen Scanner in der Scannerliste doppelklicken, um den Scanner auszuwählen.

    Durch das Doppelklicken auf den Scanner wird der Scanner für einen Computer verfügbar gemacht und das Scanner-Auswahltool wird beendet.

  • Beim fi-8950, fi-8930, fi-8820, fi-8040, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 oder fi-8250 können Sie durch Anklicken einer IP-Adresse, die in der Scannerliste unter [IP-Adresse] angezeigt wird, die fi Series-Netzwerkeinstellungen (in einem Webbrowser) aufrufen.

    Einzelheiten zu den fi Series-Netzwerkeinstellungen (in einem Webbrowser) finden Sie in der Bedienungsanleitung' des Scanners.

  • Wenn ein Scanner bereits ausgewählt wurde und Sie das Scanner-Auswahltool starten oder die Schaltfläche [Erneut suchen] im Fenster [Scanner-Auswahltool] in einem der folgenden Zustände anklicken, wird dem ausgewählten Scanner stattdessen hinzugefügt .

    • Der ausgewählte Scanner ist nicht mit einem Netzwerk verbunden
    • Der ausgewählte Scanner ist ausgeschaltet

    • Ein ungültiger Wert für den ausgewählten Scanner wurde in [Suchbereich] unter [Suchmethode für den Scanner] festgelegt

      Wenn der ausgewählte Scanner an ein Netzwerk angeschlossen ist, können Sie den Scanner verwenden, wie er ist.

Suchmethode für den Scanner
Suchbereich
IPv4

Sucht nach Scannern, die mittels einer IPv4-Adresse mit dem gleichen Subnetzwerk wie der Computer verbunden sind.

Dies ist die Standardeinstellung.

IPv6

Sucht nach Scannern, die mittels einer IPv6-Adresse mit dem gleichen Subnetzwerk wie der Computer verbunden sind.

Für fi-8950, fi-8930, fi-8820, fi-8040, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 oder fi-8250 können Sie diese Option auswählen, um nach Scannern zu suchen.

IP-Adresse eingeben

Wählen Sie diese Option, um nach einem Scanner zu suchen, indem Sie die IP-Adresse eines Scanners festlegen oder diese auswählen, um einen Scanner zu verwenden, der mit einem Subnetzwerk verbunden ist, das sich von dem Subnetzwerk unterscheidet, mit dem der Computer verbunden ist.

Geben Sie eine IP-Adresse in die Eingabefelder ein.

Namen eingeben

Wählen Sie diese Option, um nach einem Scanner zu suchen, indem Sie den Namen eines Scanners angeben, der auf dem DNS-Server registriert ist.

TIPP

Der Name eines Scanners muss ein Name sein, der auf dem DNS-Server registriert ist.

Geben Sie einen Scannernamen mit bis zu 255 Zeichen in das Eingabefeld ein.

Folgende Zeichen sind zulässig:

  • Alphanumerische Zeichen

  • - (Bindestrich)

  • . (Punkt)

Schaltfläche [Erneut suchen]

Startet eine Suche nach einem Scanner.

Haben Sie den gesuchten Scanner nicht gefunden?

Zeigt die Hilfe an.

Schaltfläche [IP-Adresse festlegen]

Starten Sie das Tool zum Festlegen der IP-Adresse.

Wenn der Scanner, den Sie über den Computer verwenden möchten, nicht gefunden wird, können Sie durch einen Klick auf diese Option den Scannernamen oder die IP-Adresse des Scanners prüfen.

Um das Tool zum Festlegen der IP-Adresse zu verwenden, müssen Sie den Scanner über das USB-Kabel mit dem Computer verbunden.

Schaltfläche [OK]

Beendet das Scanner-Auswahltool.

Die Änderungen werden gespeichert.

Schaltfläche [Abbrechen]

Beendet das Scanner-Auswahltool.

Die Änderungen werden nicht gespeichert.
