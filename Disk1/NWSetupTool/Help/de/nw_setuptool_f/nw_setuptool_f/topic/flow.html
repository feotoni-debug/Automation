Bedienungsablauf

Im Folgenden sehen Sie den Bedienungsablauf für die Verwendung einer Bildscananwendung zum Scannen von Dokumenten.

  • Starten eines Scans über eine Bildscananwendung

  • Starten eines Scans durch Ausführen einer Bildscananwendung über die Taste eines Scanners

Starten eines Scans über eine Bildscananwendung

  • Für fi-8040 oder fi-7300NX

    1. Konfigurieren Sie die Netzwerkeinstellungen im Touchscreen des Scanners.

      Ausführliche Informationen finden Sie im Bedienungshandbuch des Scanners.

    2. Verbinden Sie den Scanner mit einem Netzwerk.

      TIPP

      Wenn Sie den fi-7300NX über WLAN mit einem Netzwerk verbinden, für das ein Zertifikat erforderlich ist, muss das Zertifikat im Voraus auf dem Scanner registriert werden. Weitere Informationen finden Sie unter Registrieren von Zertifikaten auf einem Scanner.

    3. Starten Sie das Scanner-Auswahltool, um den Scanner auszuwählen, den Sie mit dem Computer verwenden möchten.

      Ausführliche Informationen finden Sie unter Schritt 3 und den nachfolgenden Schritten von Auswählen eines zu verwendenden Scanners.

    4. Wählen Sie in einer Bildscananwendung den Scanner für eine verkabelte LAN- oder WLAN-Verbindung aus.

      Die Namen der Scanner für eine LAN- oder WLAN-Verbindung sind wie folgt:

      • Für PaperStream IP (TWAIN)/PaperStream IP (TWAIN x64)

        PaperStream IP xxx Net

      • Für PaperStream IP (ISIS) fi-8000 Series/PaperStream IP (ISIS) Bundle

        PaperStream_IP xxx Net

      "xxx" gibt den Scannermodellnamen an. Ausführliche Informationen finden Sie in der Scannertreiber-Hilfe.

      TIPP

      Nur der fi-7300NX kann mit einer WLAN-Verbindung verwendet werden.

    5. Legen Sie Dokumente in einen Scanner ein und scannen Sie sie über eine Bildscananwendung.

      Ausführliche Informationen zum Einlegen von Dokumenten finden Sie im Bedienungshandbuch des Scanners.

      TIPP

      Auch wenn ein Scanner mit dem Scanner-Auswahltool ausgewählt wurde, wird der Scanner möglicherweise nicht in der Bildscananwendung angezeigt, die verwendet wird. Weitere Informationen finden Sie unter Über die Bildscananwendung kann kein Scan durchgeführt werden.

  • Für fi-8950, fi-8930, fi-8820, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 oder fi-8250

    1. Verbinden Sie einen Scanner über ein LAN-Kabel mit einem Netzwerkgerät (wie einem Switch, Hub oder Router)

      Ausführliche Informationen finden Sie im Bedienungshandbuch des Scanners.

      • Wenn die IP-Adresse automatisch zugewiesen wird

        Fahren Sie mit dem nächsten Schritt fort.

      • Wenn Sie die IP-Adresse manuell zuweisen

        Starten Sie das Tool zum Festlegen der IP-Adresse, um dem Scanner eine IP-Adresse zuzuweisen.

        Ausführliche Informationen finden Sie unter Ändern der IP-Adresse eines Scanners.

    2. Starten Sie das Scanner-Auswahltool, um den Scanner auszuwählen, den Sie mit dem Computer verwenden möchten.

      Ausführliche Informationen finden Sie unter Schritt 3 und den nachfolgenden Schritten von Auswählen eines zu verwendenden Scanners.

    3. Wählen Sie in einer Bildscananwendung den Scanner für eine verkabelte LAN-Verbindung aus.

      Die Namen der Scanner für eine verkabelte LAN-Verbindung sind wie folgt:

      • Für PaperStream IP (TWAIN)/PaperStream IP (TWAIN x64)

        PaperStream IP xxx Net

      • Für PaperStream IP (ISIS) fi-8000 Series

        PaperStream_IP xxx Net

      "xxx" gibt den Scannermodellnamen an. Ausführliche Informationen finden Sie in der Scannertreiber-Hilfe.

    4. Legen Sie Dokumente in einen Scanner ein und scannen Sie sie über eine Bildscananwendung.

      Ausführliche Informationen zum Einlegen von Dokumenten finden Sie im Bedienungshandbuch des Scanners.

      TIPP

      Auch wenn ein Scanner mit dem Scanner-Auswahltool ausgewählt wurde, wird der Scanner möglicherweise nicht in der Bildscananwendung angezeigt, die verwendet wird. Weitere Informationen finden Sie unter Über die Bildscananwendung kann kein Scan durchgeführt werden.

Starten eines Scans durch Ausführen einer Bildscananwendung über die Taste eines Scanners

  • Für fi-8040 oder fi-7300NX

    1. Konfigurieren Sie die Netzwerkeinstellungen im Touchscreen des Scanners.

      Ausführliche Informationen finden Sie im Bedienungshandbuch des Scanners.

    2. Verbinden Sie den Scanner mit einem Netzwerk.

      TIPP

      Wenn Sie den fi-7300NX über WLAN mit einem Netzwerk verbinden, für das ein Zertifikat erforderlich ist, muss das Zertifikat im Voraus auf dem Scanner registriert werden. Weitere Informationen finden Sie unter Registrieren von Zertifikaten auf einem Scanner.

    3. Starten Sie das Scanner-Auswahltool, um den Scanner auszuwählen, den Sie mit dem Computer verwenden möchten.

      Ausführliche Informationen finden Sie unter Schritt 3 und den nachfolgenden Schritten von Auswählen eines zu verwendenden Scanners.

    4. Starten Sie Button Event Manager und legen Sie eine Bildscananwendung fest, die gestartet werden soll, wenn die Taste am Scanner betätigt wird.

      Ausführliche Informationen finden Sie unter Schritt 3 und den nachfolgenden Schritten von Konfigurieren der Einstellungen für die Tasten am Scanner.

      WICHTIG

      Wenn derselbe Scanner von mehreren Computern mit dem Scanner-Auswahltool ausgewählt wurde, wählen Sie [Das Knopfereignis ansehen] im Menü des Button Event Managers nur auf dem Computer, mit dem Sie den Scanner verwenden möchten.

    5. Legen Sie Dokumente in den Scanner ein und betätigen Sie die Taste am Scanner, um die Dokumente zu scannen.

      Ausführliche Informationen zum Einlegen von Dokumenten finden Sie im Bedienungshandbuch des Scanners.
