Konfigurieren der Einstellungen für die Tasten am Scanner

Dieser Abschnitt erläutert, wie Sie Button Event Manager verwenden und eine Bildscananwendung festlegen, die gestartet werden soll, wenn eine Taste am Scanner betätigt wird.

WICHTIG

Wenn derselbe Scanner von mehreren Computern mit dem Scanner-Auswahltool ausgewählt wurde, wählen Sie [Das Knopfereignis ansehen] im Menü des Button Event Managers nur auf dem Computer, mit dem Sie den Scanner verwenden möchten.

TIPP

Wenn Sie mit Button Event Manager eine Bildscananwendung für die Scan-Taste eines Scanners festlegen, beachten Sie Folgendes.

  • Wenn PaperStream ClickScan ausgeführt wird

    Unabhängig von möglichen Einstellungen, die mit Button Event Manager für die Scan-Taste konfiguriert wurden, wird ein Scan mit PaperStream ClickScan ausgeführt, wenn die Scan-Taste am Scanner betätigt wird.

    Um eine andere Bildscananwendung zu starten (indem die Scan-Taste am Scanner betätigt wird), beenden Sie PaperStream ClickScan. Ausführliche Informationen finden Sie in der PaperStream ClickScan Hilfe.

  • Wenn PaperStream ClickScan nicht ausgeführt wird und PaperStream Capture installiert ist

    PaperStream Capture wird automatisch für die Scan-Taste eines Scanners festgelegt.

    Wenn Sie PaperStream Capture nicht für die Scan-Taste eines Scanners festlegen, wählen Sie [Keine] oder [Folgendes Programm ausführen] unter [Vorgang] für Fenster [Schaltflächeneinstellungen].

  1. Verbinden Sie einen Scanner mit einem Netzwerk.

    Ausführliche Informationen finden Sie im Bedienungshandbuch des Scanners.

  2. Aktivieren Sie den Scanner, der in einer Bildscananwendung ausgewählt werden kann.

    Starten Sie das Scanner-Auswahltool und wählen Sie den zu verwendenden Scanner aus den mit dem Netzwerk verbundenen Scannern aus.

    Ausführliche Informationen finden Sie unter Auswählen eines zu verwendenden Scanners.

  3. Konfigurieren Sie die Scaneinstellungen in der Bildscananwendung.

    Ausführliche Informationen finden Sie in der Anleitung der Bildscananwendung.

  4. Starten Sie Button Event Manager.

    Ausführliche Informationen finden Sie unter Starten von Button Event Manager.

    Wenn Button Event Manager gestartet wurde, wird im Infobereich ganz rechts in der Taskleiste angezeigt.

  5. Klicken Sie mit der rechten Maustaste auf .

    Das Menü von Button Event Manager wird angezeigt.

  6. Wählen Sie [Das Knopfereignis ansehen] im Menü aus.
  7. Klicken Sie auf [Konfigurieren der Schaltflächeneinstellungen] im Menü.

    Das Fenster [Schaltflächeneinstellungen] wird angezeigt.

  8. Legen Sie eine Bildscananwendung fest, die gestartet werden soll, wenn eine Taste am Scanner betätigt wird.

    Ausführliche Informationen zu den Einstellungen finden Sie unter Fenster [Schaltflächeneinstellungen].

  9. Klicken Sie auf die Schaltfläche [OK].
