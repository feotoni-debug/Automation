Registrieren eines Zertifikats

Dieser Abschnitt erläutert, wie Sie das Registrierungstool für das Zertifikat verwenden, um ein Zertifikat beim Scanner zu registrieren.

Um den Scanner über Wi-Fi mit einem Netzwerk zu verbinden, das ein Zertifikat erfordert, muss dieses Zertifikat im Vorfeld beim Scanner registriert werden.

Die folgenden Zertifikate können registriert werden:

  • Client-Zertifikate: PKCS#12-Formatdatei (*.p12, *.pfx)

  • CA-Zertifikate: CA-Zertifikatdatei (*.cer, *.crt, *.der, *.pem)

  1. Starten Sie das Registrierungstool für das Zertifikat.

    Weitere Informationen finden Sie unter Starten des Registrierungstools für das Zertifikat.

    Das Fenster [Registrierungstool für das Zertifikat] wird angezeigt.

  2. Verbinden Sie den Scanner über das USB-Kabel im Lieferumfang des Scanners mit einem Computer und klicken Sie auf die Schaltfläche [Einrichten] im Fenster [Registrierungstool für das Zertifikat].

    Das Zertifikateinstellungen-Fenster wird angezeigt.

    WICHTIG

    Wenn Sie das USB-Kabel abtrennen und wieder anschließen, während das Fenster mit den Zertifikatseinstellungen angezeigt wird, können Sie kein Zertifikat registrieren.

    Schließen Sie das Fenster mit den Zertifikatseinstellungen und klicken Sie im Fenster [Registrierungstool für das Zertifikat] erneut auf die Schaltfläche [Einrichten].

  3. Wählen Sie eine Registerkarte für das Zertifikat, das Sie registrieren möchten ([Client-Zertifikate] oder [CA-Zertifikate]), und klicken Sie auf die Schaltfläche [Registrieren].

    Wenn die Registerkarte [Client-Zertifikate] ausgewählt ist, wird das Fenster [Anmeldung des Zertifikats] (Client-Zertifikate) angezeigt.

    Wenn die Registerkarte [CA-Zertifikate] ausgewählt ist, wird das Fenster [Anmeldung des Zertifikats] (CA-Zertifikate) angezeigt.

  4. Wählen Sie ein Zertifikat aus, das Sie registrieren möchten.

    Um ein Client-Zertifikat zu registrieren, geben Sie das Kennwort für das Zertifikat ein.

  5. Klicken Sie auf die Schaltfläche [OK].

    Das Zertifikat wird beim Scanner registriert.

    Das Zertifikat wird zu der Registerkarte für das Zertifikat ([Client-Zertifikate] oder [CA-Zertifikate]) im Fenster für die Zertifikateinstellungen hinzugefügt.

  6. Klicken Sie auf die Schaltfläche [OK].
  7. Trennen Sie das USB-Kabel vom Scanner.
  8. Schalten Sie den Scanner aus und wieder ein.
    TIPP

    Wenn Sie versuchen, den Scanner auszuschalten, wird möglicherweise die Meldung "In Betrieb..." im Touchscreen des Scanners angezeigt. Auch wenn diese Meldung angezeigt wird, sollte das Ausschalten des Scanners kein Problem darstellen.
