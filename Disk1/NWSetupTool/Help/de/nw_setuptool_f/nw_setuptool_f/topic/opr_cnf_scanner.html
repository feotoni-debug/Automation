Auswählen eines zu verwendenden Scanners

Dieser Abschnitt erläutert, wie das Scanner-Auswahltool verwendet wird, um einen Scanner auszuwählen, den Sie über einen Computer verwenden möchten.
  1. Verbinden Sie einen Scanner mit einem Netzwerk.

    Ausführliche Informationen finden Sie im Bedienungshandbuch des Scanners.

  2. Starten Sie das Scanner-Auswahltool.

    Ausführliche Informationen finden Sie unter Starten des Scanner-Auswahltools.

    Das Fenster [Scanner-Auswahltool] wird angezeigt.

    TIPP

    Wenn Sie das Scanner-Auswahltool starten, sucht dieses Tool automatisch nach Scannern innerhalb des Suchbereichs, der für [Suchmethode für den Scanner] eingestellt ist.

  3. Wählen Sie über die Scannerliste den Scanner aus, den Sie mit einem Computer verwenden möchten.

    Neben einem ausgewählten Scanner wird ein Häkchen angezeigt.

    TIPP

    Wenn der zu verwendende Scanner nicht in der Scannerliste angezeigt wird, suchen Sie anhand der folgenden Schritte nach dem Scanner.

    • Wenn der Scanner mit dem gleichen Subnetzwerk wie der Computer verbunden ist

      Wählen Sie [IPv4] oder [IPv6] im [Suchbereich] unter [Suchmethode für den Scanner] und klicken Sie auf die Schaltfläche [Erneut suchen]

    • Wenn der Scanner mit einem anderen Subnetzwerk als der Computer verbunden ist

      Wählen Sie [IP-Adresse eingeben] oder [Namen eingeben] im [Suchbereich] unter [Suchmethode für den Scanner] und geben Sie die IP-Adresse oder den Namen ein, klicken Sie dann auf die Schaltfläche [Erneut suchen]

  4. Klicken Sie auf die Schaltfläche [OK].
TIPP

  • Sie können auch auf einen Scanner in der Scannerliste doppelklicken, um den Scanner auszuwählen.

    Durch das Doppelklicken auf den Scanner wird der Scanner für einen Computer verfügbar gemacht und das Scanner-Auswahltool wird beendet.

  • Wählen Sie [IP-Adresse eingeben] oder [Namen eingeben] im [Suchbereich] unter [Suchmethode für den Scanner] überprüfen Sie, ob eine IP-Adresse oder ein Name in das Eingabefeld eingegeben wurde, und klicken Sie dann auf die Schaltfläche [OK].
