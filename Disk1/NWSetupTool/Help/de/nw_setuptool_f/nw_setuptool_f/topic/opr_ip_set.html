Ändern der IP-Adresse eines Scanners

Dieser Abschnitt erläutert, wie das Tool zum Festlegen der IP-Adresse verwendet wird, um die IP-Adresse eines Scanners zu ändern.

Die IP-Adresse wird in der Scannerliste im Fenster [Scanner-Auswahltool] angezeigt.

Die Ipv4- oder IPv6-Adresse wird einem Scanner automatisch als werkseitige Standardeinstellung zugewiesen.

Verwenden Sie zum Beispiel in den folgenden Fällen das Tool zum Festlegen der IP-Adresse eines Scanners.

  • Wenn ein Scanner nicht im Scanner-Auswahltool gefunden wurde

  • Wenn ein Scanner mit einem Netzwerk verbunden wird, das keinen DHCP-Server verwendet

  • Wenn Sie eine feste IP-Adresse für einen Scanner festlegen möchten

  1. Verbinden Sie einen Scanner über das USB-Kabel im Lieferumfang des Scanners mit einem Computer.
  2. Schalten Sie den Scanner ein.

    Ausführliche Informationen finden Sie im Bedienungshandbuch des Scanners.

  3. Starten Sie das Tool zum Festlegen der IP-Adresse.

    Ausführliche Informationen finden Sie unter Starten des Tools zum Festlegen der IP-Adresse.

    Das Anmeldefenster des Tools zum Festlegen der IP-Adresse wird angezeigt.

    Wenn für den Scanner kein Administratorkennwort festgelegt wurde, wird das Fenster [Tool zum Festlegen der IP-Adresse] angezeigt. Fahren Sie mit Schritt 5 fort.

  4. Geben Sie das Administratorkennwort für einen Scanner ein und klicken Sie auf die Schaltfläche [Anmelden].

    Ausführliche Informationen zur werkseitigen Standardeinstellung für das Administratorkennwort finden Sie im Bedienungshandbuch des Scanners.

    Das Fenster [Tool zum Festlegen der IP-Adresse] wird angezeigt.

  5. Wählen Sie eine Methode, um eine IP-Adresse festzulegen.

    • IPv4-Adresse

      Wählen Sie unter [IPv4-Konfiguration] unter [Netzwerk] eine Methode, um eine IP-Adresse für einen Scanner festzulegen.

      • Wenn Sie [Automatisch] auswählen

        Fahren Sie mit Schritt 6 fort.

      • Wenn Sie [Manuell] auswählen

        Geben Sie die entsprechenden Zahlen unter [IP-Adresse], [Subnetzmaske] und [Standardgateway] ein.

    • IPv6-Adresse

      1. Klicken Sie auf die Schaltfläche [IPv6-Einstellungen] in [IPv6] unter [Netzwerk].

      2. Wählen Sie eine Methode zum Festlegen einer IP-Adresse für einen Scanner unter [IPv6-Konfiguration] unter Fenster [IPv6-Einstellungen].

        • Wenn Sie [Automatisch] oder [Deaktivieren] auswählen

          Klicken Sie auf die Schaltfläche [OK] und fahren Sie mit Schritt 6 fort.

        • Wenn Sie [Manuell] auswählen

          Geben Sie die entsprechenden Zahlen unter [IP-Adresse], [Subnetzpräfixlänge] und [Standardgateway] ein.

      3. Klicken Sie auf die Schaltfläche [OK].

  6. Klicken Sie auf die Schaltfläche [OK].
  7. Trennen Sie das USB-Kabel vom Scanner.
