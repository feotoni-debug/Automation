Ändern des Scannernamens

Dieser Abschnitt erläutert, wie das Tool zum Festlegen der IP-Adresse verwendet wird, um den Scannernamen zu ändern.

Der Scannername wird in der Scannerliste im Fenster [Scanner-Auswahltool] angezeigt.

Die werkseitige Standardeinstellung für den Scannernamen ist der Modellname und die Seriennummer des Scanners (Modellname - Seriennummer).

Die Seriennummer des Scanners ist auf dem Typenschild des Produktes aufgedruckt.

Ausführliche Informationen finden Sie im Bedienungshandbuch des Scanners.

  1. Verbinden Sie einen Scanner über das USB-Kabel im Lieferumfang des Scanners mit einem Computer.
  2. Schalten Sie den Scanner ein.

    Ausführliche Informationen finden Sie im Bedienungshandbuch des Scanners.

  3. Starten Sie das Tool zum Festlegen der IP-Adresse.

    Ausführliche Informationen finden Sie unter Starten des Tools zum Festlegen der IP-Adresse.

    Das Anmeldefenster des Tools zum Festlegen der IP-Adresse wird angezeigt.

    Wenn für den Scanner kein Administratorkennwort festgelegt wurde, wird das Fenster [Tool zum Festlegen der IP-Adresse] angezeigt. Fahren Sie mit Schritt 5 fort.

  4. Geben Sie das Administratorkennwort für einen Scanner ein und klicken Sie auf die Schaltfläche [Anmelden].

    Ausführliche Informationen zur werkseitigen Standardeinstellung für das Administratorkennwort finden Sie im Bedienungshandbuch des Scanners.

    Das Fenster [Tool zum Festlegen der IP-Adresse] wird angezeigt.

  5. Geben Sie im Eingabefeld [Scannername] passende Zeichen ein.

    Zulässige Zeichen sind alphanumerische Zeichen, "-" (Bindestrich), "_" (Unterstrich) und Leerzeichen.

    Es können bis zu 64 Zeichen festgelegt werden.

    TIPP

    Wenn Sie [Dynamische DNS] in den Scanner-Einstellungen aktivieren, geben Sie einen Scannernamen mit einer maximalen Länge von 63 Zeichen ein.

    Ausführliche Informationen zum Dynamischen DNS finden Sie im Bedienungshandbuch des Scanners.

    Es wird empfohlen, keine der folgenden Zeichen halber Breite zu verwenden, wenn ein Scannername auf dem DNS-Server registriert wird, weil diese Zeichen in "-" (Bindestrich) umgewandelt werden.

    • _ (Unterstrich)

    • Leerzeichen

  6. Klicken Sie auf die Schaltfläche [OK].
  7. Trennen Sie das USB-Kabel vom Scanner.
