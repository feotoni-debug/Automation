Starten des Scanner-Auswahltools

Dieser Abschnitt erläutert, wie das Scanner-Auswahltool gestartet wird.

Startvorgang

  • Für Windows 10/Windows Server 2016/Windows Server 2019/Windows Server 2022

    Wählen Sie das [Start]-Menü → [fi Series] → [Scanner-Auswahltool for fi Series].

  • Für Windows 11/Windows Server 2025

    Wählen Sie das [Start]-Menü → [Alle Apps] → [fi Series] → [Scanner-Auswahltool for fi Series].

TIPP

Sie können das Scanner-Auswahltool auch starten, indem Sie auf die Schaltfläche [Wählen Sie einen Scanner aus] im Fenster [Tool zum Festlegen der IP-Adresse] klicken.
