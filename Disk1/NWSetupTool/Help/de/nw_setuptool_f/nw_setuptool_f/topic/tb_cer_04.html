Entfernen des Zertifikats fehlgeschlagen.

Ursache

Sie haben die folgenden Schritte ausgeführt, nachdem Sie im Fenster [Registrierungstool für das Zertifikat] auf die Schaltfläche [Einrichten] geklickt haben.

  • Ausschalten des Scanners

  • Verbinden des Scanners mit dem Computer über ein USB-Kabel und Trennen der Verbindung

Abhilfemaßnahme

Führen Sie folgende Schritte aus:

  • Schalten Sie den Scanner ein.

  • Verbinden Sie den Scanner über das USB-Kabel im Lieferumfang des Scanners mit dem Computer.

  • Starten Sie das Registrierungstool für das Zertifikat neu.

Führen Sie die folgenden Schritte durch, wenn auch nach Durchführung der oben aufgeführten Maßnahmen noch immer eine Meldung angezeigt wird:

  1. Schalten Sie den Scanner aus und wieder ein.

    TIPP

    Wenn Sie versuchen, den Scanner auszuschalten, wird möglicherweise die Meldung "In Betrieb..." im Touchscreen des Scanners angezeigt. Auch wenn diese Meldung angezeigt wird, sollte das Ausschalten des Scanners kein Problem darstellen.

  2. Starten Sie den Computer neu.

  3. Starten Sie das Registrierungstool für das Zertifikat neu.
