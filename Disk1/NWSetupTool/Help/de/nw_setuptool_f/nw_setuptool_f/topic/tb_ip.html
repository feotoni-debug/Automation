Tool zum Festlegen der IP-Adresse

Dieser Abschnitt beschreibt Fehlermeldungen, die möglicherweise bei der Verwendung des Tools zum Festlegen der IP-Adresse angezeigt werden, und erläutert Lösungsmöglichkeiten für die Fehler.
  • Verbinden Sie den Scanner über das USB-Kabel mit dem Computer.
  • Schließen Sie nur einen Scanner an.
  • Es ist ein Kommunikationsfehler aufgetreten.
  • Der Scannername enthält nicht unterstützte Zeichen.
  • Eine reservierte Adresse kann nicht für die IP-Adresse angegeben werden.
  • Eine reservierte Adresse kann nicht für die Subnetzmaske angegeben werden.
  • Die IP-Adresse oder die Subnetzmaske ist ungültig.
  • Die IP-Adresse hat ein falsches Format.
  • Die Subnetzpräfixlänge hat ein falsches Format.
  • Eine reservierte Adresse kann nicht für das Standard-Gateway angegeben werden.
  • Das Standardgateway hat ein falsches Format.
  • Das Standard-Gateway oder die Subnetzmaske ist ungültig.
  • Es wurde kein Name für den Scanner angegeben.
  • Dieser Scanner wird von einem andere Benutzer oder einer anderen Anwendung verwendet.
  • Das Programm konnte nicht gestartet werden.
  • Anmeldung fehlgeschlagen.
  • Es wurde keine Hilfsdatei gefunden.
