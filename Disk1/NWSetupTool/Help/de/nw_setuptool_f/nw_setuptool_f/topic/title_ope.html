Bedienvorgänge

Dieser Abschnitt erläutert, wie Sie das jeweilige Tool im Network Setup Tool for fi Series verwenden.

Die unterstützten Scannermodelle variieren abhängig von dem für das Modell verwendeten Tool. Ausführliche Informationen zu den jeweiligen vom Tool unterstützten Scannermodellen finden Sie unter Unterstützte Scannermodelle.

WICHTIG

Wenn sich der Scanner gerade in einem Scanvorgang befindet, können keine Einstellungen über das Scanner-Auswahltool, das Tool zum Festlegen der IP-Adresse oder das Registrierungstool für das Zertifikat konfiguriert werden.

Scanner-Auswahltool

  • Auswählen eines zu verwendenden Scanners

Tool zum Festlegen der IP-Adresse

  • Ändern des Scannernamens

  • Ändern der IP-Adresse eines Scanners

  • Verschlüsseln der Kommunikation im Netzwerk

Registrierungstool für das Zertifikat

  • Registrieren eines Zertifikats

  • Entfernen eines Zertifikats

Button Event Manager

  • Konfigurieren der Einstellungen für die Tasten am Scanner

  • Auswählen eines zu verwendenden Scanners
  • Ändern der Netzwerkeinstellungen eines Scanners
  • Registrieren von Zertifikaten auf einem Scanner
  • Konfigurieren der Einstellungen für die Tasten am Scanner
