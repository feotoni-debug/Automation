Wurde für die WinHTTP-Proxy-Einstellung ein Proxy-Server festgelegt?

Abhilfemaßnahme

Ändern Sie die WinHTTP-Proxy-Einstellungen so, dass Sie über den Computer auf den Scanner zugreifen können.

Ändern Sie die WinHTTP-Proxy-Einstellungen anhand der folgenden Schritte.

  1. Starten Sie auf dem Computer ein Eingabeaufforderungsfenster als Benutzer mit Administratorrechten.

  2. Führen Sie den folgenden Befehl aus, um den Namen des Proxy-Servers und die verwendeten Port-Nummern zu prüfen.

    netsh winhttp show proxy

    TIPP

    Der Name des Proxy-Servers und die Port-Nummern, die verwendet werden sollen, werden wie folgt angezeigt.

    "Name des Proxy-Servers: Port-Nummern"

  3. Führen Sie einen der folgenden Befehle aus.

    • Wenn bereits ein Proxy-Server festgelegt wurde

      Konfigurieren Sie die Einstellung so, dass der Computer ohne die Verwendung des Proxy-Servers auf den Scanner zugreifen kann.

      netsh winhttp set proxy proxy-server="XXXXXX:YYYY" bypass-list=ZZZ.ZZZ.ZZZ.ZZZ

      XXXXXX: Name des Proxy-Servers

      YYYY: Zu verwendende Port-Nummern

      ZZZ.ZZZ.ZZZ.ZZZ: IP-Adresse des Scanners (*1)(*2)

    • Wenn der Proxy-Server nicht festgelegt wurde

      Wenn Sie die Einstellungen zurücksetzen, kann der Computer möglicherweise auf den Scanner zugreifen.

      netsh winhttp reset proxy
*1:

Sie können die IP-Adresse des Scanners über den Touchscreen oder das Bedienfeld des Scanners oder über das Tool zum Festlegen der IP-Adresse prüfen.
*2:

Das IPv4-Adressformat wird hier als Beispiel verwendet.

Für eine IPv6-Adresse wird das folgende Format verwendet.

ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ
