[Button Settings] Window

Specify an image scanning application that you want to start up when a button on a scanner is pressed.
Select an event

From the button list, select a button to specify an image scanning application to be started up when a button on a scanner is pressed.

TIP

  • The button names shown in the button list vary depending on the scanner model.

    For details, refer to the Operator's Guide of the scanner.

  • If you use Button Event Manager to specify an image scanning application for the scan button on a scanner, take note of the following.

    • When PaperStream ClickScan is running

      Regardless of any settings that were configured for the scan button with Button Event Manager, a scan is performed with PaperStream ClickScan when the scan button on a scanner is pressed.

      To start up another image scanning application (by pressing the scan button on a scanner), exit PaperStream ClickScan. For details, refer to the PaperStream ClickScan Help.

    • When PaperStream ClickScan is not running and PaperStream Capture is installed

      PaperStream Capture is automatically set for the scan button on a scanner.

      If you do not set PaperStream Capture for the scan button on a scanner, select [Take no action] or [Run the following program] in [Operation].

      For details about how to set a button on the scanner, refer to Configuring the Settings for Buttons on a Scanner.

Operation
Launch [PaperStream Capture]

Select this to start PaperStream Capture.

Document profile names are displayed on the touch screen or the operator panel depending on the scanner that you use.

For details, refer to the PaperStream Capture Help.

Run the following program

Select this to run a program of your choice.

Specify the path of a program to run.

[Browse] button

Displays the [Select an application] window.

Specify a program to run.

Parameters

Up to 255 characters can be specified for parameters.

For details about parameters, refer to the manual of the program to run.

Take no action

Select this to not run any program.

[OK] button

Closes the window.

[Cancel] button
