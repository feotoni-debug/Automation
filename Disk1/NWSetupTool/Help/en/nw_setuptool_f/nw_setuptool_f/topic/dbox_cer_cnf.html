Certificate Settings Window

A client certificate and a CA certificate can be set.
[Client Certificates] tab/[CA Certificates] tab

Select one of them according to the certificate that you want to register or remove.

When a certificate is registered, the information of the certificate is displayed.

[Register] button

Registers certificates on the scanner.

One certificate for each certificate type can be registered on the scanner.

If certificates are already registered, the existing certificates are overwritten.

When the [Client Certificates] tab is selected, the [Certificate Registration] Window (Client Certificates) appears.

When [CA Certificates] tab is selected, the [Certificate Registration] Window (CA Certificates) appears.

[Details] button

Displays detailed information of the registered certificates on the scanner.

Clicking this button displays the [Details of the Certificate] Window.

[Remove] button

Removes a certificate registered on the scanner.

[Back] button

Returns to the [Certificate Registration Tool] Window.
