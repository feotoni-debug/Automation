[IPv6 Settings] Window

Set an IPv6 address.
IPv6 Configuration

Select a method to set an IPv6 address for a scanner.

  • Auto

    An IP address is automatically assigned to a scanner from the DHCP server.

    This is the factory default setting.

  • Manual

    Assign an IP address manually.

  • Disable

    Disable the IPv6 address settings.

[Receive RA packet] check box

This check box appears when you select [Manual] in [IPv6 Configuration].

Select this to enable an IPv6 address that has been generated automatically.

You can check an IPv6 address that has been generated automatically in [IP Address] under [IPv6] in the [IP Address Setting Tool] window.

The check box is selected for the factory default setting.

IP Address

Enter an IP address for a scanner when you select [Manual] in [IPv6 Configuration].

Subnet prefix length

Enter a subnet prefix length for the IP address when you select [Manual] in [IPv6 Configuration].

A value from 3 to 128 can be entered.

Default Gateway

Enter a default gateway for the IP address when you select [Manual] in [IPv6 Configuration].

[OK] button

Closes the window.

The changes are applied to the [IP Address Setting Tool] window.

[Cancel] button

Closes the window.

The changes are not applied to the [IP Address Setting Tool] window.
