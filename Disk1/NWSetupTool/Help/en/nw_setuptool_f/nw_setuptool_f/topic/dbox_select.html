[Scanner Selection Tool] Window

From among the scanners connected to a network, select a scanner that you want to use from your computer.
Do you want to operate a scanner from an application?

Displays the help.

Scanner list

Displays the information of scanners that are found.

When you start Scanner Selection Tool, this tool automatically searches for scanners within the search range that is set for [Search Method for the Scanner], and displays model names, scanner names as well as IP addresses of scanners that are found.

Click the name of a scanner that you want to use from your computer in order to select the check box. You can select only one scanner.

If a scanner has already been selected, the scanner appears at the top of the scanner list.

When you do not use a scanner that is connected to the network, click the name of the selected scanner to clear the check mark.

TIP

  • You can also double-click a scanner in the scanner list to select the scanner.

    Double-clicking the scanner makes the scanner available for a computer and exits Scanner Selection Tool.

  • For fi-8950, fi-8930, fi-8820, fi-8040, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150, or fi-8250, clicking an IP address displayed in [IP Address] on the scanner list starts up fi Series Network Settings (on a web browser).

    For details about fi Series Network Settings (on a web browser), refer to the Operator's Guide of the scanner.

  • When a scanner has already been selected and you start Scanner Selection Tool or click the [Search again] button in the [Scanner Selection Tool] window in one of the following states, will be added to the selected scanner instead of .

    • The selected scanner is not connected to a network
    • The selected scanner is turned off

    • A value that will not search the selected scanner has been specified in [Search Range] under [Search Method for the Scanner]

      In this case, if the selected scanner is connected to a network, you can use the scanner as is.

Search Method for the Scanner
Search Range
IPv4

Searches for scanners that are connected to the same subnetwork as your computer using an IPv4 address.

This is the factory default setting.

IPv6

Searches for scanners that are connected to the same subnetwork as your computer using an IPv6 address.

For fi-8950, fi-8930, fi-8820, fi-8040, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150, or fi-8250, you can select this to search for scanners.

Enter an IP address

Select this to search for a scanner by specifying the IP address of a scanner or select this in order to use a scanner connected to a subnetwork that is different from the subnetwork which your computer is connected to.

Enter an IP address in the input fields.

Enter a name

Select this to search for a scanner by specifying the name of a scanner which is registered on the DNS server.

TIP

The name of a scanner must be a name that is registered on the DNS server.

Enter a name within 255 characters in the input field.

The following characters are available:

  • Alphanumeric characters

  • - (Hyphen)

  • . (Period)

[Search again] button

Starts a search for a scanner.

Could you not find the scanner you are looking for?

Displays the help.

[Set an IP Address] button

Start up IP Address Setting Tool.

When the scanner that you want to use from your computer is not found, clicking this allows you to check the scanner name or the IP address of the scanner.

To use IP Address Setting Tool, you need to connect the scanner to your computer via the USB cable.

[OK] button

Exits Scanner Selection Tool.

The changes are saved.

[Cancel] button

Exits Scanner Selection Tool.

The changes are not saved.
