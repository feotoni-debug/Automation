Flow of the Operation

The following shows the flow of the operation for using an image scanning application in order to scan documents.

  • Starting a scan from an image scanning application

  • Starting a scan by running an image scanning application from the button on a scanner

Starting a scan from an image scanning application

  • For fi-8040 or fi-7300NX

    1. Configure the network settings on the touch screen of the scanner

      For details, refer to the Operator's Guide of the scanner.

    2. Connect the scanner to a network

      TIP

      When you use fi-7300NX connected to a network that requires a certificate via Wi-Fi, the certificate must be registered on the scanner in advance. For details, refer to Registering Certificates on a Scanner.

    3. Start up Scanner Selection Tool to select the scanner that you want to use from a computer

      For details, refer to step 3 and the subsequent steps in Selecting a Scanner That You Want to Use.

    4. In an image scanning application, select the scanner connected to a wired LAN or Wi-Fi

      Names of the scanners connected to a wired LAN or Wi-Fi are as follows:

      • For PaperStream IP (TWAIN)/PaperStream IP (TWAIN x64)

        PaperStream IP xxx Net

      • For PaperStream IP (ISIS) fi-8000 series/PaperStream IP (ISIS) Bundle

        PaperStream_IP xxx Net

      "xxx" indicates the scanner model name. For details, refer to the Help of the scanner driver.

      TIP

      Only fi-7300NX can be used with a Wi-Fi connection.

    5. Load documents in a scanner and scan them from an image scanning application

      For details about how to load documents, refer to the Operator's Guide of the scanner.

      TIP

      Even though a scanner is selected with Scanner Selection Tool, the scanner may not appear in the image scanning application that is being used. For details, refer to Cannot Perform a Scan from the Image Scanning Application.

  • For fi-8950, fi-8930, fi-8820, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150, or fi-8250

    1. Connect a scanner to a network device (such as a switch, hub, or router) with a LAN cable

      For details, refer to the Operator's Guide of the scanner.

      • When an IP address is automatically assigned

        Proceed to the next step.

      • When you assign an IP address manually

        Start up IP Address Setting Tool to assign an IP address to a scanner.

        For details, refer to Changing the IP Address for a Scanner.

    2. Start up Scanner Selection Tool to select the scanner that you want to use from a computer

      For details, refer to step 3 and the subsequent steps in Selecting a Scanner That You Want to Use.

    3. In an image scanning application, select the scanner connected to a wired LAN

      Names of the scanners connected to a wired LAN are as follows:

      • For PaperStream IP (TWAIN)/PaperStream IP (TWAIN x64)

        PaperStream IP xxx Net

      • For PaperStream IP (ISIS) fi-8000 series

        PaperStream_IP xxx Net

      "xxx" indicates the scanner model name. For details, refer to the Help of the scanner driver.

    4. Load documents in a scanner and scan them from an image scanning application

      For details about how to load documents, refer to the Operator's Guide of the scanner.

      TIP

      Even though a scanner is selected with Scanner Selection Tool, the scanner may not appear in the image scanning application that is being used. For details, refer to Cannot Perform a Scan from the Image Scanning Application.

Starting a scan by running an image scanning application from the button on a scanner

  • For fi-8040 or fi-7300NX

    1. Configure the network settings on the touch screen of the scanner

      For details, refer to the Operator's Guide of the scanner.

    2. Connect the scanner to a network

      TIP

      When you use fi-7300NX connected to a network that requires a certificate via Wi-Fi, the certificate must be registered on the scanner in advance. For details, refer to Registering Certificates on a Scanner.

    3. Start up Scanner Selection Tool to select the scanner that you want to use from a computer

      For details, refer to step 3 and the subsequent steps in Selecting a Scanner That You Want to Use.

    4. Start up Button Event Manager and specify an image scanning application to be started when the button on the scanner is pressed

      For details, refer to step 3 and the subsequent steps in Configuring the Settings for Buttons on a Scanner.

      ATTENTION

      When the same scanner has been selected by more than one computer using Scanner Selection Tool, select [Watch Button Event] on the menu of Button Event Manager only on the computer that you want to use the scanner with.

    5. Load documents in the scanner, and press the button on the scanner to scan the documents

      For details about how to load documents, refer to the Operator's Guide of the scanner.

  • For fi-8950, fi-8930, fi-8820, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150, or fi-8250

    1. Connect a scanner to a network device (such as a switch, hub, or router) with a LAN cable

        Proceed to the next step.

      • When you assign an IP address manually

        For details, refer to Changing the IP Address for a Scanner.

    2. Start up Scanner Selection Tool to select the scanner that you want to use from a computer

    4. Load documents in the scanner, and press the button on the scanner to scan the documents

      For details about how to load documents, refer to the Operator's Guide of the scanner.
