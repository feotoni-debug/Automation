Configuring the Settings for Buttons on a Scanner

This section explains how to use Button Event Manager and specify an image scanning application to be started when a button on a scanner is pressed.

ATTENTION

When the same scanner has been selected by more than one computer using Scanner Selection Tool, select [Watch Button Event] on the menu of Button Event Manager only on the computer that you want to use the scanner with.

TIP

If you use Button Event Manager to specify an image scanning application for the scan button on a scanner, take note of the following.

  • When PaperStream ClickScan is running

    Regardless of any settings that were configured for the scan button with Button Event Manager, a scan is performed with PaperStream ClickScan when the scan button on a scanner is pressed.

    To start up another image scanning application (by pressing the scan button on a scanner), exit PaperStream ClickScan. For details, refer to the PaperStream ClickScan Help.

  • When PaperStream ClickScan is not running and PaperStream Capture is installed

    PaperStream Capture is automatically set for the scan button on a scanner.

    If you do not set PaperStream Capture for the scan button on a scanner, select [Take no action] or [Run the following program] for [Operation] in the [Button Settings] Window.

  1. Connect a scanner to a network.

    For details, refer to the Operator's Guide of the scanner.

  2. Enable the scanner to be selected in an image scanning application.

    Start up Scanner Selection Tool, and select the scanner to be used from scanners connected to a network.

    For details, refer to Selecting a Scanner That You Want to Use.

  3. Configure the scan settings in the image scanning application.

    For details, refer to the manual for the image scanning application.

  4. Start up Button Event Manager.

    For details, refer to Starting Up Button Event Manager.

    When Button Event Manager is started, appears in the notification area located at the far right of the task bar.

  5. Right-click .

    The Menu of Button Event Manager appears.

  6. Select [Watch Button Event] on the menu.
  7. Click [Configure button settings] on the menu.

    The [Button Settings] Window appears.

  8. Specify an image scanning application to be started when a button on a scanner is pressed.

    For details about the settings, refer to [Button Settings] Window.

  9. Click the [OK] button.
