Register a Certificate

This section explains how to use Certificate Registration Tool to register a certificate on a scanner.

To connect a scanner to a network that requires a certificate via Wi-Fi , register this certificate on the scanner in advance.

Certificates that can be registered are as follows:

  • Client certificate: PKCS#12 format file (*.p12, *.pfx)

  • CA certificate: CA certificate file (*.cer, *.crt, *.der, *.pem)

  1. Start up Certificate Registration Tool.

    For details, refer to Starting Up Certificate Registration Tool.

    The [Certificate Registration Tool] Window appears.

  2. Connect a scanner to a computer with the USB cable that is supplied with the scanner, and click the [Set] button in the [Certificate Registration Tool] window.

    The Certificate Settings Window appears.

    ATTENTION

    If you disconnect then connect the USB cable while the certificate settings window is displayed, you cannot register a certificate.

    Close the certificate settings window, and click the [Set] button again in the [Certificate Registration Tool] window.

  3. Select a tab for the certificate that you want to register ([Client Certificates] or [CA Certificates]) and click the [Register] button.

    When the [Client Certificates] tab is selected, the [Certificate Registration] Window (Client Certificates) appears.

    When [CA Certificates] tab is selected, the [Certificate Registration] Window (CA Certificates) appears.

  4. Specify a certificate that you want to register.

    To register a client certificate, enter a password for the certificate.

  5. Click the [OK] button.

    The certificate is registered on the scanner.

    The certificate is added to a tab for the certificate ([Client Certificates] or [CA Certificates]) in the certificate settings window.

  6. Click the [OK] button.
  7. Unplug the USB cable from the scanner.
  8. Turn off the scanner and turn it on again.
    TIP

    When you try to turn off the scanner, the message "Operating..." may keep appearing on the touch screen of the scanner. Even if this occurs, turning off the scanner should not be a problem.
