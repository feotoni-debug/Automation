Selecting a Scanner That You Want to Use

This section explains how to use Scanner Selection Tool in order to select a scanner that you want to use from a computer.
  1. Connect a scanner to a network.

    For details, refer to the Operator's Guide of the scanner.

  2. Start up Scanner Selection Tool.

    For details, refer to Starting Up Scanner Selection Tool.

    The [Scanner Selection Tool] Window appears.

    TIP

    When you start Scanner Selection Tool, this tool automatically searches for scanners within the search range that is set for [Search Method for the Scanner].

  3. From the scanner list, select the scanner that you want to use from a computer.

    A check mark appears next to a selected scanner.

    TIP

    If the scanner that you want to use is not shown in the scanner list, search for the scanner in the following procedure.

    • When the scanner is connected to the same subnetwork as the one that the computer is connected to

      Select [IPv4] or [IPv6] in [Search Range] under [Search Method for the Scanner], and click the [Search again] button

    • When the scanner is connected to a different subnetwork from the one that the computer is connected to

      Select [Enter an IP address] or [Enter a name] in [Search Range] under [Search Method for the Scanner], and enter the IP address or the name, and click the [Search again] button

  4. Click the [OK] button.
TIP

  • You can also double-click a scanner in the scanner list to select the scanner.

    Double-clicking the scanner makes the scanner available for a computer and exits Scanner Selection Tool.

  • When you specify [Enter an IP address] or [Enter a name] in [Search Range] under [Search Method for the Scanner], check that an IP address or a name is entered in the input field, then click the [OK] button.
