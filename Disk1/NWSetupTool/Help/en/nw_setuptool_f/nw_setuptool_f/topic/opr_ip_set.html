Changing the IP Address for a Scanner

This section explains how to use IP Address Setting Tool to change the IP address for a scanner.

The IP address is displayed in the scanner list in the [Scanner Selection Tool] window.

The IPv4 address or IPv6 address is assigned automatically to a scanner as the factory default setting.

For example, use IP Address Setting Tool to change the IP address of a scanner in the following cases.

  • When a scanner is not found in Scanner Selection Tool

  • When connecting a scanner to a network that does not use a DHCP server

  • When you want to set a fixed IP address for a scanner

  1. Connect a scanner to a computer with the USB cable that is supplied with the scanner.
  2. Turn on the scanner.

    For details, refer to the Operator's Guide of the scanner.

  3. Start up IP Address Setting Tool.

    For details, refer to Starting Up IP Address Setting Tool.

    The login window of IP Address Setting Tool appears.

    When an administrator password is not set for the scanner, the [IP Address Setting Tool] Window appears. Proceed to step 5.

  4. Enter the administrator password for a scanner, and click the [Login] button.

    For details about the factory default administrator password, refer to the Operator's Guide of the scanner.

    The [IP Address Setting Tool] Window appears.

  5. Select a method to set an IP address.

    • IPv4 address

      Select a method to set an IP address for a scanner in [IPv4 Configuration] under [Network].

      • When you select [Auto]

        Proceed to step 6.

      • When you select [Manual]

        Enter appropriate numbers in [IP Address], [Subnet Mask], and [Default Gateway].

    • IPv6 address

      1. Click the [IPv6 Settings] button in [IPv6] under [Network].

      2. Select a method to set an IP address for a scanner in [IPv6 Configuration] in the [IPv6 Settings] Window.

        • When you select [Auto] or [Disable]

          Click the [OK] button, and proceed to step 6.

        • When you select [Manual]

          Enter appropriate numbers in [IP Address], [Subnet prefix length], and [Default Gateway].

      3. Click the [OK] button.

  6. Click the [OK] button.
  7. Unplug the USB cable from the scanner.
