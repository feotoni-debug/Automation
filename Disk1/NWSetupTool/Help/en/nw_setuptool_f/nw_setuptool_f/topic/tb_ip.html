IP Address Setting Tool

This section describes error messages that may be displayed while you are using IP Address Setting Tool and explains the solutions for the errors.
  • Connect the scanner to the computer using the USB cable.
  • Connect only one scanner.
  • A communication error occurred.
  • Unsupported characters are included in the scanner name.
  • A reserved address cannot be specified for the IP Address.
  • A reserved address cannot be specified for the subnet mask.
  • The IP address or subnet mask is invalid.
  • The IP address is in an incorrect format.
  • The subnet prefix length is in an incorrect format.
  • A reserved address cannot be specified for the default gateway.
  • The default gateway is in an incorrect format.
  • The default gateway or subnet mask is invalid.
  • A scanner name has not been entered.
  • This scanner is being used by another user or application.
  • Failed to start up the program.
  • Login failed.
  • No help file is found.
