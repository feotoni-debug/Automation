No Scanner Is Found

Check the following:

  • Is the connection method (used to connect the scanner) different from the one that is set in the scanner settings? (fi-7300NX)

  • Are the scanner's network settings configured properly?

  • Is the scanner in the middle of the start-up process or the initialization process?

  • Is another application using the scanner?

  • Are the computer's network settings configured properly?

  • Is the operating system on the computer being updated or waiting to be restarted?

  • Is the scanner connected to the same subnetwork as your computer?

  • Are the settings for network devices (such as a switch, hub, or router) correct?

  • Is the communication status between the scanner and the computer stable?

If a scanner is not found after taking the measures above, restart the scanner and computer and then restart Scanner Selection Tool.

If a scanner does not appear in the image scanning application, refer to Cannot Perform a Scan from the Image Scanning Application.

Is the connection method (used to connect the scanner) different from the one that is set in the scanner settings? (fi-7300NX)

Solution

Check that Wi-Fi or a wired LAN is set for the connection method of the scanner.

You can check it as follows.

On the touch screen of the scanner, press → [Scanner Settings] → [How to connect].

Are the scanner's network settings configured properly?

Solution

  • For fi-8040 or fi-7300NX

    Check the network settings of the scanner.

    You can check it as follows.

    On the touch screen of the scanner, press → [Scanner Settings] → [Network].

  • For fi-8950, fi-8930, fi-8820, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150, or fi-8250

    Use IP Address Setting Tool to check the network settings of the scanner.

    For details about how to start IP Address Setting Tool, refer to Starting Up IP Address Setting Tool.

Is the scanner in the middle of the start-up process or the initialization process?

Solution

Check that the scanner is not in the middle of the start-up process or the initialization process.

For details, refer to the Operator's Guide of the scanner.

Is another application using the scanner?

Solution

Exit the other application that is using the scanner.

Are the computer's network settings configured properly?

Solution

Check the computer's network settings.

For details about how to configure the computer's network settings, refer to the manual of your computer.

Is the operating system on the computer being updated or waiting to be restarted?

Solution

Restart Scanner Selection Tool after the operating system on the computer is updated or the computer is restarted.

Is the scanner connected to the same subnetwork as your computer?

Even if the scanner is connected to the same subnetwork as your computer, it may not be found.

Solution

Select [Search from the IP address of the scanner] in the [Scanner Selection Tool] Window and enter the IP address to search for the scanner.

Are the settings for network devices (such as a switch, hub, or router) correct?

Solution

Check the settings for network devices (such as a switch, hub, or router).

For details about how to set the network device, refer to the manual of your network device.

Is the communication status between the scanner and the computer stable?

Solution

  • For fi-8040 or fi-7300NX

    Check the communication status between the scanner and the computer.

    You can check the communication status between the scanner and the computer on the touch screen of the scanner.

    You can check it as follows.

    On the touch screen of the scanner, press → [Scanner Settings] → [Network] → [Check connection (Ping)].

  • For fi-8950, fi-8930, fi-8820, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150, or fi-8250

    Check the communication status between the scanner and the computer.

    Start up the command prompt on your computer, and execute the ping command to check the communication status by specifying the IP address for the scanner.

    Use IP Address Setting Tool to check the IP address for the scanner.

    For details about how to start IP Address Setting Tool, refer to Starting Up IP Address Setting Tool.
