Cannot Perform a Scan by Pressing the Button on the Scanner

Check the following:

  • Is the scanner selected in Scanner Selection Tool?

  • Has Button Event Manager been started?

  • Is [Watch Button Event] selected on the menu of Button Event Manager?

  • Is the settings for the button on the scanner correct?

  • Is the scanner being used by another computer?

Is the scanner selected in Scanner Selection Tool?

Solution

In the [Scanner Selection Tool] Window, check that the scanner is selected.

Has Button Event Manager been started?

Solution

Check that Button Event Manager has been started.

When Button Event Manager has been started, appears in the notification area located at the far right of the task bar.

For details about how to start Button Event Manager, refer to Starting Up Button Event Manager.

Is [Watch Button Event] selected on the menu of Button Event Manager?

Solution

Start Button Event Manager and right-click in the notification area located at the far right of the task bar to display the Menu of Button Event Manager. Check that [Watch Button Event] is selected.

For details about how to start Button Event Manager, refer to Starting Up Button Event Manager.

Is the settings for the button on the scanner correct?

Solution

  • In the [Button Settings] Window of Button Event Manager, check that the button setting is correct.

  • Check that the image scanning application that you specified for the button on the scanner runs on the computer.

Is the scanner being used by another computer?

Solution

When the same scanner has been selected by more than one computer using Scanner Selection Tool, select [Watch Button Event] on the menu of Button Event Manager only on the computer that you want to use the scanner with.

If you cannot start a scan after taking the measures above, perform the following:

  • Exit the image scanning application which resides in the notification area located at the far right of the task bar

  • Turn off the scanner and turn it on again
