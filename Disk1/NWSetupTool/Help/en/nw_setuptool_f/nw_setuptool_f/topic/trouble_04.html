Has a proxy server been set for the WinHTTP proxy setting?

Solution

Change the WinHTTP proxy settings so that you can access the scanner from the computer.

Change the WinHTTP proxy settings in the following procedure.

  1. Start up the command prompt window as a user with Administrator privileges on the computer.

  2. Run the following command to check the proxy server name and port numbers that are to be used.

    netsh winhttp show proxy

    TIP

    The proxy server name and port numbers that are to be used will be displayed as follows.

    "Proxy server name: Port numbers"

  3. Run one of the following commands.

    • When a proxy server has already been set

      Configure the setting so that the computer can access the scanner without the use of the proxy server.

      netsh winhttp set proxy proxy-server="XXXXXX:YYYY" bypass-list=ZZZ.ZZZ.ZZZ.ZZZ

      XXXXXX: Proxy server name

      YYYY: Port numbers to be used

      ZZZ.ZZZ.ZZZ.ZZZ: IP address of the scanner (*1)(*2)

    • When the proxy server has not been set

      If you reset the settings, the computer may be able to access the scanner.

      netsh winhttp reset proxy
*1:

You can check the IP address of a scanner on the touch screen or the operator panel of the scanner or in IP Address Setting Tool.
*2:

The IPv4 address format is used as an example here.

For an IPv6 address, the following format is used.

ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ
