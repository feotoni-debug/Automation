Ventana [Ajustes del botón]

Especifique la aplicación de digitalización de imágenes que desea que se inicie al pulsar un botón del escáner.
Seleccione un evento

En la lista de botones, seleccione un botón para especificar una aplicación de digitalización de imágenes para que se inicie al pulsar un botón del escáner.

CONSEJO

  • Los nombres de botones que se muestran en la lista de botones varían en función del modelo de escáner.

    Para obtener más información, consulte la Guía del usuario del escáner.

  • Si usa Button Event Manager para especificar una aplicación de digitalización de imágenes para el botón de digitalización en un escáner, tenga en cuenta lo siguiente.

    • Cuando PaperStream ClickScan se está ejecutando

      Independientemente de los ajustes configurados para el botón Scan con Button Event Manager, se realiza una digitalización con PaperStream ClickScan al pulsar el botón Scan del escáner.

      Para iniciar otra aplicación de digitalización de imágenes (al pulsar el botón Scan del escáner), salga de PaperStream ClickScan. Para obtener más información, consulte la Ayuda de ClickScan SimpleScan.

    • Cuando PaperStream ClickScan no se está ejecutando y PaperStream Capture está instalado

      Se configura automáticamente PaperStream Capture para el botón Scan del escáner.

      Si no se configura PaperStream Capture para el botón Scan del escáner, seleccione [Ninguno] o [Ejecutar el siguiente programa] en [Operación].

      Para obtener información acerca de cómo configurar un botón del escáner, consulte Configurar los botones del escáner.

Operación
Iniciar [PaperStream Capture]

Seleccione esta opción para iniciar PaperStream Capture.

Los nombres de perfil de documento se muestran en el panel táctil o el panel del operador, en función del escáner que use.

Para obtener más información, consulte la Ayuda de PaperStream Capture.

Ejecutar el siguiente programa

Seleccione esta opción para ejecutar el programa que elija.

Especifique la ruta de un programa para ejecutarlo.

Botón [Examinar]

Muestra la ventana [Seleccione una aplicación].

Especifique un programa para ejecutarlo.

Parámetros

Pueden especificarse un máximo de 255 caracteres para los parámetros.

Para obtener más información acerca de los parámetros, consulte el manual del programa que va a ejecutar.

Ninguno

Seleccione esta opción si desea que no se ejecute ningún programa.

Botón [Aceptar]

Botón [Cancelar]
