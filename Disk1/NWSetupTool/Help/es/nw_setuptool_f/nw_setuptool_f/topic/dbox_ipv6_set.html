Ventana [Ajustes de IPv6]

Establece una dirección IPv6.
Configuración IPv6

Seleccione un método para establecer una dirección IPv6 para el escáner.

  • Automático

    Se asigna automáticamente una dirección IP al escáner procedente del servidor DHCP.

    Este es el ajuste predeterminado de fábrica.

  • Manual

    Asignar una dirección IP manualmente.

  • Deshabilitar

    Deshabilita los ajustes de la dirección IPv6.

Casilla [Recibir paquete RA]

Esta casilla aparece al seleccionar [Manual] en [Configuración IPv6].

Seleccione esto para habilitar una dirección IPv6 generada automáticamente.

Puede comprobar la dirección IPv6 que se ha generado automáticamente en [Dirección IP] en [IPv6] en la ventana [Herramienta de configuración de dirección IP].

La casilla está seleccionada en el ajuste predeterminado de fábrica.

Dirección IP

Introduzca una dirección IP para el escáner al seleccionar [Manual] en [Configuración IPv6].

Longitud del prefijo de subred

Introduzca una longitud del prefijo de subred para la dirección IP al seleccionar [Manual] en [Configuración IPv6].

Se puede introducir un valor entre 3 y 128.

Puerta de enlace predeterminada

Introduzca una puerta de enlace predeterminada para la dirección IP al seleccionar [Manual] en [Configuración IPv6].

Botón [Aceptar]

Cierra la ventana.

Los cambios se aplicarán en la ventana [Herramienta de configuración de dirección IP].

Botón [Cancelar]

Cierra la ventana.

Los cambios no se aplicarán en la ventana [Herramienta de configuración de dirección IP].
