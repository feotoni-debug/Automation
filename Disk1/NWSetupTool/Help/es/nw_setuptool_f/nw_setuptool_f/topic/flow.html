Flujo del funcionamiento

A continuación se muestra el procedimiento de digitalizar documentos utilizando una aplicación de digitalización de imágenes.

  • Realizar una digitalización desde una aplicación de digitalización de imágenes

  • Realizar una digitalización ejecutado una aplicación de digitalización de imágenes desde el botón del escáner

Realizar una digitalización desde una aplicación de digitalización de imágenes

  • Para fi-8040 o fi-7300NX

    1. Configurar la red en la pantalla táctil del escáner

      Para obtener más información, consulte la Guía del usuario del escáner.

    2. Conectar el escáner a la red

      CONSEJO

      Cuendo utilce el fi-7300NX conectado a una red que necesita un certificado mediante Wi-Fi, primero debe registrar el certificado en el escáner. Para obtener información detallada, consulte Registrar certificados en un escáner.

    3. Inicie la Herramienta de selección de escáner para seleccionar el escáner que desea utilizar con un ordenador

      Para obtener detalles, consulte el paso 3 y los pasos siguientes en Selección del escáner que desea utilizar.

    4. En una aplicación de digitalización de imágenes, seleccione el escáner conectado a una LAN por cable o Wi-Fi

      A continuación se muestran los nombres de los escáneres conectados a una LAN por cable o Wi-Fi:

      • Para PaperStream IP (TWAIN)/PaperStream IP (TWAIN x64)

        PaperStream IP xxx Net

      • Pour PaperStream IP (ISIS) fi-8000 Series/PaperStream IP (ISIS) Bundle

        PaperStream_IP xxx Net

      "xxx" indica el nombre de modelo de escáner. Para obtener más detalles, consulte la Ayuda del controlador del escáner.

      CONSEJO

      Con una conexión Wi-Fi, solo se puede usar el fi-7300NX.

    5. Cargue los documentos en un escáner y digitalícelos desde una aplicación de digitalización de imágenes

      Para más detalles sobre cómo cargar documentos, consulte la Guía del usuario del escáner.

      CONSEJO

      Aunque haya seleccionado un escáner con la Herramienta de selección de escáner, es posible que el escáner no se muestre en la aplicación de digitalización de imágenes que se está usando. Para obtener información detallada, consulte No se puede realizar una digitalización desde la aplicación de digitalización de imágenes.

  • Para fi-8950, fi-8930, fi-8820, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 o fi-8250

    1. Conectar el escáner a un dispositivo de red (como un conmutador, un concentrador o un enrutador) con un cable LAN

      Para obtener más información, consulte la Guía del usuario del escáner.

      • Cuando la dirección IP se asigna automáticamente:

        Continúe con el paso siguiente.

      • Cuando la dirección IP se asigna manualmente:

        Inicie la Herramienta de configuración de dirección IP para asignar una dirección IP al escáner.

        Para obtener más información, consulte Cambiar la dirección IP del escáner.

    2. Inicie la Herramienta de selección de escáner para seleccionar el escáner que desea utilizar con un ordenador

      Para obtener detalles, consulte el paso 3 y los pasos siguientes en Selección del escáner que desea utilizar.

    3. En una aplicación de digitalización de imágenes, seleccione el escáner conectado a una LAN por cable

      A continuación se muestran los nombres de los escáneres conectados a una LAN por cable:

      • Para PaperStream IP (TWAIN)/PaperStream IP (TWAIN x64)

        PaperStream IP xxx Net

      • PaperStream IP (ISIS) fi-8000 Series

        PaperStream_IP xxx Net

      "xxx" indica el nombre de modelo de escáner. Para obtener más detalles, consulte la Ayuda del controlador del escáner.

    4. Cargue los documentos en un escáner y digitalícelos desde una aplicación de digitalización de imágenes

      Para más detalles sobre cómo cargar documentos, consulte la Guía del usuario del escáner.

      CONSEJO

      Aunque haya seleccionado un escáner con la Herramienta de selección de escáner, es posible que el escáner no se muestre en la aplicación de digitalización de imágenes que se está usando. Para obtener información detallada, consulte No se puede realizar una digitalización desde la aplicación de digitalización de imágenes.

Realizar una digitalización ejecutado una aplicación de digitalización de imágenes desde el botón del escáner

  • Para fi-8040 o fi-7300NX

    1. Configurar la red en la pantalla táctil del escáner

      Para obtener más información, consulte la Guía del usuario del escáner.

    2. Conectar el escáner a la red

      CONSEJO

      Cuendo utilce el fi-7300NX conectado a una red que necesita un certificado mediante Wi-Fi, primero debe registrar el certificado en el escáner. Para obtener información detallada, consulte Registrar certificados en un escáner.

    3. Inicie la Herramienta de selección de escáner para seleccionar el escáner que desea utilizar con un ordenador

      Para obtener detalles, consulte el paso 3 y los pasos siguientes en Selección del escáner que desea utilizar.

    4. Inicie Button Event Manager y especifique una aplicación de digitalización de imágenes para que se inicie al pulsar el botón del escáner

      Para obtener detalles, consulte el paso 3 y los pasos siguientes en Configurar los botones del escáner.

      ATENCIÓN

      Cuando el escáner esté seleccionado en más de un ordenador al utilizar la herramienta de selección de escáner, seleccione [Evento Mirar el botón] en el menú de Button Event Manager solo en el ordenador en el que quiera utilizar el escáner.

    5. Coloque los documentos en el escáner y pulse el botón del escáner para digitalizarlos

      Para más detalles sobre cómo cargar documentos, consulte la Guía del usuario del escáner.
