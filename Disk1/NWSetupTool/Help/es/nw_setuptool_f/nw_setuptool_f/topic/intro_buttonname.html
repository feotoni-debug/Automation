Nombres usados para botones del escáner en esta ayuda

A continuación se explican los nombres que se usan en esta ayuda para los botones del escáner.

Botones del escáner

Se trata de un término general para botones del escáner que se pueden configurar para que realicen una tarea en particular mediante Button Event Manager.

Los botones del escáner que se pueden configurar para realizar una tarea concreta mediante Button Event Manager pueden variar según el modelo de escáner.

Los botones del escáner conectado que se pueden configurar para realizar una tarea en particular se muestran en "Seleccione un evento" en la Ventana [Ajustes del botón].

Botón Scan del escáner

Se trata de un término general para un botón del escáner que incluye la palabra "Scan", como el botón [Scan/Enter] o el botón [Scan/Stop].

El nombre del botón para digitalizar en un escáner varía según el modelo de escáner. Para obtener más información, consulte la Guía del usuario del escáner.
