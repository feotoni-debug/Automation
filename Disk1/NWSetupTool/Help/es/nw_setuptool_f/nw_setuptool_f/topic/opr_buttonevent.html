Configurar los botones del escáner

En esta sección se explica cómo usar Button Event Manager y especificar una aplicación de digitalización de imágenes para que se inicie al pulsar un botón del escáner.

ATENCIÓN

Cuando el escáner esté seleccionado en más de un ordenador al utilizar la herramienta de selección de escáner, seleccione [Evento Mirar el botón] en el menú de Button Event Manager solo en el ordenador en el que quiera utilizar el escáner.

CONSEJO

Si usa Button Event Manager para especificar una aplicación de digitalización de imágenes para el botón de digitalización en un escáner, tenga en cuenta lo siguiente.

  • Cuando PaperStream ClickScan se está ejecutando

    Independientemente de los ajustes configurados para el botón Scan con Button Event Manager, se realiza una digitalización con PaperStream ClickScan al pulsar el botón Scan del escáner.

    Para iniciar otra aplicación de digitalización de imágenes (al pulsar el botón Scan del escáner), salga de PaperStream ClickScan. Para obtener más información, consulte la Ayuda de ClickScan SimpleScan.

  • Cuando PaperStream ClickScan no se está ejecutando y PaperStream Capture está instalado

    Se configura automáticamente PaperStream Capture para el botón Scan del escáner.

    Si no se configura PaperStream Capture para el botón Scan del escáner, seleccione [Ninguno] o [Ejecutar el siguiente programa] en [Operación] en Ventana [Ajustes del botón].

  1. Conecte el escáner a la red.

    Para obtener más información, consulte la Guía del usuario del escáner.

  2. Habilite el escáner que se va a seleccionar en una aplicación de digitalización de imágenes.

    Inicie la Herramienta de selección de escáner y seleccione el escáner que utilizará de entre los escáneres conectados a la red.

    Para obtener más información, consulte Selección del escáner que desea utilizar.

  3. Configure los ajustes de digitalización en la aplicación de digitalización de imágenes.

    Para obtener más información, consulte el manual de la aplicación de digitalización de imágenes.

  4. Inicie Button Event Manager.

    Para obtener más información, consulte Iniciar Button Event Manager.

    Cuando se inicia Button Event Manager, aparece en el área de notificaciones ubicada en el lado derecho de la barra de tareas.

  5. Haga clic con el botón derecho en .

    Aparece la Menú de Button Event Manager.

  6. Seleccione [Evento Mirar el botón] en el menú.
  7. Haga clic en [Ajustes de la configuración del botón] en el menú.

    Aparece la Ventana [Ajustes del botón].

  8. Especifique una aplicación de digitalización de imágenes para que se inicie al pulsar un botón del escáner.

    Para obtener detalles sobre la configuración, consulte Ventana [Ajustes del botón].

  9. Haga clic en el botón [Aceptar].
