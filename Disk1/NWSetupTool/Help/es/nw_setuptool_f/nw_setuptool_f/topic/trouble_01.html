Si no se encuentran escáneres después de tomar las medidas anteriores, reinicie el escáner y el ordenador y después reinicie la Herramienta de selección de escáner.

Si un escáner no aparece en la aplicación de digitalización de imágenes, consulte No se puede realizar una digitalización desde la aplicación de digitalización de imágenes.

¿El método de conexión (usado para conectarse al escáner) es diferente del que está configurado en los ajustes del escáner? (fi-7300NX)

Solución

Compruebe que ha configurado Wi-Fi o una LAN con cable como método de conexión del escáner.

Puede comprobarlo siguiendo los pasos descritos a continuación.

En la pantalla táctil del escáner, pulse → [Ajustes del escáner] → [Método de conexión].

¿Están configurados correctamente los ajustes de red del escáner?

Solución

  • Para fi-8040 o fi-7300NX

    Compruebe la configuración de red del escáner.

    Puede comprobarlo siguiendo los pasos descritos a continuación.

    En la pantalla táctil del escáner, pulse → [Ajustes del escáner] → [Red].

  • Para fi-8950, fi-8930, fi-8820, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 o fi-8250

    Utilice la Herramienta de configuración de dirección IP para comprobar la configuración de red del escáner.

    Para obtener detalles sobre cómo iniciar la Herramienta de configuración de dirección IP, consulte Iniciar la Herramienta de configuración de dirección IP.

¿El escáner se encuentra en pleno proceso de inicio o inicialización?

Solución

Compruebe que el escáner no se encuentra en pleno proceso de inicio o inicialización.

Para obtener más información, consulte la Guía del usuario del escáner.

¿Hay otra aplicación que esté utilizando el escáner?

Solución

Salga de otra aplicación que esté utilizando el escáner.

¿Están configurados correctamente los ajustes de red del ordenador?

Solución

Compruebe los ajustes de red del ordenador.

Para obtener más detalles sobre cómo configurar los ajustes de red del ordenador, consulte el manual del ordenador.

¿Se está actualizando el sistema operativo del ordenador o está esperando para reiniciarse?

Solución

Reinicie la Herramienta de selección de escáner después de haber actualizado el sistema operativo o de haber reiniciado el ordenador.

¿Están el escáner y el ordenador conectados a la misma subred?

Es posible que no se detecte el escáner aunque esté conectado a la misma subred que el ordenador.

Solución

Seleccione [Buscar desde la dirección IP del escáner] en la Ventana [Herramienta de selección de escáner] e introduzca la dirección IP para buscar el escáner.

¿Son correctos los ajustes de los dispositivos de red (como un conmutador, hub o router)?

Solución

Compruebe los ajustes de los dispositivos de red (como un conmutador, hub o router).

Para obtener información acerca de la configuración del dispositivo de red, consulte el manual del dispositivo de red.

¿Es estable el estado de la comunicación entre el escáner y el ordenador?

Solución

  • Para fi-8040 o fi-7300NX

    Compruebe el estado de la comunicación entre el escáner y el ordenador.

    Puede comprobar el estado de comunicación entre el escáner y el ordenador en la pantalla táctil del escáner.

    Puede comprobarlo siguiendo los pasos descritos a continuación.

    En la pantalla táctil del escáner, pulse → [Ajustes del escáner] → [Red] → [Comprobar conexión (Ping)].

  • Para fi-8950, fi-8930, fi-8820, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 o fi-8250

    Compruebe el estado de la comunicación entre el escáner y el ordenador.

    Inicie el símbolo del sistema del ordenador y ejecute el comando ping para comprobar el estado de comunicación especificando la dirección IP del escáner.

    Utilice la Herramienta de configuración de dirección IP para comprobar la configuración IP del escáner.

    Para obtener detalles sobre cómo iniciar la Herramienta de configuración de dirección IP, consulte Iniciar la Herramienta de configuración de dirección IP.
