¿Se ha configurado un servidor proxy para el ajuste de proxy WinHTTP?

Solución

Cambie la configuración del proxy WinHTTP para que pueda acceder al escáner desde el ordenador.

Cambie la configuración del proxy WinHTTP mediante el siguiente procedimiento.

  1. Inicie la ventana del símbolo del sistema como usuario con privilegios de administrador en el ordenador.

  2. Ejecute el siguiente comando para comprobar el nombre del servidor proxy y los números de puerto que se van a usar.

    netsh winhttp show proxy

    CONSEJO

    A continuación se mostrará el nombre del servidor proxy y los números de puerto que se van a usar.

    "Nombre del servidor proxy: Números de puerto"

  3. Ejecute uno de los siguientes comandos.

    • Cuando ya se ha configurado un servidor proxy

      Configure los ajustes para que el ordenador pueda acceder al escáner sin usar el servidor proxy.

      netsh winhttp set proxy proxy-server="XXXXXX:YYYY" bypass-list=ZZZ.ZZZ.ZZZ.ZZZ

      XXXXXX: nombre del servidor proxy

      YYYY: números de puertos que se usarán

      ZZZ.ZZZ.ZZZ.ZZZ: Dirección IP del escáner (*1)(*2)

    • Cuando no se ha configurado el servidor proxy

      Si restablece la configuración, es posible que el ordenador pueda tener acceso al escáner.

      netsh winhttp reset proxy
*1:

Puede comprobar la dirección IP del escáner en la pantalla táctil o el panel del operador del escáner o la Herramienta de configuración de dirección IP.
*2:

Aquí se muestra como ejemplo un formato de la dirección IPv4.

Para una dirección Ipv6, se utiliza el siguiente formato.

ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ
