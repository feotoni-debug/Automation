Fenêtre [Paramètres du bouton]

Spécifiez l'application de numérisation d'image à démarrer lorsque vous appuyez sur une touche du scanneur.
Sélectionner un événement

Dans la liste des touches, sélectionnez une touche pour spécifier l'application de numérisation d'image à démarrer lorsque vous appuyez sur cette touche sur le scanneur.

CONSEIL

  • Les noms des touches indiqués dans la liste des touches varient en fonction du modèle de scanneur.

    Pour en savoir plus, consultez le Guide d'utilisation du scanneur.

  • Si vous utilisez Button Event Manager pour spécifier une application de numérisation d'image pour la touche de numérisation d'un scanneur, prenez note de ce qui suit.

    • Lors de l'exécution de PaperStream ClickScan

      Quels que soient les paramètres configurés pour la touche de numérisation à l'aide de Button Event Manager, une numérisation est lancée avec PaperStream ClickScan lorsque vous appuyez sur la touche de numérisation du scanneur.

      Pour démarrer une autre application de numérisation d'image (en appuyant sur la touche de numérisation du scanneur), quittez PaperStream ClickScan. Pour en savoir plus, consultez les rubriques d'aide de PaperStream ClickScan.

    • Si PaperStream ClickScan n'est pas exécuté et que PaperStream Capture est installé

      PaperStream Capture est automatiquement attribué à la touche de numérisation du scanneur.

      Si vous n'attribuez pas PaperStream Capture à la touche de numérisation du scanneur, sélectionnez [Aucune] ou [Exécuter le programme suivant] dans [Opération].

      Pour en savoir plus sur l'attribution d'une touche sur le scanneur, reportez-vous à la rubrique Configuration des paramètres des touches du scanneur.

Opération
Lancer [PaperStream Capture]

Sélectionnez cette option pour démarrer PaperStream Capture.

Les noms des profils de documents s'affichent sur l'écran tactile du panneau de commande en fonction du scanneur que vous utilisez.

Pour en savoir plus, consultez les rubriques d'aide de PaperStream Capture.

Exécuter le programme suivant

Sélectionnez cette option pour exécuter le programme de votre choix.

Indiquez le chemin d'accès au programme à exécuter.

Bouton [Parcourir]

Affiche la fenêtre [Sélectionner une application].

Spécifiez un programme à exécuter.

Paramètres

Vous pouvez spécifier jusqu'à 255 caractères pour les paramètres.

Pour plus de détails sur les paramètres, consultez le guide du programme à exécuter.

Aucune

Sélectionnez cette option pour n'exécuter aucun programme.

Bouton [OK]

Ce bouton permet de fermer la fenêtre.

Les modifications sont enregistrées.

Bouton [Annuler]

Ce bouton permet de fermer la fenêtre.

Les modifications ne sont pas enregistrées.
