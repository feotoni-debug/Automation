Menu de Button Event Manager

Les options de menu suivantes s'affichent lorsque vous cliquez avec le bouton droit de la souris dans la zone de notification située à l'extrémité droite de la barre des tâches.
Afficher l'événement de bouton

Cette option détecte le mouvement descendant de la touche de numérisation du scanneur.

Si vous ne sélectionnez pas cette option, l'application de numérisation d'image que vous avez spécifiée dans la Fenêtre [Paramètres du bouton] ne démarre pas lorsque vous appuyez sur la touche de numérisation du scanneur.

IMPORTANT

Lorsque le même scanner a été sélectionné par plusieurs ordinateurs à l'aide de l'outil de sélection du scanneur, sélectionnez [Afficher l'événement de bouton] uniquement sur l'ordinateur avec lequel vous souhaitez utiliser le scanner.

CONSEIL

Pour démarrer le Software Operation Panel en appuyant sur la touche de numérisation du scanneur, sélectionnez [Afficher l'événement de bouton].

Pour en savoir plus sur le fonctionnement d'un scanneur lorsque vous appuyez sur la touche de numérisation du scanneur, consultez le Guide d'utilisation du scanneur.

Lancer cet outil lors de la connexion

Si vous sélectionnez cette option, Button Event Manager démarre lorsque vous vous connectez à Windows.

Une fois Button Event Manager démarré, un message de notification apparaît dans la zone de notification située à l'extrémité droite de la barre des tâches.

Configurer les paramètres du bouton

Spécifiez l'application de numérisation d'image à démarrer lorsque vous appuyez sur la touche de numérisation du scanneur.

La Fenêtre [Paramètres du bouton] s'affiche.

Aide

Cette option permet d'afficher l'aide.

A propos

Cette option permet d'afficher les informations sur la version.

Quitter

Cette option permet de quitter Button Event Manager.
