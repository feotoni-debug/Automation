Fenêtre [Outil de configuration de l'adresse IP]

Vérifiez les paramètres réseau d'un scanneur.
Nom du scanneur

Saisissez un nom de scanneur comprenant maximum 64 caractères.

Les caractères suivants sont disponibles :

  • Caractères alphanumériques

  • - (tiret)

  • _ (trait de soulignement)

  • Espaces

    Notez que les espaces au début et à la fin d'un nom sont supprimés.

Le paramètre par défaut correspond au nom du modèle et au numéro de série du scanneur (Nom du modèle - Numéro de série).

CONSEIL

  • Le numéro de série du scanneur est imprimé sur l'étiquette.

    Pour en savoir plus, consultez le Guide d'utilisation du scanneur.

  • Si vous activez [DNS dynamique] dans les paramètres du scanneur, saisissez un nom de scanneur d'une longueur de 63 caractères maximum.

    Pour en savoir plus le DNS dynamique, consultez le Guide d'utilisation du scanneur.

    Il est recommandé de ne pas utiliser les caractères demi-chasse suivants lors de l'enregistrement d'un nom de scanneur sur le serveur DNS car les caractères seront convertis en "-" (tiret).

    • Espaces

Réseau

Les paramètres réseau d'un scanneur s'affichent.

Adresse MAC

L'adresse MAC d'un scanneur s'affiche.

IPv4
Configuration Ipv4

Sélectionnez une méthode pour définir l'adresse IPv4 d'un scanneur.

  • Automatique

    Une adresse IP est automatiquement attribuée à un scanneur via le serveur DHCP.

    Il s'agit de la configuration d'usine par défaut.

  • Manuelle

    Attribuez une adresse IP manuellement.

Adresse IP

L'adresse IP d'un scanneur s'affiche.

Saisissez l'adresse IP d'un scanneur lorsque vous sélectionnez [Manuelle] dans [Configuration Ipv4].

Masque de sous réseau

Affiche le masque de sous-réseau pour l'adresse IP.

Saisissez le masque de sous réseau de l'adresse IP lorsque vous sélectionnez [Manuelle] dans [Configuration Ipv4].

Passerelle par défaut

Affiche la passerelle par défaut pour l'adresse IP.

Saisissez la passerelle par défaut de l'adresse IP lorsque vous sélectionnez [Manuelle] dans [Configuration Ipv4].

IPv6
Adresse IP

Affiche l'adresse IP et la longueur du préfixe de sous-réseau d'un scanner.

Passerelle par défaut

Affiche la passerelle par défaut pour l'adresse IP.

Bouton [Paramètres IPv6]

Affiche la Fenêtre [Paramètres de IPv6].

Configurer une adresse IPv6.

Sécurité
Cryptage réseau

Indiquez si vous souhaitez chiffrer les communications réseau.

Cryptage désactivé (HTTP)

Il s'agit d'une méthode de transmission qui privilégie la vitesse de numérisation.

Il s'agit de la configuration d'usine par défaut.

Cryptage activé (HTTPS)

Il s'agit d'une méthode de transmission qui privilégie la sécurité.

Notez que la vitesse de numérisation peut ralentir.
