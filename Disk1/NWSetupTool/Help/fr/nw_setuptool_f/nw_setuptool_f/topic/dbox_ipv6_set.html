Fenêtre [Paramètres de IPv6]

Configurer une adresse IPv6.
Configuration Ipv6

Sélectionnez une méthode pour définir l'adresse IPv6 d'un scanneur.

  • Automatique

    Une adresse IP est automatiquement attribuée à un scanneur via le serveur DHCP.

    Il s'agit de la configuration d'usine par défaut.

  • Manuelle

    Attribuez une adresse IP manuellement.

  • Désactiver

    Désactivez les paramètres de l'adresse IPv6.

Case à cocher [Recevoir le paquet RA]

Cette case à cocher apparaît lorsque vous sélectionnez [Manuelle] dans [Configuration Ipv6].].

Cochez cette case pour activer une adresse IPv6 qui a été générée automatiquement.

Vous pouvez cocher une adresse IPv6 qui a été générée automatiquement dans [Adresse IP] sous [IPv6] dans la fenêtre [Outil de configuration de l'adresse IP].

La case à cocher est sélectionnée pour le paramètre par défaut.

Adresse IP

Saisissez l'adresse IP d'un scanneur lorsque vous sélectionnez [Manuelle] dans [Configuration Ipv6].

Longueur du préfixe de sous-réseau

Saisissez la longueur du préfixe de sous-réseau de l'adresse IP lorsque vous sélectionnez [Manuelle] dans [Configuration Ipv6].

Une valeur de 3 à 128 peut être saisie.

Passerelle par défaut

Saisissez la passerelle par défaut de l'adresse IP lorsque vous sélectionnez [Manuelle] dans [Configuration Ipv6].

Bouton [OK]

Ce bouton permet de fermer la fenêtre.

Les modifications sont appliquées à la fenêtre [Outil de configuration de l'adresse IP].

Bouton [Annuler]

Ce bouton permet de fermer la fenêtre.

Les modifications ne sont pas appliquées à la fenêtre [Outil de configuration de l'adresse IP].
