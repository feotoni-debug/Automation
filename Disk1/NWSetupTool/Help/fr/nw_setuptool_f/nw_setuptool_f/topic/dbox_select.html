Fenêtre [Outil de sélection du scanneur]

Parmi les scanneurs connectés à un réseau, sélectionnez celui que vous souhaitez utiliser à partir de votre ordinateur.
Voulez-vous utiliser un scanneur à partir d'une application ?

Cette option permet d'afficher l'aide.

Liste de scanneurs

Des informations concernant les scanneurs détectés s'affichent.

Lorsque vous lancez Outil de sélection du scanneur, cet outil recherche automatiquement les scanners dans la plage de recherche définie pour [Rechercher une méthode pour le scanneur], et affiche les noms de modèle, les noms de scanner ainsi que les adresses IP des scanners trouvés.

Cliquez sur le nom du scanneur à utiliser pour à partir de votre ordinateur afin de sélectionner cette case à cocher. Vous ne pouvez sélectionner qu'un seul scanneur.

Si un scanneur est déjà sélectionné, il apparaît en haut de la liste de scanneurs.

Lorsque vous n'utilisez pas le scanneur connecté au réseau, cliquez sur le nom du scanneur sélectionné pour supprimer la coche.

CONSEIL

  • Vous pouvez également double cliquer sur un scanneur dans la liste de scanneurs pour le sélectionner.

    Lorsque vous double-cliquez sur le scanneur, celui-ci devient disponible et l'Outil de sélection du scanneur se ferme.

  • Pour le modèle fi-8950, fi-8930, fi-8820, fi-8040, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 ou fi-8250, cliquer sur une adresse IP affichée dans [Adresse IP] sur la liste de scanneurs permet de démarrer les Paramètres réseau de fi Series (sur un navigateur Web).

    Pour plus de détails sur les Paramètres réseau de fi Series (sur un navigateur Web), reportez-vous au Guide de l'opérateur' du scanner.

  • Lorsqu'un scanner a déjà été sélectionné et que vous démarrez Scanner Selection Tool ou cliquez sur le bouton [Nouvelle recherche] dans la fenêtre [Outil de sélection du scanneur] dans l'un des états suivants, sera ajouté au scanner sélectionné au lieu de .

    • Le scanner sélectionné n'est pas connecté à un réseau
    • Le scanner sélectionné est éteint

    • Une valeur qui ne recherchera pas le scanner sélectionné a été spécifiée dans [Plage de recherche] sous [Rechercher une méthode pour le scanneur]

      Dans ce cas, si le scanner sélectionné est connecté à un réseau, vous pouvez utiliser le scanner tel quel.

Rechercher une méthode pour le scanneur
Plage de recherche
IPv4

Recherche les scanners qui sont connectés au même sous-réseau que votre ordinateur à l'aide d'une adresse IPv4.

Il s'agit de la configuration d'usine par défaut.

IPv6

Recherche les scanners qui sont connectés au même sous-réseau que votre ordinateur en utilisant une adresse IPv6.

Pour le modèle fi-8950, fi-8930, fi-8820, fi-8040, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 ou fi-8250, vous pouvez sélectionner cette option pour rechercher des scanneurs.

Saisissez une adresse IP

Sélectionnez cette option pour rechercher un scanneur en spécifiant son adresse IP ou pour utiliser un scanneur connecté à un sous-réseau autre que celui auquel l'ordinateur est connecté.

Saisissez une adresse IP dans les champs de saisie.

Saisissez un nom

Sélectionnez cette option pour rechercher un scanner en spécifiant le nom d'un scanner enregistré sur le serveur DNS.

CONSEIL

Le nom d'un scanner doit être un nom enregistré sur le serveur DNS.

Saisissez un nom de 255 caractères maximum dans le champ de saisie.

Les caractères suivants sont disponibles :

  • Caractères alphanumériques

  • - (tiret)

  • . (Période)

Bouton [Nouvelle recherche]

Ce bouton permet de lancer une recherche sur un scanneur.

Vous ne trouvez pas le scanneur que vous recherchez ?

Cette option permet d'afficher l'aide.

Bouton [Configurer une adresse IP]

Ce bouton permet de démarrer l'Outil de configuration de l'adresse IP.

Si le scanneur que vous souhaitez utiliser à partir de votre ordinateur est introuvable, cliquez sur ce bouton pour vérifier le nom du scanneur ou l'adresse IP du scanneur.

Pour utiliser l'Outil de configuration de l'adresse IP, vous devez connecter le scanneur à votre ordinateur via le câble USB.

Bouton [OK]

Ce bouton permet de quitter l'Outil de sélection du scanneur.

Les modifications sont enregistrées.

Bouton [Annuler]

Ce bouton permet de quitter l'Outil de sélection du scanneur.

Les modifications ne sont pas enregistrées.
