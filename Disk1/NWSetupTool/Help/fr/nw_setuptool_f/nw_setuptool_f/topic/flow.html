Flux d'opérations

Voici le flux d'opérations lors de l'utilisation d'une application de numérisation d'images pour numériser des documents.

  • Démarrage d'une numérisation à partir d'une application de numérisation d'images

  • Démarrage d'une numérisation en exécutant une application de numérisation d'images via la touche d'un scanneur

Démarrage d'une numérisation à partir d'une application de numérisation d'images

  • Pour fi-8040 ou fi-7300NX

    1. Configurez les paramètres réseau sur l'écran tactile du scanneur

      Pour en savoir plus, consultez le Guide d'utilisation du scanneur.

    2. Connecter le scanneur à un réseau

      CONSEIL

      Lorsque vous utilisez le fi-7300NX connecté à un réseau nécessitant un certificat via Wi-Fi, le certificat doit être préalablement enregistré sur le scanner. Pour en savoir plus, consultez la section Enregistrement de certificats sur le scanneur.

    3. Démarrez l'Outil de sélection du scanneur pour sélectionner le scanneur à utiliser à partir d'un ordinateur

      Pour en savoir plus, consultez l'étape 3 et les étapes suivantes de la section Sélection d'un scanneur à utiliser.

    4. Dans une application de numérisation d'images, sélectionnez le scanner connecté à un réseau LAN câblé ou Wi-Fi

      Les noms des scanners connectés à un réseau LAN câblé ou Wi-Fi sont les suivants :

      • Pour PaperStream IP (TWAIN)/PaperStream IP (TWAIN x64)

        PaperStream IP xxx Net

      • Pour PaperStream IP (ISIS) fi-8000 Series/PaperStream IP (ISIS) Bundle

        PaperStream_IP xxx Net

      "xxx" indique le nom de modèle du scanneur. Pour en savoir plus, consultez les rubriques d'aide du pilote du scanneur.

      CONSEIL

      Seul le fi-7300NX peut être utilisé avec une connexion Wi-Fi.

    5. Chargez les documents dans un scanneur et numérisez-les à partir d'une application de numérisation d'images

      Pour en savoir plus sur le chargement de documents, consultez le Guide d'utilisation du scanneur.

      CONSEIL

      Même si vous sélectionnez un scanneur avec l'Outil de sélection du scanneur, il est possible que le scanneur n'apparaisse pas dans l'application de numérisation d'image en cours d'utilisation. Pour en savoir plus, reportez-vous à la rubrique Impossible de lancer une numérisation depuis l'application de numérisation d'image.

  • Pour fi-8950, fi-8930, fi-8820, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 ou fi-8250

    1. Connectez un scanneur à un périphérique réseau (par exemple un commutateur, un concentrateur ou un routeur) avec un câble LAN

      Pour en savoir plus, consultez le Guide d'utilisation du scanneur.

      • Lors de l'attribution automatique d'une adresse IP

        Passez à l'étape suivante.

      • Lors de l'attribution manuelle d'une adresse IP

        Démarrez l'Outil de configuration de l'adresse IP pour attribuer une adresse IP à un scanneur.

        Pour en savoir plus, consultez la section Modification de l'adresse IP d'un scanneur.

    2. Démarrez l'Outil de sélection du scanneur pour sélectionner le scanneur à utiliser à partir d'un ordinateur

      Pour en savoir plus, consultez l'étape 3 et les étapes suivantes de la section Sélection d'un scanneur à utiliser.

    3. Dans une application de numérisation d'images, sélectionnez le scanneur pour une connexion au réseau LAN câblé

      Les noms des scanneurs pour une connexion de réseau LAN câblé sont les suivants :

      • Pour PaperStream IP (TWAIN)/PaperStream IP (TWAIN x64)

        PaperStream IP xxx Net

      • Pour PaperStream IP (ISIS) fi-8000 Series

        PaperStream_IP xxx Net

      "xxx" indique le nom de modèle du scanneur. Pour en savoir plus, consultez les rubriques d'aide du pilote du scanneur.

    4. Chargez les documents dans un scanneur et numérisez-les à partir d'une application de numérisation d'images

      Pour en savoir plus sur le chargement de documents, consultez le Guide d'utilisation du scanneur.

      CONSEIL

      Même si vous sélectionnez un scanneur avec l'Outil de sélection du scanneur, il est possible que le scanneur n'apparaisse pas dans l'application de numérisation d'image en cours d'utilisation. Pour en savoir plus, reportez-vous à la rubrique Impossible de lancer une numérisation depuis l'application de numérisation d'image.

Démarrage d'une numérisation en exécutant une application de numérisation d'images via la touche d'un scanneur

    1. Configurez les paramètres réseau sur l'écran tactile du scanneur

      Pour en savoir plus, consultez le Guide d'utilisation du scanneur.

    2. Connecter le scanneur à un réseau

      CONSEIL

      Lorsque vous utilisez le fi-7300NX connecté à un réseau nécessitant un certificat via Wi-Fi, le certificat doit être préalablement enregistré sur le scanner. Pour en savoir plus, consultez la section Enregistrement de certificats sur le scanneur.

    3. Démarrez l'Outil de sélection du scanneur pour sélectionner le scanneur à utiliser à partir d'un ordinateur

      Pour en savoir plus, consultez l'étape 3 et les étapes suivantes de la section Sélection d'un scanneur à utiliser.

    4. Démarrez Button Event Manager et spécifiez l'application de numérisation d'image à démarrer lorsque vous appuyez sur la touche du scanneur

      Pour en savoir plus, consultez l'étape 3 et les étapes suivantes de la section Configuration des paramètres des touches du scanneur.

      IMPORTANT

      Lorsque le même scanner a été sélectionné par plusieurs ordinateurs à l'aide de l'outil de sélection du scanneur, sélectionnez [Afficher l'événement de bouton] dans le menu de Button Event Manager uniquement sur l'ordinateur avec lequel vous souhaitez utiliser le scanner.

    5. Chargez des documents dans le scanneur, puis appuyez sur la touche du scanneur pour numériser les documents

      Pour en savoir plus sur le chargement de documents, consultez le Guide d'utilisation du scanneur.
