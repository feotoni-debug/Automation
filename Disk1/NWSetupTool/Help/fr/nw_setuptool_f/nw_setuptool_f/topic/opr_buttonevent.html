Configuration des paramètres des touches du scanneur

Cette section vous explique comment utiliser Button Event Manager et spécifier l'application de numérisation d'image à démarrer lorsque vous appuyez sur une touche du scanneur.

IMPORTANT

Lorsque le même scanner a été sélectionné par plusieurs ordinateurs à l'aide de l'outil de sélection du scanneur, sélectionnez [Afficher l'événement de bouton] dans le menu de Button Event Manager uniquement sur l'ordinateur avec lequel vous souhaitez utiliser le scanner.

CONSEIL

Si vous utilisez Button Event Manager pour spécifier une application de numérisation d'image pour la touche de numérisation d'un scanneur, prenez note de ce qui suit.

  • Lors de l'exécution de PaperStream ClickScan

    Quels que soient les paramètres configurés pour la touche de numérisation à l'aide de Button Event Manager, une numérisation est lancée avec PaperStream ClickScan lorsque vous appuyez sur la touche de numérisation du scanneur.

    Pour démarrer une autre application de numérisation d'image (en appuyant sur la touche de numérisation du scanneur), quittez PaperStream ClickScan. Pour en savoir plus, consultez les rubriques d'aide de PaperStream ClickScan.

  • Si PaperStream ClickScan n'est pas exécuté et que PaperStream Capture est installé

    PaperStream Capture est automatiquement attribué à la touche de numérisation du scanneur.

    Si vous n'attribuez pas PaperStream Capture à la touche de numérisation du scanneur, sélectionnez [Aucune] ou [Exécuter le programme suivant] pour [Opération] dans Fenêtre [Paramètres du bouton].

  1. Connectez le scanneur à un réseau.

    Pour en savoir plus, consultez le Guide d'utilisation du scanneur.

  2. Activez la sélection du scanneur dans une application de numérisation d'images.

    Démarrez l'Outil de sélection du scanneur et sélectionnez le scanneur à utiliser parmi les scanneurs connectés à un réseau.

    Pour en savoir plus, consultez la section Sélection d'un scanneur à utiliser.

  3. Configurez les paramètres de numérisation dans l'application de numérisation d'images.

    Pour en savoir plus, consultez le guide de l'application de numérisation d'image.

  4. Démarrez Button Event Manager.

    Pour en savoir plus, consultez la section Démarrage de Button Event Manager.

    Une fois Button Event Manager démarré, apparaît dans la zone de notification située à l'extrémité droite de la barre des tâches.

  5. Cliquez avec le bouton droit sur .

    La Menu de Button Event Manager s'affiche.

  6. Sélectionnez [Afficher l'événement de bouton] dans le menu.
  7. Cliquez sur [Configurer les paramètres du bouton] dans le menu.

    La Fenêtre [Paramètres du bouton] s'affiche.

  8. Spécifiez l'application de numérisation d'image à démarrer lorsque vous appuyez sur la touche de numérisation du scanneur.

    Pour en savoir plus sur les paramètres, reportez-vous à la section Fenêtre [Paramètres du bouton].

  9. Cliquez sur le bouton [OK].
