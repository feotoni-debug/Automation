Enregistrer un certificat

Cette section vous explique comment utiliser l'Outil d'enregistrement de certificats pour enregistrer un certificat sur le scanneur.

Pour connecter le scanneur à un réseau nécessitant un certificat via Wi-Fi, enregistrez au préalable ce certificat sur le scanneur.

Les certificats pouvant être enregistrés sont les suivants :

  • Certificats client: fichier au format PKCS#12 (*.p12, *.pfx)

  • Certificats CA: fichier de certificat CA (*.cer, *.crt, *.der, *.pem)

  1. Démarrez l'Outil d'enregistrement de certificats.

    Pour en savoir plus, reportez-vous à la rubrique Démarrage de l'Outil d'enregistrement de certificats.

    La Fenêtre [Outil d'enregistrement de certificats] s'affiche.

  2. Connectez le scanneur à un ordinateur à l'aide du câble USB fourni avec le scanneur, puis cliquez sur le bouton [Configurer] dans la fenêtre [Outil d'enregistrement des certificats].

    La Fenêtre Paramètres du certificat s'affiche.

    IMPORTANT

    Si vous déconnectez puis connectez le câble USB alors que la fenêtre des paramètres de certificat est affichée, vous ne pouvez pas enregistrer un certificat.

    Fermez la fenêtre des paramètres du certificat, puis cliquez à nouveau sur le bouton [Configurer] dans la fenêtre [Outil d'enregistrement des certificats].

  3. Sélectionnez un onglet pour le certificat que vous souhaitez enregistrer ([Certificats de client] ou [Certificats CA]), puis cliquez sur le bouton [Enregistrer].

    Lorsque vous cliquez sur l'onglet [Certificats de client], la Fenêtre [Enregistrement du certificat] (Certificats de client) s'affiche.

    Lorsque vous cliquez sur l'onglet [Certificats CA], la Fenêtre [Enregistrement du certificat] (Certificats CA) s'affiche.

  4. Spécifiez le certificat que vous souhaitez enregistrer.

    Pour enregistrer un certificat de client, saisissez le mot de passe du certificat.

  5. Cliquez sur le bouton [OK].

    Le certificat est enregistré sur le scanneur.

    Le certificat est ajouté à un onglet dédié ([Certificats de client] ou [Certificats CA]) dans la fenêtre Paramètres du certificat.

  6. Cliquez sur le bouton [OK].
  7. Débranchez le câble USB du scanneur.
  8. Éteignez le scanneur, puis rallumez-le.
    CONSEIL

    Lorsque vous essayez d'éteindre le scanneur, le message "En cours de fonctionnement..." peut rester affiché sur l'écran tactile du scanneur. Même si cela se produit, l'extinction du scanneur ne devrait pas être un problème.
