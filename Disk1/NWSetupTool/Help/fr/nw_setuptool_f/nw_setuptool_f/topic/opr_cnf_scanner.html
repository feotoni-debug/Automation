Sélection d'un scanneur à utiliser

Cette section vous explique comment utiliser l'Outil de sélection du scanneur pour sélectionner le scanneur à utiliser avec un ordinateur.
  1. Connectez le scanneur à un réseau.

    Pour en savoir plus, consultez le Guide d'utilisation du scanneur.

  2. Démarrez l'Outil de sélection du scanneur.

    Pour en savoir plus, consultez la section Démarrage de l'Outil de sélection du scanneur.

    La Fenêtre [Outil de sélection du scanneur] s'affiche.

    CONSEIL

    Lorsque vous lancez Outil de sélection du scanneur, cet outil recherche automatiquement les scanners dans la plage de recherche définie pour [Rechercher une méthode pour le scanneur].

  3. Dans la liste de scanneurs, sélectionnez le scanneur à utiliser à partir d'un ordinateur.

    Une coche apparaît en regard du scanneur sélectionné.

    CONSEIL

    Si le scanneur que vous souhaitez utiliser ne figure pas dans la liste de scanneurs, recherchez-le en procédant comme suit.

    • Si le scanneur est connecté au même sous-réseau que celui auquel est connecté l'ordinateur

      Sélectionnez [IPv4] ou [IPv6] dans [Plage de recherche] sous [Rechercher une méthode pour le scanneur], puis cliquez sur le bouton [Nouvelle recherche]

    • Si le scanneur est connecté à un sous-réseau différent de celui auquel est connecté l'ordinateur

      Sélectionnez [Saisissez une adresse IP] ou [Saisissez un nom] dans [Plage de recherche] sous [Rechercher une méthode pour le scanneur], et entrez l'adresse IP ou le nom, puis cliquez sur le bouton [Nouvelle recherche]

  4. Cliquez sur le bouton [OK].
CONSEIL

  • Vous pouvez également double cliquer sur un scanneur dans la liste de scanneurs pour le sélectionner.

    Lorsque vous double-cliquez sur le scanneur, celui-ci devient disponible et l'Outil de sélection du scanneur se ferme.

  • Lorsque vous spécifiez [Saisissez une adresse IP] ou [Saisissez un nom] dans [Plage de recherche] sous [Rechercher une méthode pour le scanneur], vérifiez qu'une adresse IP ou un nom est saisi dans le champ de saisie, puis cliquez sur le bouton [OK].
