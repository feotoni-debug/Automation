Modification du nom du scanneur

Cette section explique comment utiliser l'Outil de configuration de l'adresse IP pour modifier le nom du scanneur.

Le nom du scanneur s'affiche dans la liste de scanneurs de la fenêtre [Outil de sélection du scanneur].

Le paramètre par défaut du nom du scanneur correspond au nom du modèle et au numéro de série du scanneur (Nom du modèle - Numéro de série).

Le numéro de série du scanneur est imprimé sur l'étiquette.

Pour en savoir plus, consultez le Guide d'utilisation du scanneur.

  1. Reliez un scanneur à un ordinateur à l'aide du câble USB fourni avec le scanneur.
  2. Mettez le scanneur sous tension.

    Pour en savoir plus, consultez le Guide d'utilisation du scanneur.

  3. Ce bouton permet de démarrer l'Outil de configuration de l'adresse IP.

    Pour en savoir plus, consultez la section Démarrage de l'Outil de configuration de l'adresse IP.

    La fenêtre de connexion de l'Outil de configuration de l'adresse IP s'affiche.

    Si vous n'avez pas défini de mot de passe d'administrateur pour le scanneur, la Fenêtre [Outil de configuration de l'adresse IP] s'affiche. Passez à l'étape 5.

  4. Saisissez le mode de passe de l'administrateur du scanneur, puis cliquez sur le bouton [Connexion].

    Pour en savoir plus sur le mot de passe de l'administrateur par défaut défini en usine, reportez-vous au Guide d'utilisation du scanneur.

    La Fenêtre [Outil de configuration de l'adresse IP] s'affiche.

  5. Saisissez les caractères appropriés dans [Nom du scanneur].

    Les caractères autorisés sont les suivants : caractères alphanumériques, "-" (tiret), "_" (trait de soulignement) et espaces.

    64 caractères maximum sont pris en charge.

    CONSEIL

    Si vous activez [DNS dynamique] dans les paramètres du scanneur, saisissez un nom de scanneur d'une longueur de 63 caractères maximum.

    Pour en savoir plus sur le DNS dynamique, consultez le Guide d'utilisation du scanneur.

    Il est recommandé de ne pas utiliser les caractères demi-chasse suivants lors de l'enregistrement d'un nom de scanneur sur le serveur DNS car les caractères seront convertis en "-" (tiret).

    • _ (trait de soulignement)

    • Espaces

  6. Cliquez sur le bouton [OK].
  7. Débranchez le câble USB du scanneur.
