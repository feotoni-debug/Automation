Échec de l'enregistrement du certificat.

Cause

Les origines du problème peuvent être les suivantes :

  • Le format du certificat spécifié est incorrect

  • Le chargement du certificat spécifié a échoué

  • Vous avez effectué les opérations suivantes après avoir cliqué sur le bouton [Configurer] dans la Fenêtre [Outil d'enregistrement de certificats]

    • Mise hors tension du scanneur

    • Connexion et déconnexion du scanneur de l'ordinateur avec le câble USB

Solution

Procédez comme suit :

  • Vérifiez que le format du certificat est correct.

    Les certificats pouvant être enregistrés sont les suivants :

    • Certificats client: fichier au format PKCS#12 (*.p12, *.pfx)

    • Certificats CA: fichier de certificat CA (*.cer, *.crt, *.der, *.pem)

  • Vérifiez que vous disposez de privilèges d'accès au fichier de certificat.

  • Mettez le scanneur sous tension.

  • Reliez le scanneur à l'ordinateur à l'aide du câble USB fourni avec le scanneur.

  • Redémarrez l'Outil d'enregistrement de certificats.

Si un message reste affiché après la prise des mesures ci-dessus, procédez comme suit :

  1. Éteignez le scanneur, puis rallumez-le.

    CONSEIL

    Lorsque vous essayez d'éteindre le scanneur, le message "En cours de fonctionnement..." peut rester affiché sur l'écran tactile du scanneur. Même si cela se produit, l'extinction du scanneur ne devrait pas être un problème.

  2. Redémarrez le scanneur.

  3. Redémarrez l'Outil d'enregistrement de certificats.
