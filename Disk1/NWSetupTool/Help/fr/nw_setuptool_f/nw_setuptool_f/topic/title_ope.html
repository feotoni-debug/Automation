Opérations

Cette section vous explique comment utiliser chaque outil dans Network Setup Tool for fi Series.

Les modèles de scanneurs pris en charge varient en fonction de l'outil utilisé pour le modèle. Pour en savoir plus sur les modèles de scanneurs pris en charge par chaque outil, consultez la rubrique Modèles de scanneurs pris en charge.

IMPORTANT

Lorsque le scanneur est en cours de numérisation, il est impossible de configurer les paramètres via l'Outil de sélection du scanneur, l'Outil de configuration de l'adresse IP et l'Outil d'enregistrement de certificats.

Outil de sélection du scanneur

  • Sélection d'un scanneur à utiliser

Outil de configuration de l'adresse IP

  • Modification du nom du scanneur

  • Modification de l'adresse IP d'un scanneur

  • Chiffrement des communications sur le réseau

Outil d'enregistrement de certificats

  • Enregistrer un certificat

  • Retirer un certificat

Button Event Manager

  • Configuration des paramètres des touches du scanneur

  • Sélection d'un scanneur à utiliser
  • Modification des paramètres réseau d'un scanneur
  • Enregistrement de certificats sur le scanneur
  • Configuration des paramètres des touches du scanneur
