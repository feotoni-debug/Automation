Aucun scanneur trouvé

Vérifiez les éléments suivants :

  • La méthode de connexion (utilisée pour connecter le scanneur) est-elle différente de celle définie dans les paramètres du scanneur ? (fi-7300NX)

  • Les paramètres du scanneur sont-ils correctement configurés ?

  • Le processus de démarrage ou d'initialisation est-il en cours d'exécution sur le scanneur ?

  • Est-ce qu'une autre application utilise le scanneur ?

  • Les paramètres réseau de l'ordinateur sont-ils correctement configurés ?

  • Le système d'exploitation de l'ordinateur est-il en cours de mise à jour ou en attente de redémarrage ?

  • Le scanneur est-il connecté au même sous-réseau que votre ordinateur ?

  • Les paramètres des périphériques réseau (commutateur, concentrateur ou routeur) sont-ils corrects ?

  • L'état de la communication entre le scanneur et l'ordinateur est-il stable ?

Si un scanneur est introuvable après avoir pris les mesures ci-dessus, redémarrez le scanneur et l'ordinateur, puis redémarrez l'Outil de sélection du scanneur.

Si le scanneur n'apparaît pas dans l'application de numérisation d'image, consultez la rubrique Impossible de lancer une numérisation depuis l'application de numérisation d'image.

La méthode de connexion (utilisée pour connecter le scanneur) est-elle différente de celle définie dans les paramètres du scanneur ? (fi-7300NX)

Solution

Vérifiez que le réseau Wi-Fi ou le réseau LAN câblé est configuré comme méthode de connexion du scanneur.

Pour cela, procédez comme suit.

Sur l'écran tactile du scanneur, appuyez sur → [Paramètres du scanneur] → [Méthode de connexion].

Les paramètres du scanneur sont-ils correctement configurés ?

Solution

  • Pour fi-8040 ou fi-7300NX

    Vérifiez les paramètres réseau du scanneur.

    Pour cela, procédez comme suit.

    Sur l'écran tactile du scanneur, appuyez sur → [Paramètres du scanneur] → [Réseau].

  • Pour fi-8950, fi-8930, fi-8820, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 ou fi-8250

    Utilisez l'Outil de configuration de l'adresse IP pour vérifier les paramètres réseau du scanneur.

    Pour en savoir plus sur la façon de démarrer l'Outil de configuration de l'adresse IP, consultez la section Démarrage de l'Outil de configuration de l'adresse IP.

Le processus de démarrage ou d'initialisation est-il en cours d'exécution sur le scanneur ?

Solution

Vérifiez que le processus de démarrage ou d'initialisation n'est pas en cours sur le scanneur.

Pour en savoir plus, consultez le Guide d'utilisation du scanneur.

Est-ce qu'une autre application utilise le scanneur ?

Solution

Quittez l'autre application qui utilise actuellement le scanneur.

Les paramètres réseau de l'ordinateur sont-ils correctement configurés ?

Solution

Vérifiez les paramètres réseau de l'ordinateur.

Pour en savoir plus sur la configuration des paramètres réseau de l'ordinateur, consultez le guide de votre ordinateur.

Le système d'exploitation de l'ordinateur est-il en cours de mise à jour ou en attente de redémarrage ?

Solution

Redémarrez l'Outil de sélection du scanneur après la mise à jour du système d'exploitation ou le redémarrage de l'ordinateur.

Le scanneur est-il connecté au même sous-réseau que votre ordinateur ?

Même si le scanneur est connecté au même sous-réseau que votre ordinateur, il peut être introuvable.

Solution

Sélectionnez [Rechercher à partir de l'adresse IP du scanneur] dans la Fenêtre [Outil de sélection du scanneur], puis saisissez l'adresse IP du scanneur.

Les paramètres des périphériques réseau (commutateur, concentrateur ou routeur) sont-ils corrects ?

Solution

Vérifiez les paramètres des périphériques réseau (commutateur, concentrateur ou routeur).

Pour en savoir plus sur la définition du périphérique réseau, consultez le guide de votre périphérique réseau.

L'état de la communication entre le scanneur et l'ordinateur est-il stable ?

Solution

  • Pour fi-8040 ou fi-7300NX

    Vérifiez l'état de la communication entre le scanneur et l'ordinateur.

    Vous pouvez vérifier l'état de la communication entre le scanneur et l'ordinateur sur l'écran tactile du scanneur.

    Pour cela, procédez comme suit.

    Sur l'écran tactile du scanneur, appuyez sur → [Paramètres du scanneur] → [Réseau] → [Vérifier la connexion (Ping)].

  • Pour fi-8950, fi-8930, fi-8820, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 ou fi-8250

    Vérifiez l'état de la communication entre le scanneur et l'ordinateur.

    Démarrez l'invite de commandes sur votre ordinateur et exécutez la commande ping pour vérifier l'état de communication en spécifiant l'adresse IP du scanneur.

    Utilisez l'Outil de configuration de l'adresse IP pour vérifier l'adresse IP du scanneur.

    Pour en savoir plus sur la façon de démarrer l'Outil de configuration de l'adresse IP, consultez la section Démarrage de l'Outil de configuration de l'adresse IP.
