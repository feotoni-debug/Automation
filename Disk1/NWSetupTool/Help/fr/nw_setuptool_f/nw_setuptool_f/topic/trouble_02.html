Impossible de lancer une numérisation en appuyant sur la touche du scanneur

Vérifiez les éléments suivants :

  • Le scanneur est-il sélectionné dans l'Outil de sélection du scanneur ?

  • Button Event Manager a-t-il démarré ?

  • L'option [Afficher l'événement de bouton] est-elle sélectionnée dans le menu de Button Event Manager ?

  • Les paramètres de la touche du scanneur sont-ils corrects ?

  • Le scanneur est-il utilisé par un autre ordinateur ?

Le scanneur est-il sélectionné dans l'Outil de sélection du scanneur ?

Solution

Dans la Fenêtre [Outil de sélection du scanneur], vérifiez que le scanneur est sélectionné.

Button Event Manager a-t-il démarré ?

Solution

Vérifiez que Button Event Manager a démarré.

Une fois que Button Event Manager a démarré, apparaît dans la zone de notification située à l'extrémité droite de la barre des tâches.

Pour en savoir plus sur la façon de démarrer Button Event Manager, consultez la section Démarrage de Button Event Manager.

L'option [Afficher l'événement de bouton] est-elle sélectionnée dans le menu de Button Event Manager ?

Solution

Démarrez Button Event Manager et cliquez avec le bouton droit sur dans la zone de notification située à l'extrémité droite de la barre des tâches pour afficher la Menu de Button Event Manager. Vérifiez que l'option [Afficher l'événement de bouton] est sélectionnée.

Pour en savoir plus sur la façon de démarrer Button Event Manager, consultez la section Démarrage de Button Event Manager.

Les paramètres de la touche du scanneur sont-ils corrects ?

Solution

  • Dans la Fenêtre [Paramètres du bouton] de Button Event Manager, vérifiez que le paramètre de la touche est correct.

  • Vérifiez que l'application de numérisation d'image que vous avez attribuée à la touche du scanneur est exécutée sur l'ordinateur.

Le scanneur est-il utilisé par un autre ordinateur ?

Solution

Lorsque le même scanner a été sélectionné par plusieurs ordinateurs à l'aide de l'outil de sélection du scanneur, sélectionnez [Afficher l'événement de bouton] dans le menu de Button Event Manager uniquement sur l'ordinateur avec lequel vous souhaitez utiliser le scanner.

Si vous ne parvenez pas à lancer une numérisation après avoir pris les mesures ci-dessus, procédez comme suit :

  • Quittez l'application de numérisation d'images qui se trouve dans la zone de notification située à l'extrême droite de la barre des tâches

  • Éteignez le scanneur, puis rallumez-le
