Impossible de lancer une numérisation depuis l'application de numérisation d'image

Vérifiez les éléments suivants :

  • Avez-vous configuré un serveur proxy lors de la configuration du proxy WinHTTP ?

Avez-vous configuré un serveur proxy lors de la configuration du proxy WinHTTP ?

Solution

Modifiez les paramètres du proxy WinHTTP de façon à pouvoir accéder au scanneur depuis l'ordinateur.

Procédez comme suit pour modifier les paramètres du proxy WinHTTP.

  1. Ouvrez la fenêtre d'invite de commande en tant qu'utilisateur doté de privilèges d'administrateur sur l'ordinateur.

  2. Exécutez la commande suivante pour vérifier le nom du serveur proxy et les numéros de port à utiliser.

    netsh winhttp show proxy

    CONSEIL

    Le nom du serveur proxy et les numéros de port à utiliser s'affichent comme suit.

    "Nom du serveur proxy : Numéros de port"

  3. Exécutez l'une des commandes suivantes.

    • Si un serveur proxy a déjà été configuré

      Configurez ce paramètre de façon à ce que l'ordinateur puisse accéder au scanneur sans utiliser le serveur proxy.

      netsh winhttp set proxy proxy-server="XXXXXX:YYYY" bypass-list=ZZZ.ZZZ.ZZZ.ZZZ

      XXXXXX : nom du serveur proxy

      YYYY : numéros de port à utiliser

      ZZZ.ZZZ.ZZZ.ZZZ : adresse IP du scanneur (*1)(*2)

    • Si aucun serveur proxy n'a été configuré

      Réinitialisez les paramètres pour que l'ordinateur puisse accéder au scanneur.

      netsh winhttp reset proxy
*1 :

vous pouvez vérifier l'adresse IP du scanneur sur l'écran tactile ou sur le panneau de commande du scanneur, ou dans l'Outil de configuration de l'adresse IP.
*2 :

Le format d'adresse IPv4 est utilisé ici à titre d'exemple.

Pour une adresse IPv6, le format suivant est utilisé.

ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ
