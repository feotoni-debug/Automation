[버튼 설정] 창

스캐너 버튼을 누를 때 시작할 이미지 스캔 애플리케이션을 지정합니다.
이벤트를 선택해 주십시오.

버튼 목록에서 버튼을 선택하여 스캐너 버튼을 누를 때 시작할 이미지 스캔 애플리케이션을 지정합니다.

정보

  • 버튼 목록에 표시된 버튼 이름은 스캐너 모델에 따라 다릅니다.

    자세한 내용은 스캐너 사용 설명서를 참조해 주십시오.

  • Button Event Manager를 사용하여 스캐너의 스캔 버튼에 이미지 스캔 애플리케이션을 지정할 경우 다음 사항에 유의해 주십시오.

    • PaperStream ClickScan이 실행 중인 경우

      Button Event Manager로 스캔 버튼을 구성한 설정에 관계없이 스캐너의 스캔 버튼을 누르면 PaperStream ClickScan으로 스캔을 수행합니다.

      스캐너의 스캔 버튼을 눌러 다른 이미지 스캔 애플리케이션을 시작하려면 PaperStream ClickScan을 종료합니다. 자세한 내용은 PaperStream ClickScan 도움말을 참조해 주십시오.

    • PaperStream ClickScan이 실행되지 않으며 PaperStream Capture를 설치한 경우

      PaperStream Capture이 스캐너의 스캔 버튼에 자동으로 설정됩니다.

      스캐너의 스캔 버튼에 PaperStream Capture를 설정하지 않은 경우 [조작]에서 [없음]이나 [다음 프로그램 실행]을 선택합니다.

      스캐너 버튼을 설정하는 방법에 대한 자세한 내용은 스캐너 버튼 설정 구성하기를 참조해 주십시오.

조작
[PaperStream Capture] 시작

PaperStream Capture를 시작하려면 선택합니다.

문서 프로필 이름이 사용하는 스캐너에 따라 터치 스크린이나 조작 패널에 표시됩니다.

자세한 내용은 도움말을 참조해 주십시오.

다음 프로그램 실행
