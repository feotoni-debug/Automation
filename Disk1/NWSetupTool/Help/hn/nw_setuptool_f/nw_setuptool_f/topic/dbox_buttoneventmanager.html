Button Event Manager 메뉴

작업 표시줄 오른쪽 끝에 있는 알림 영역에서 을 마우스 오른쪽 버튼으로 클릭하면 다음 메뉴 항목이 표시됩니다.
버튼 이벤트 감시

스캐너 버튼의 누름 동작을 감지합니다.

선택하지 않으면 스캐너 버튼을 누를 때 [버튼 설정] 창에서 지정한 이미지 스캔 애플리케이션이 시작되지 않습니다.

중요

스캐너 선택 도구를 사용하여 두 대 이상의 컴퓨터에서 동일한 스캐너를 선택한 경우 스캐너를 사용할 컴퓨터에서만 [버튼 이벤트 감시]를 선택합니다.

정보

스캐너의 스캔 버튼을 눌러 Software Operation Panel을 시작하려면 [버튼 이벤트 감시]를 선택합니다.

스캐너의 스캔 버튼을 누를 때 스캐너가 작동하는 방식에 대한 자세한 내용은 스캐너 사용 설명서를 참조해 주십시오.

로그인 시에 이 도구 시작

선택하면 Windows에 로그인할 때 Button Event Manager가 시작합니다.

Button Event Manager가 시작하면 작업 표시줄 오른쪽 끝에 있는 알림 영역에 알림 메시지가 나타납니다.

버튼 설정 구성

스캐너 버튼을 누를 때 시작할 이미지 스캔 애플리케이션을 지정합니다.

[버튼 설정] 창가 나타납니다.

도움말

도움말을 표시합니다.

정보

버전 정보를 표시합니다.

끝내기

Button Event Manager를 종료합니다.
