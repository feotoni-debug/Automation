[IPv6 설정] 창

IPv6 주소를 설정합니다.
IPv6 구성

스캐너의 IPv6 주소를 설정할 방법을 선택합니다.

  • 자동

    IP 주소가 자동으로 DHCP 서버에서 스캐너로 할당됩니다.

    공장 출하 시 설정입니다.

  • 수동

    IP 주소를 수동으로 할당합니다.

  • 사용 안함

    IPv6 주소 설정을 사용하지 않습니다.

[RA 패킷 수신] 확인란

이 확인란은 [IPv6 구성]에서 [수동]을 선택하면 나타납니다.

자동으로 생성된 IPv6 주소를 사용하려면 선택합니다.

[IP 주소 설정 도구] 창의 [IPv6]의 [IP 주소]에서 자동으로 생성된 IPv6 주소를 확인할 수 있습니다.

확인란은 공장 출하 시 기본으로 선택되어 있습니다.

IP 주소

[IPv6 구성]에서 [수동]을 선택한 경우 스캐너의 IP 주소를 입력합니다.

서브넷 접두사 길이

[IPv6 구성]에서 [수동]을 선택한 경우 IP 주소의 서브넷 접두사 길이를 입력합니다.

값은 3~128까지 입력할 수 있습니다.

기본 게이트웨이

[IPv6 구성]에서 [수동]을 선택한 경우 IP 주소의 기본 게이트웨이를 입력합니다.
