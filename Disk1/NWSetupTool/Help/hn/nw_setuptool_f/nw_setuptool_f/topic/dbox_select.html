[스캐너 선택 도구] 창

네트워크에 연결된 스캐너 중에 컴퓨터에서 사용할 스캐너를 선택할 수 있습니다.
스캐너를 애플리케이션에서 사용하시겠습니까?

도움말을 표시합니다.

스캐너 목록

발견된 스캐너의 정보를 표시합니다.

스캐너 선택 도구를 시작하면 이 도구는 [스캐너 검색 방법]에 설정된 검색 범위 내에서 스캐너를 자동으로 검색하고 발견된 스캐너의 모델명, 스캐너 이름 및 IP 주소를 표시합니다.

확인란을 선택하려면 컴퓨터에서 사용할 스캐너의 이름을 클릭합니다. 스캐너 한 개만 선택할 수 있습니다.

스캐너가 이미 선택되어 있으면 스캐너 목록 상단에 스캐너가 표시됩니다.

네트워크에 연결된 스캐너를 사용하지 않으려면 선택한 스캐너의 이름을 클릭하여 확인 표시를 지웁니다.

정보

  • 또한 스캐너 목록에서 스캐너를 더블 클릭하여 스캐너를 선택할 수 있습니다.

    스캐너를 더블 클릭하면 컴퓨터에서 스캐너를 사용할 수 있게 되고 스캐너 선택 도구가 종료됩니다.

  • fi-8950, fi-8930, fi-8820, fi-8040, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 또는 fi-8250의 경우 스캐너 목록의 [IP 주소]에 표시된 IP 주소를 클릭하면 fi Series 네트워크 설정(웹 브라우저에서)이 시작됩니다.

    fi Series 네트워크 설정(웹 브라우저에서)에 대한 자세한 내용은 스캐너의 사용 설명서를 참조해 주십시오.

  • 스캐너가 이미 선택되어 있고 다음 상태 중 하나에서 스캐너 선택 도구를 시작하거나 [스캐너 선택 도구] 창에서 [다시 검색] 버튼을 클릭하면 선택한 스캐너에 대신 가 추가됩니다.

    • 선택한 스캐너는 네트워크에 연결되어 있지 않음
    • 선택한 스캐너의 전원이 꺼져 있음

    • [스캐너 검색 방법]의 [검색 범위]에 선택한 스캐너를 검색하지 않는 값이 지정되었습니다.

      이 경우 선택한 스캐너가 네트워크에 연결되어 있으면 스캐너를 그대로 사용할 수 있습니다.

스캐너 검색 방법
검색 범위
IPv4

IPv4 주소를 사용하여 컴퓨터와 동일한 서브네트워크에 연결되어 있는 스캐너를 검색합니다.

공장 출하 시 설정입니다.

IPv6

IPv6 주소를 사용하여 컴퓨터와 동일한 서브네트워크에 연결되어 있는 스캐너를 검색합니다.

fi-8950, fi-8930, fi-8820, fi-8040, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 또는 fi-8250의 경우 스캐너를 검색할 때 선택합니다.

IP 주소 입력

스캐너의 IP 주소를 지정하여 스캐너를 검색하거나 컴퓨터가 연결된 서브네트워크와 다른 서브네트워크에 연결된 스캐너를 사용할 경우에 선택합니다.

입력 필드에 IP 주소를 입력합니다.

이름 입력

DNS 서버에 등록된 스캐너의 이름을 지정하여 스캐너를 검색할 때 선택합니다.

정보

스캐너 이름은 DNS 서버에 등록된 이름이어야 합니다.

입력 필드에 255자 이내의 이름을 입력합니다.

다음 문자를 사용할 수 있습니다.

  • 영문자

  • - (하이픈)

  • . (마침표)

[다시 검색] 버튼

스캐너 검색을 시작합니다.

찾고자 하는 스캐너가 없습니까?

도움말을 표시합니다.

[IP 주소 설정] 버튼

IP 주소 설정 도구를 시작합니다.

컴퓨터에서 사용할 스캐너를 찾지 못한 경우 이 버튼을 클릭하여 스캐너 이름이나 스캐너의 IP 주소를 확인할 수 있습니다.

IP 주소 설정 도구를 사용하려면 USB 케이블을 통해 스캐너가 컴퓨터에 연결되어 있어야 합니다.
