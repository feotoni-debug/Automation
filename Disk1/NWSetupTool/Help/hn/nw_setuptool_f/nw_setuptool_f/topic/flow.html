이미지 스캔 애플리케이션에서 스캔 시작

  • fi-8040 또는 fi-7300NX의 경우

    1. 스캐너 터치 스크린에서 네트워크 설정 구성

      자세한 내용은 스캐너 사용 설명서를 참조해 주십시오.

    2. 스캐너를 네트워크에 연결

      정보

      Wi-Fi를 통한 증명서가 필요한 네트워크에 연결된 fi-7300NX를 사용하려면 사전에 증명서를 스캐너에 등록해야 합니다. 자세한 내용은 스캐너에 증명서 등록하기를 참조해 주십시오.

    3. 스캐너 선택 도구를 시작하여 컴퓨터에서 사용할 스캐너를 선택합니다

      자세한 내용은 사용할 스캐너 선택하기의 3단계와 이후 단계를 참조해 주십시오.

    4. 이미지 스캔 애플리케이션에서 유선 LAN 또는 Wi-Fi에 연결된 스캐너를 선택합니다.

      유선 LAN 또는 Wi-Fi에 연결된 스캐너의 이름은 다음과 같습니다.

      • PaperStream IP (TWAIN)/PaperStream IP (TWAIN x64)의 경우

        PaperStream IP xxx Net

      • PaperStream IP (ISIS) fi-8000 Series/PaperStream IP (ISIS) Bundle의 경우

        PaperStream_IP xxx Net

      "xxx"는 스캐너 모델 이름을 나타냅니다. 자세한 내용은 스캐너 드라이브의 도움말을 참조해 주십시오.

      정보

      fi-7300NX만 Wi-Fi 연결로 사용할 수 있습니다.

    5. 스캐너에 문서를 올려놓고 이미지 스캔 애플리케이션에서 스캔합니다

      스캐너에 문서를 올려놓는 방법에 대한 자세한 내용은 스캐너 사용 설명서를 참조해 주십시오.

      정보

      스캐너 선택 도구를 사용하여 스캐너를 선택하더라도 스캐너가 사용 중인 이미지 스캔 애플리케이션에 표시되지 않을 수 있습니다. 자세한 내용은 이미지 스캔 애플리케이션에서 스캔을 수행할 수 없음를 참조해 주십시오.

  • fi-8950, fi-8930, fi-8820, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 또는 fi-8250의 경우

    1. LAN 케이블로 스캐너를 네트워크 장치(예: 스위치, 허브 또는 라우터)에 연결합니다

      자세한 내용은 스캐너 사용 설명서를 참조해 주십시오.

      • IP 주소가 자동으로 할당된 경우

        다음 단계로 진행합니다.

      • IP 주소가 수동으로 할당된 경우

        IP 주소 설정 도구를 시작하여 IP 주소를 스캐너에 할당합니다.

        세부 사항은 스캐너의 IP 주소 변경하기를 참조해 주십시오.

    2. 스캐너 선택 도구를 시작하여 컴퓨터에서 사용할 스캐너를 선택합니다

      자세한 내용은 사용할 스캐너 선택하기의 3단계와 이후 단계를 참조해 주십시오.

    3. 이미지 스캔 애플리케이션에서 유선 LAN에 연결된 스캐너를 선택합니다.

      유선 LAN에 연결된 스캐너의 이름은 다음과 같습니다.

      • PaperStream IP (TWAIN)/PaperStream IP (TWAIN x64)의 경우

        PaperStream IP xxx Net

      • PaperStream IP (ISIS) fi-8000 Series의 경우

        PaperStream_IP xxx Net

      "xxx"는 스캐너 모델 이름을 나타냅니다. 자세한 내용은 스캐너 드라이브의 도움말을 참조해 주십시오.

    4. 스캐너에 문서를 올려놓고 이미지 스캔 애플리케이션에서 스캔합니다

      스캐너에 문서를 올려놓는 방법에 대한 자세한 내용은 스캐너 사용 설명서를 참조해 주십시오.

      정보

      스캐너 선택 도구를 사용하여 스캐너를 선택하더라도 스캐너가 사용 중인 이미지 스캔 애플리케이션에 표시되지 않을 수 있습니다. 자세한 내용은 이미지 스캔 애플리케이션에서 스캔을 수행할 수 없음를 참조해 주십시오.

  • fi-8040 또는 fi-7300NX의 경우

    1. 스캐너 터치 스크린에서 네트워크 설정 구성

      자세한 내용은 스캐너 사용 설명서를 참조해 주십시오.

    2. 스캐너를 네트워크에 연결

      정보

      Wi-Fi를 통한 증명서가 필요한 네트워크에 연결된 fi-7300NX를 사용하려면 사전에 증명서를 스캐너에 등록해야 합니다. 자세한 내용은 스캐너에 증명서 등록하기를 참조해 주십시오.

    3. 스캐너 선택 도구를 시작하여 컴퓨터에서 사용할 스캐너를 선택합니다

      자세한 내용은 사용할 스캐너 선택하기의 3단계와 이후 단계를 참조해 주십시오.

    4. Button Event Manager를 시작하고 스캐너 버튼을 누를 때 시작할 이미지 스캔 애플리케이션 지정

      자세한 내용은 스캐너 버튼 설정 구성하기의 3단계와 이후 단계를 참조해 주십시오.

      중요

      스캐너 선택 도구를 사용하여 두 대 이상의 컴퓨터에서 동일한 스캐너를 선택한 경우 스캐너를 사용할 컴퓨터에서만 Button Event Manager 메뉴에서 [버튼 이벤트 감시]를 선택합니다.

    5. 스캐너에 문서를 올려놓고 스캐너 버튼을 눌러 문서 스캔
