스캐너 버튼 설정 구성하기

이 단원에서는 Button Event Manager를 사용하고 스캐너 버튼을 누를 때 시작할 이미지 스캔 애플리케이션을 지정하는 방법을 설명합니다.

중요

스캐너 선택 도구를 사용하여 두 대 이상의 컴퓨터에서 동일한 스캐너를 선택한 경우 스캐너를 사용할 컴퓨터에서만 Button Event Manager 메뉴에서 [버튼 이벤트 감시]를 선택합니다.

정보

Button Event Manager를 사용하여 스캐너의 스캔 버튼에 이미지 스캔 애플리케이션을 지정할 경우 다음 사항에 유의해 주십시오.

  • PaperStream ClickScan이 실행 중인 경우

    Button Event Manager로 스캔 버튼을 구성한 설정에 관계없이 스캐너의 스캔 버튼을 누르면 PaperStream ClickScan으로 스캔을 수행합니다.

    스캐너의 스캔 버튼을 눌러 다른 이미지 스캔 애플리케이션을 시작하려면 PaperStream ClickScan을 종료합니다. 자세한 내용은 PaperStream ClickScan 도움말을 참조해 주십시오.

  • PaperStream ClickScan이 실행되지 않으며 PaperStream Capture를 설치한 경우

    PaperStream Capture이 스캐너의 스캔 버튼에 자동으로 설정됩니다.

    스캐너의 스캔 버튼에 PaperStream Capture를 설정하지 않은 경우 [버튼 설정] 창에서 [조작]의 [없음]이나 [다음 프로그램 실행]을 선택합니다.

  1. 스캐너를 네트워크에 연결합니다.

    자세한 내용은 스캐너 사용 설명서를 참조해 주십시오.

  2. 이미지 스캔 애플리케이션에서 선택할 스캐너를 활성화합니다.

    스캐너 선택 도구를 시작하고 네트워크에 연결된 스캐너에서 사용할 스캐너를 선택합니다.

    세부 사항은 사용할 스캐너 선택하기를 참조해 주십시오.

  3. 이미지 스캔 애플리케이션에서 스캔 설정을 구성합니다.

    자세한 내용은 이미지 스캔 애플리케이션의 설명서를 참조해 주십시오.

  4. Button Event Manager를 시작합니다.

    세부 사항은 Button Event Manager 시작하기를 참조해 주십시오.

    Button Event Manager가 시작하면 작업 표시줄 오른쪽 끝에 있는 알림 영역에 가 나타납니다.

  5. 를 마우스 오른쪽 버튼으로 클릭합니다.

    Button Event Manager 메뉴가 나타납니다.

  6. 메뉴에서 [버튼 이벤트 감시]를 선택합니다.
  7. 메뉴에서 [버튼 설정 구성]을 클릭합니다.

    [버튼 설정] 창가 나타납니다.

  8. 스캐너 버튼을 누를 때 시작할 이미지 스캔 애플리케이션을 지정합니다.

    설정에 대한 자세한 내용은 [버튼 설정] 창를 참조해 주십시오.

  9. [확인] 버튼을 클릭합니다.
