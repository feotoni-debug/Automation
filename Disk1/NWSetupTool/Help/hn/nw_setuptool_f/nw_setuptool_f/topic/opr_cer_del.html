증명서 제거하기

이 단원에서는 증명서 등록 도구를 사용하여 스캐너에 등록된 증명서를 제거하는 방법을 설명합니다.
  1. 증명서 등록 도구를 시작합니다.

    자세한 내용은 증명서 등록 도구 시작하기를 참조해 주십시오.

    [증명서 등록 도구] 창가 나타납니다.

  2. 스캐너와 함께 제공되는 USB 케이블로 스캐너를 컴퓨터에 연결하고 [증명서 등록 도구] 창의 [설정] 버튼을 클릭합니다.

    증명서 설정 창가 나타납니다.

    중요

    증명서 설정 창이 표시된 상태에서 USB 케이블을 분리한 후 연결하면 증명서를 제거할 수 없습니다.

    증명서 설정 창을 닫고 [증명서 등록 도구] 창에서 다시 [설정] 버튼을 클릭합니다.

  3. 제거할 증명서의 탭([클라이언트 증명서] 또는 [CA 증명서])을 선택합니다.
  4. 제거할 증명서를 선택합니다.
  5. [제거] 버튼을 클릭합니다.

    증명서가 스캐너에서 제거됩니다.

  6. [확인] 버튼을 클릭합니다.
  7. 스캐너에서 USB 케이블을 뽑습니다.
  8. 스캐너를 껐다가 다시 켭니다.
    정보

    스캐너를 끄려고 할 때 스캐너의 터치 스크린에 "작동 중..." 메시지가 표시될 수 있습니다. 이러한 경우에도 스캐너를 끄는 것은 문제가 되지 않습니다.
