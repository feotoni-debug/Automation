사용할 스캐너 선택하기

이 단원에서는 스캐너 선택 도구를 사용하여 컴퓨터에서 사용할 스캐너를 선택하는 방법을 설명합니다.
  1. 스캐너를 네트워크에 연결합니다.

    자세한 내용은 스캐너 사용 설명서를 참조해 주십시오.

  2. 스캐너 선택 도구를 시작합니다.

    세부 사항은 스캐너 선택 도구 시작하기를 참조해 주십시오.

    [스캐너 선택 도구] 창가 나타납니다.

    정보

    스캐너 선택 도구를 시작하면 이 도구는 [스캐너 검색 방법]에 설정된 검색 범위 내에서 스캐너를 자동으로 검색합니다.

  3. 스캐너 목록에서 컴퓨터에서 사용할 스캐너를 선택합니다.

    선택한 스캐너 옆에 확인 표시가 나타납니다.

    정보

    사용할 스캐너가 스캐너 목록에 표시되지 않으면 다음 절차를 따라 스캐너를 검색합니다.

    • 스캐너가 컴퓨터가 연결된 것과 동일한 서브네트워크에 연결되어 있는 경우

      [스캐너 검색 방법]의 [검색 범위]에서 [IPv4] 또는 [IPv6]을 선택하고 [다시 검색] 버튼을 클릭합니다.

    • 스캐너가 컴퓨터가 연결된 것과 다른 서브네트워크에 연결되어 있는 경우

      [스캐너 검색 방법]의 [검색 범위]에서 [IP 주소 입력] 또는 [이름 입력]을 선택한 후 IP 주소 또는 이름을 입력하고 [다시 검색] 버튼을 클릭합니다.

  4. [확인] 버튼을 클릭합니다.
정보

  • 또한 스캐너 목록에서 스캐너를 더블 클릭하여 스캐너를 선택할 수 있습니다.

    스캐너를 더블 클릭하면 컴퓨터에서 스캐너를 사용할 수 있게 되고 스캐너 선택 도구가 종료됩니다.

  • [스캐너 검색 방법]의 [검색 범위]에 [IP 주소 입력] 또는 [이름 입력]을 지정한 경우 입력 필드에 IP 주소 또는 이름이 입력되었는지 확인한 다음 [확인] 버튼을 클릭합니다.

    관련 항목
