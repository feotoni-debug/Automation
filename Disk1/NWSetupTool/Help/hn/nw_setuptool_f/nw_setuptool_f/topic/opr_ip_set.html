스캐너의 IP 주소 변경하기

이 단원에서는 IP 주소 설정 도구를 사용하여 스캐너의 IP 주소를 변경하는 방법을 설명합니다.

[스캐너 선택 도구] 창의 스캐너 목록에 IP 주소가 표시됩니다.

IPv4 주소 또는 IPv6 주소는 공장 출하 시 설정으로 스캐너에 자동 할당됩니다.

예를 들어 다음과 같은 경우에는 IP 주소 설정 도구를 사용하여 스캐너 IP 주소를 변경합니다.

  • 스캐너 선택 도구에서 스캐너를 찾지 못한 경우

  • DHCP 서버를 사용하지 않는 네트워크에 스캐너를 연결한 경우

  • 스캐너에 고정 IP 주소를 설정하려는 경우

  1. 스캐너와 함께 제공되는 USB 케이블로 스캐너를 컴퓨터에 연결합니다.
  2. 스캐너를 켭니다.

    자세한 내용은 스캐너 사용 설명서를 참조해 주십시오.

  3. IP 주소 설정 도구를 시작합니다.

    세부 사항은 IP 주소 설정 도구 시작하기를 참조해 주십시오.

    IP 주소 설정 도구의 로그인 창이 표시됩니다.

    스캐너에 관리자 암호를 설정하지 않으면 [IP 주소 설정 도구] 창이 표시됩니다. 5단계를 진행합니다.

  4. 스캐너의 관리자 암호를 입력하고 [로그인] 버튼을 클릭합니다.

    공장 기본 관리자 암호에 대한 자세한 내용은 스캐너의 사용 설명서를 참조해 주십시오.

    [IP 주소 설정 도구] 창가 나타납니다.

  5. IP 주소를 설정할 방법을 선택합니다.

    • IPv4 주소

      [네트워크]의 [IPv4 구성]에서 스캐너의 IP 주소를 설정할 방법을 선택합니다.

      • [자동]을 선택한 경우

        6단계를 진행합니다.

      • [수동]을 선택한 경우

        [IP 주소], [서브넷 마스크] 및 [기본 게이트웨이]에 적절한 숫자를 입력합니다.

    • IPv6 주소

      1. [네트워크]의 [IPv6]에서 [IPv6 설정] 버튼을 클릭합니다.

      2. [IPv6 설정] 창의 [IPv6 구성]에서 스캐너의 IP 주소 설정 방법을 선택합니다.

        • [자동] 또는 [사용 안함]을 선택한 경우

          [확인] 버튼을 클릭하고 6단계를 진행합니다.

        • [수동]을 선택한 경우

          [IP 주소], [서브넷 접두사 길이] 및 [기본 게이트웨이]에 적절한 숫자를 입력합니다.

      3. [확인] 버튼을 클릭합니다.

  6. [확인] 버튼을 클릭합니다.
  7. 스캐너에서 USB 케이블을 뽑습니다.
