스캐너 이름 변경하기

이 단원에서는 IP 주소 설정 도구를 사용하여 스캐너 이름을 변경하는 방법을 설명합니다.

[스캐너 선택 도구] 창의 스캐너 목록에 스캐너 이름이 표시됩니다.

스캐너 이름 공장 출하 시 설정은 스캐너의 모델 이름과 일련 번호(모델 이름 - 일련 번호)입니다.

스캐너 일련 번호는 제품 레이블에 인쇄되어 있습니다.

자세한 내용은 스캐너 사용 설명서를 참조해 주십시오.

  1. 스캐너와 함께 제공되는 USB 케이블로 스캐너를 컴퓨터에 연결합니다.
  2. 스캐너를 켭니다.

    자세한 내용은 스캐너 사용 설명서를 참조해 주십시오.

  3. IP 주소 설정 도구를 시작합니다.

    세부 사항은 IP 주소 설정 도구 시작하기를 참조해 주십시오.

    IP 주소 설정 도구의 로그인 창이 표시됩니다.

    스캐너에 관리자 암호를 설정하지 않으면 [IP 주소 설정 도구] 창이 표시됩니다. 5단계를 진행합니다.

  4. 스캐너의 관리자 암호를 입력하고 [로그인] 버튼을 클릭합니다.

    공장 기본 관리자 암호에 대한 자세한 내용은 스캐너의 사용 설명서를 참조해 주십시오.

    [IP 주소 설정 도구] 창가 나타납니다.

  5. [스캐너명]에 적절한 문자를 입력해 주십시오.

    사용 가능한 문자는 영문자, "-"(하이픈), "_"(밑줄) 및 공백입니다.

    최대 64자까지 설정할 수 있습니다.

    정보

    스캐너 설정에서 [동적 DNS]를 활성화하는 경우 길이가 63자 이하인 스캐너명을 입력해 주십시오.

    동적 DNS에 대한 자세한 내용은 스캐너 사용 설명서를 참조해 주십시오.

    문자가 "-"(하이픈)으로 변환되므로 DNS 서버에 스캐너명을 등록할 때 다음과 같은 반각문자는 사용하지 않는 것이 좋습니다.

    • _ (밑줄)

    • 공백

  6. [확인] 버튼을 클릭합니다.
  7. 스캐너에서 USB 케이블을 뽑습니다.
