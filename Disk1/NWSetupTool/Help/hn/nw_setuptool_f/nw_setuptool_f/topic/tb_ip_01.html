USB 케이블을 사용하여 스캐너를 컴퓨터에 연결합니다.

원인

다음으로 인해 문제가 발생할 수 있습니다.

  • 스캐너가 USB 케이블로 컴퓨터에 연결되지 않음

  • 스캐너 드라이브가 설치되지 않음

  • 스캐너가 켜지지 않음

  • IP 주소 설정 도구에서 컴퓨터에 연결된 컴퓨터를 지원하지 않음

해결책

다음을 수행합니다.

  • 스캐너와 함께 제공되는 USB 케이블로 스캐너를 컴퓨터에 연결합니다.

  • 스캐너 드라이브를 설치합니다.

    자세한 내용은 스캐너 사용 설명서를 참조해 주십시오.

  • 스캐너를 켭니다.

  • IP 주소 설정 도구 도구에서 지원하는 스캐너 모델인지 확인합니다.

    자세한 내용은 지원되는 스캐너 모델를 참조해 주십시오.
