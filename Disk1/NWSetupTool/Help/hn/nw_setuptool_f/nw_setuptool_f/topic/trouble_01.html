  • 스캐너를 연결하는 데 사용한 연결 방법이 스캐너 설정에서 설정한 연결 방법과 다릅니까? (fi-7300NX)

  • 스캐너의 네트워크 설정이 올바르게 구성되었습니까?

  • 스캐너에서 시작 프로세스나 초기화 프로세스가 진행 중입니까?

  • 다른 애플리케이션에서 스캐너를 사용하고 있습니까?

  • 컴퓨터의 네트워크 설정이 올바르게 구성되었습니까?

  • 컴퓨터의 운영 체제가 업데이트 중이거나 다시 시작하기 위해 대기 중입니까?

  • 스캐너가 컴퓨터와 동일한 서브네트워크에 연결되어 있습니까?

  • 네트워크 장치(예: 스위치, 허브 또는 라우터)의 설정이 올바릅니까?

  • 스캐너와 컴퓨터 간의 연결 상태가 안정적입니까?

이미지 스캔 애플리케이션에 스캐너가 표시되지 않으면 이미지 스캔 애플리케이션에서 스캔을 수행할 수 없음를 참조해 주십시오.

스캐너를 연결하는 데 사용한 연결 방법이 스캐너 설정에서 설정한 연결 방법과 다릅니까? (fi-7300NX)

해결책

Wi-Fi나 유선 LAN이 스캐너 연결 방법에 설정되어 있는지 확인합니다.

다음과 같이 확인할 수 있습니다.

스캐너 터치 스크린에서 → [스캐너 설정] → [연결 방법]을 누릅니다.

스캐너의 네트워크 설정이 올바르게 구성되었습니까?

해결책

  • fi-8040 또는 fi-7300NX의 경우

    스캐너의 네트워크 설정을 확인합니다.

    다음과 같이 확인할 수 있습니다.

    스캐너 터치 스크린에서 → [스캐너 설정] → [네트워크]를 누릅니다.

  • fi-8950, fi-8930, fi-8820, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 또는 fi-8250의 경우

    IP 주소 설정 도구를 사용하여 스캐너의 네트워크 설정을 확인해 주십시오.

    IP 주소 설정 도구를 시작하는 방법에 대한 자세한 내용은 IP 주소 설정 도구 시작하기를 참조해 주십시오.

스캐너에서 시작 프로세스나 초기화 프로세스가 진행 중입니까?

해결책

스캐너에서 시작 프로세스나 초기화 프로세스가 진행 중이지 않은지 확인합니다.

자세한 내용은 스캐너 사용 설명서를 참조해 주십시오.

다른 애플리케이션에서 스캐너를 사용하고 있습니까?

해결책

스캐너를 사용 중인 다른 애플리케이션을 종료해 주십시오.

컴퓨터의 네트워크 설정이 올바르게 구성되었습니까?

해결책

컴퓨터의 네트워크 설정을 확인해 주십시오.

컴퓨터의 네트워크 설정을 구성하는 방법에 대한 자세한 내용은 컴퓨터 설명서를 참조해 주십시오.

컴퓨터의 운영 체제가 업데이트 중이거나 다시 시작하기 위해 대기 중입니까?

해결책

컴퓨터의 운영 체제가 업데이트되거나 컴퓨터가 다시 시작한 후에 스캐너 선택 도구를 다시 시작해 주십시오.

스캐너가 컴퓨터와 동일한 서브네트워크에 연결되어 있습니까?

스캐너가 컴퓨터와 동일한 서브네트워크에 연결되어 있더라도 검색되지 않을 수 있습니다.

해결책

[스캐너 선택 도구] 창에서 [스캐너의 IP 주소에서 검색]을 선택하고 IP 주소를 입력하여 스캐너를 검색해 주십시오.

네트워크 장치(예: 스위치, 허브 또는 라우터)의 설정이 올바릅니까?

해결책

네트워크 장치(예: 스위치, 허브 또는 라우터)의 설정을 확인해 주십시오.

네트워크 장치를 설정하는 방법에 대한 자세한 내용은 네트워크 장치 설명서를 참조해 주십시오.

스캐너와 컴퓨터 간의 연결 상태가 안정적입니까?

해결책

  • fi-8040 또는 fi-7300NX의 경우

    스캐너와 컴퓨터 간의 연결 상태를 확인해 주십시오.

    스캐너 터치 스크린에서 스캐너와 컴퓨터 간의 통신 상태를 확인할 수 있습니다.

    다음과 같이 확인할 수 있습니다.

    스캐너 터치 스크린에서 → [스캐너 설정] → [네트워크] → [연결 확인(Ping)]을 누릅니다.

  • fi-8950, fi-8930, fi-8820, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 또는 fi-8250의 경우

    스캐너와 컴퓨터 간의 연결 상태를 확인해 주십시오.

    컴퓨터에서 명령 프롬프트를 시작하고 ping 명령을 실행해 스캐너의 IP 주소를 지정하여 통신 상태를 확인해 주십시오.

    IP 주소 설정 도구를 사용하여 스캐너의 IP 주소를 확인해 주십시오.

    IP 주소 설정 도구를 시작하는 방법에 대한 자세한 내용은 IP 주소 설정 도구 시작하기를 참조해 주십시오.
