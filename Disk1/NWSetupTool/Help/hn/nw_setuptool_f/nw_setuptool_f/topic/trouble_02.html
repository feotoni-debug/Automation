스캐너 선택 도구에서 스캐너를 선택했습니까?

해결책

[스캐너 선택 도구] 창에서 스캐너를 선택했는지 확인해 주십시오.

Button Event Manager를 시작했습니까?

해결책

Button Event Manager를 시작했는지 확인해 주십시오.

Button Event Manager가 시작하면 작업 표시줄 오른쪽 끝에 있는 알림 영역에 가 나타납니다.

Button Event Manager를 시작하는 방법에 대한 자세한 내용은 Button Event Manager 시작하기를 참조해 주십시오.

Button Event Manager의 메뉴에서 [버튼 이벤트 감시]가 선택되어 있습니까?

해결책

Button Event Manager를 시작하고 작업 표시줄 오른쪽 끝에 있는 알림 영역에 을 마우스 오른쪽 버튼으로 클릭하여 Button Event Manager 메뉴를 표시합니다. [버튼 이벤트 감시]가 선택되어 있는지 확인해 주십시오.

Button Event Manager를 시작하는 방법에 대한 자세한 내용은 Button Event Manager 시작하기를 참조해 주십시오.

스캐너 버튼 설정이 올바릅니까?

해결책

  • Button Event Manager의 [버튼 설정] 창에서 버튼 설정이 올바른지 확인해 주십시오.

  • 스캐너 버튼에 지정한 이미지 스캔 애플리케이션이 컴퓨터에서 실행되는지 확인합니다.

다른 컴퓨터에서 스캐너를 사용하고 있습니까?

해결책

스캐너 선택 도구를 사용하여 두 대 이상의 컴퓨터에서 동일한 스캐너를 선택한 경우 스캐너를 사용할 컴퓨터에서만 Button Event Manager 메뉴에서 [버튼 이벤트 감시]를 선택합니다.

위 조치를 취한 후에도 스캔을 시작할 수 없는 경우 다음을 수행합니다.

  • 작업 표시줄의 오른쪽에 끝에 있는 알림 영역에 있는 이미지 스캔 애플리케이션을 종료합니다.

  • 스캐너를 껐다가 다시 켭니다.
