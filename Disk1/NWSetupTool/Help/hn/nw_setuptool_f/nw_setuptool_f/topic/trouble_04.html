프록시 서버를 WinHTTP 프록시 설정에 설정했습니까?

해결책

컴퓨터에서 스캐너에 액세스할 수 있도록 WinHTTP 프록시 설정을 변경합니다.

다음 절차를 통해 WinHTTP 프록시 설정을 변경합니다.

  1. 컴퓨터에 대한 관리자 권한이 있는 사용자로 명령 프롬프트 창을 시작합니다.

  2. 다음 명령을 실행하여 사용할 프록시 서버 이름과 포트 번호를 확인합니다.

    netsh winhttp show proxy

    정보

    사용할 프록시 서버 이름과 포트 번호가 다음과 같이 표시됩니다.

    "프록시 서버 이름: 포트 번호"

  3. 다음 명령 중 하나를 실행합니다.

    • 프록시 서버가 이미 설정된 경우

      컴퓨터에서 프록시 서버를 사용하지 않고 스캐너에 액세스할 수 있도록 설정을 구성합니다.

      netsh winhttp set proxy proxy-server="XXXXXX:YYYY" bypass-list=ZZZ.ZZZ.ZZZ.ZZZ

      XXXXXX: 프록시 서버 이름

      YYYY: 사용할 포트 번호

      ZZZ.ZZZ.ZZZ.ZZZ: 스캐너 IP 주소 (*1)(*2)

    • 프록시 서버가 설정되지 않은 경우

      설정을 재설정하면 컴퓨터에서 스캐너에 액세스할 수 있습니다.

      netsh winhttp reset proxy
*1:

스캐너의 터치 스크린이나 조작 패널 또는 IP 주소 설정 도구에서 스캐너 IP 주소를 확인할 수 있습니다.
*2:

여기에서는 IPv4 주소 형식을 예로 사용합니다.

IPv6 주소의 경우 다음과 같은 형식이 사용됩니다.

ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ
