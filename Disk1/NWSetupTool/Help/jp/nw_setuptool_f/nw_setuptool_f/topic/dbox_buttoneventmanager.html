Button Event Manager のメニュー

コンピューターの画面右下にある通知領域のを右クリックすると、以下のメニューが表示されます。
ボタンを監視する

スキャナーのボタンが押されたことを検出します。

チェックを外すと、スキャナーのボタンを押しても、「ボタン設定」画面で設定した画像読み取り用アプリケーションは起動しません。

重要

複数台のコンピューターから、スキャナー選択ツールで同じスキャナーを選択している場合は、スキャナーを使用するコンピューターでだけ、「ボタンを監視する」にチェックを付けてください。

ヒント

スキャナーのスキャンボタンを押してSoftware Operation Panelを起動する場合は、「ボタンを監視する」にチェックを付けてください。

スキャナーのスキャンボタンを押したときの動作（機能）については、スキャナーのオペレーターガイドを参照してください。

ログオン時に起動する

チェックを付けると、WindowsにサインインしたときにButton Event Managerを起動します。

Button Event Managerが起動すると、コンピューターの画面右下にある通知領域に、メッセージが通知されます。

ボタンを設定する

スキャナーのボタンを押したときに起動する画像読み取り用アプリケーションを設定します。

「ボタン設定」画面が表示されます。

ヘルプ

ヘルプを表示します。

バージョン情報...

バージョン情報を表示します。

終了

Button Event Managerを終了します。
