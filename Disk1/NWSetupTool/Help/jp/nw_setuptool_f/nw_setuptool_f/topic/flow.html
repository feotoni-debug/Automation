操作の流れ

画像読み取り用アプリケーションを使用して原稿を読み取るまでの操作の流れは、以下のとおりです。

  • 画像読み取り用アプリケーションから読み取りを開始する

  • スキャナーのボタンで画像読み取り用アプリケーションを起動して読み取りを開始する

画像読み取り用アプリケーションから読み取りを開始する

  • fi-8040またはfi-7300NXの場合

    1. スキャナーのタッチパネルで、ネットワークの設定をする

      詳細は、スキャナーのオペレーターガイドを参照してください。

    2. スキャナーをネットワークに接続する

      ヒント

      fi-7300NXの場合、証明書が必要な無線LANに接続して使用するときは、事前にスキャナーに証明書を登録する必要があります。詳細は、スキャナーに証明書を設定するを参照してください。

    3. スキャナー選択ツールを起動して、コンピューターで使用するスキャナーを選択する

      詳細は、スキャナーを選択するの手順3以降を参照してください。

    4. 画像読み取り用アプリケーションで、有線LANまたは無線LANに接続しているスキャナーを選択する

      有線LANまたは無線LANに接続しているスキャナーの名前は以下のとおりです。

      • PaperStream IP （TWAIN）/PaperStream IP （TWAIN x64）の場合

        PaperStream IP xxx Net

      • PaperStream IP （ISIS） fi-8000 series/PaperStream IP （ISIS） Bundleの場合

        PaperStream_IP xxx Net

      「xxx」には、スキャナーの機種名が表示されます。詳細は、スキャナードライバーのヘルプを参照してください。

      ヒント

      無線LANに接続できるのはfi-7300NXだけです。

    5. スキャナーに原稿をセットし、画像読み取り用アプリケーションで読み取りを実行する

      原稿のセット方法の詳細は、スキャナーのオペレーターガイドを参照してください。

      ヒント

      スキャナー選択ツールでスキャナーを選択しているのに、画像読み取り用アプリケーションでスキャナーが見つからない場合があります。詳細は、画像読み取り用アプリケーションで読み取りができないを参照してください。

  • fi-8950、fi-8930、fi-8820、fi-8190、fi-8290、fi-8170、fi-8270、fi-8150、またはfi-8250の場合

    1. スキャナーとネットワーク機器（スイッチ、ハブ、ルーターなど）をLANケーブルで接続する

      詳細は、スキャナーのオペレーターガイドを参照してください。

      • 自動でIPアドレスが割り当てられる場合

        次の手順に進みます。

      • 手動でIPアドレスを割り当てる場合

        IPアドレス設定ツールを起動して、スキャナーにIPアドレスを設定します。

        詳細は、スキャナーのIPアドレスを変更するを参照してください。

    2. スキャナー選択ツールを起動して、コンピューターで使用するスキャナーを選択する

      詳細は、スキャナーを選択するの手順3以降を参照してください。

    3. 画像読み取り用アプリケーションで、有線LANに接続しているスキャナーを選択する

      有線LANに接続しているスキャナーの名前は以下のとおりです。

      • PaperStream IP （TWAIN）/PaperStream IP （TWAIN x64）の場合

        PaperStream IP xxx Net

      • PaperStream IP （ISIS） fi-8000 seriesの場合

        PaperStream_IP xxx Net

      「xxx」には、スキャナーの機種名が表示されます。詳細は、スキャナードライバーのヘルプを参照してください。

    4. スキャナーに原稿をセットし、画像読み取り用アプリケーションで読み取りを実行する

      原稿のセット方法の詳細は、スキャナーのオペレーターガイドを参照してください。

      ヒント

      スキャナー選択ツールでスキャナーを選択しているのに、画像読み取り用アプリケーションでスキャナーが見つからない場合があります。詳細は、画像読み取り用アプリケーションで読み取りができないを参照してください。

スキャナーのボタンで画像読み取り用アプリケーションを起動して読み取りを開始する

    1. スキャナーのタッチパネルで、ネットワークの設定をする

      詳細は、スキャナーのオペレーターガイドを参照してください。

    2. スキャナーをネットワークに接続する

      ヒント

      fi-7300NXの場合、証明書が必要な無線LANに接続して使用するときは、事前にスキャナーに証明書を登録する必要があります。詳細は、スキャナーに証明書を設定するを参照してください。

    3. スキャナー選択ツールを起動して、コンピューターで使用するスキャナーを選択する

      詳細は、スキャナーを選択するの手順3以降を参照してください。

    4. Button Event Managerを起動して、スキャナーのボタンを押したときに起動する画像読み取り用アプリケーションを設定する

      詳細は、スキャナーのボタンを設定するの手順3以降を参照してください。

      重要

      複数台のコンピューターから、スキャナー選択ツールで同じスキャナーを選択している場合は、スキャナーを使用するコンピューターでだけ、Button Event Managerのメニューの「ボタンを監視する」にチェックを付けてください。

    5. スキャナーに原稿をセットし、スキャナーのボタンを押して、読み取りを実行する

      原稿のセット方法の詳細は、スキャナーのオペレーターガイドを参照してください。
