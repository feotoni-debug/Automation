スキャナーのボタンを設定する

Button Event Managerを使用して、スキャナーのボタンを押したときに起動する画像読み取り用アプリケーションを設定する方法を説明します。

重要

複数台のコンピューターから、スキャナー選択ツールで同じスキャナーを選択している場合は、スキャナーを使用するコンピューターでだけ、Button Event Managerのメニューの「ボタンを監視する」にチェックを付けてください。

ヒント

Button Event Managerを使用して、スキャナーのスキャンボタンに画像読み取り用アプリケーションを設定する場合、以下の点に注意してください。

  • PaperStream ClickScanが起動している場合

    Button Event Managerでの設定に関係なく、スキャナーのスキャンボタンを押すとPaperStream ClickScanで読み取りが実行されます。

    スキャナーのスキャンボタンでほかの画像読み取り用アプリケーションを起動するには、PaperStream ClickScanを終了してください。詳細は、PaperStream ClickScanのヘルプを参照してください。

  • PaperStream ClickScanが起動していない、かつPaperStream Captureがインストールされている場合

    スキャナーのスキャンボタンに自動でPaperStream Captureが設定されます。

    スキャナーのスキャンボタンにPaperStream Captureを設定しない場合は、「ボタン設定」画面の「操作」で「何もしない」または「次のプログラムを実行する」を選択してください。

  1. スキャナーをネットワークに接続します。

    詳細は、スキャナーのオペレーターガイドを参照してください。

  2. 画像読み取り用アプリケーションでスキャナーの選択ができるように設定します。

    スキャナー選択ツールを起動して、ネットワークに接続しているスキャナーから使用するスキャナーを選択します。

    詳細は、スキャナーを選択するを参照してください。

  3. 画像読み取り用アプリケーションで読み取り設定をします。

    詳細は、画像読み取り用アプリケーションのマニュアルを参照してください。

  4. Button Event Managerを起動します。

    詳細は、Button Event Managerの起動方法を参照してください。

    Button Event Managerを起動すると、コンピューターの画面右下にある通知領域にが表示されます。

  5. を右クリックします。

    Button Event Manager のメニューが表示されます。

  6. メニューの「ボタンを監視する」にチェックを付けます。
  7. メニューの「ボタンを設定する」をクリックします。

    「ボタン設定」画面が表示されます。

  8. スキャナーのボタンを押したときに起動する画像読み取り用アプリケーションを設定します。

    設定の詳細は、「ボタン設定」画面を参照してください。

  9. ［OK］ボタンをクリックします。
