スキャナーのボタンを押して読み取りを開始できない

ここをお調べください

  • スキャナー選択ツールでスキャナーが選択されていますか？

  • Button Event Managerが起動していますか？

  • Button Event Manager のメニューの「ボタンを監視する」にチェックが付いていますか？

  • スキャナーのボタンの設定は正しいですか？

  • ほかのコンピューターでスキャナーを使用していませんか？

スキャナー選択ツールでスキャナーが選択されていますか？

対処方法

「スキャナー選択ツール」画面で、スキャナーが選択されていることを確認してください。

Button Event Managerが起動していますか？

対処方法

Button Event Managerが起動していることを確認してください。

Button Event Managerが起動していると、コンピューターの画面右下にある通知領域にが表示されます。

Button Event Managerの起動方法は、Button Event Managerの起動方法を参照してください。

Button Event Manager のメニューの「ボタンを監視する」にチェックが付いていますか？

対処方法

Button Event Managerを起動し、コンピューターの画面右下にある通知領域に表示されるを右クリックすると、Button Event Manager のメニューが表示されます。「ボタンを監視する」にチェックが付いていることを確認してください。

Button Event Managerの起動方法は、Button Event Managerの起動方法を参照してください。

スキャナーのボタンの設定は正しいですか？

対処方法

  • Button Event Managerの「ボタン設定」画面で、ボタンの設定が正しいことを確認してください。

  • スキャナーのボタンに設定した画像読み取り用アプリケーションが、コンピューターで動作することを確認してください。

ほかのコンピューターでスキャナーを使用していませんか？

対処方法

複数台のコンピューターから、スキャナー選択ツールで同じスキャナーを選択している場合は、スキャナーを使用するコンピューターでだけ、Button Event Managerのメニューの「ボタンを監視する」にチェックを付けてください。

それでも読み取りを開始できない場合は、以下の対処をしてください。

  • コンピューターの画面右下の通知領域に常駐している画像読み取り用アプリケーションを終了する

  • スキャナーの電源を切断し、再度電源を投入する
