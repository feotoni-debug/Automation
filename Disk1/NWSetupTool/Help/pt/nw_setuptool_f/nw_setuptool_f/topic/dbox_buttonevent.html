Janela [Configurações do botão]

Especifique um aplicativo de digitalização de imagens que deseja iniciar quando um botão em um scanner é pressionado.
Selecione um evento

A partir da lista de botões, selecione um botão para especificar um aplicativo de digitalização de imagens para ser iniciado quando um botão em um scanner é pressionado.

DICA

  • Os nomes dos botões mostrados na lista de botões varia, dependendo do modelo do scanner.

    Para maiores detalhes, consulte o Guia do Operador do scanner.

  • Se usar o Button Event Manager para especificar um aplicativo de digitalização de imagens para o botão de digitalização em um scanner, tome nota do seguinte.

    • Quando o PaperStream ClickScan está em execução

      Independentemente das configurações definidas para o botão de digitalização com o Button Event Manager, uma digitalização é realizada com o PaperStream ClickScan quando o botão de digitalização é pressionado em um scanner.

      Para inicializar outro aplicativo de digitalização de imagem (pressionando o botão de digitalização em um scanner), feche o PaperStream ClickScan. Para maiores detalhes, consulte a Ajuda do PaperStream ClickScan.

    • Quando o PaperStream ClickScan não está em execução e o PaperStream Capture está instalado

      O PaperStream Capture é definido automaticamente para o botão de digitalização em um scanner.

      Se não definir o PaperStream Capture para o botão de digitalização em um scanner, selecione [Nenhum] ou [Execute o programa seguinte] em [Operação].

      Para maiores detalhes sobre como definir um botão no scanner, consulte Configurando as definições para botões em um scanner.

Operação
Iniciar [PaperStream Capture]

Selecione esta opção para iniciar o PaperStream Capture.

Os nomes dos perfis do documento são exibidos na tela de toque ou no painel do operador, dependendo do scanner que estiver usando.

Para maiores detalhes, consulte a Ajuda do PaperStream Capture.

Execute o programa seguinte

Selecione esta opção para executar um programa de sua escolha.

Especifique o diretório de um programa a executar.

Botão [Procurar]

Exibe a janela [Selecionar um aplicativo].

Especifique um programa para executar.

Parâmetros

Podem ser especificados até 255 caracteres para parâmetros.

Para maiores detalhes sobre os parâmetros, consulte o manual do programa a executar.

Nenhum

Selecione esta opção para não executar nenhum programa.

Botão [OK]

Fecha a janela.

As alterações serão salvas.

Botão [Cancelar]

Fecha a janela.

As alterações não serão salvas.
