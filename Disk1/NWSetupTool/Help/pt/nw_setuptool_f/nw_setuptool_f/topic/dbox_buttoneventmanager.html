Menu do Button Event Manager

Os itens do menu seguinte são exibidos quando clica com o botão direito do mouse em na área de notificação localizada na direita da barra de tarefas.
Ver evento do botão

Detecta o movimento para baixo de um botão em um scanner.

Se isto não estiver selecionado, um aplicativo de digitalização de imagens que especificou na Janela [Configurações do botão] não é iniciado quando o botão no scanner é pressionado.

ATENÇÃO

Quando o mesmo scanner for selecionado por mais de um computador, usando a Ferramenta de seleção do scanner, selecione [Ver evento do botão] somente no computador que deseja usar com o scanner.

DICA

Para iniciar o Software Operation Panel pressionando o botão de digitalização no scanner, selecione [Ver evento do botão].

Para obter mais detalhes sobre como um scanner opera (funcionamento) quando o botão de digitalização é pressionado, consulte o Guia do Operador do scanner.

Iniciar esta ferramenta ao efetuar logon

Se esta opção for selecionada, o Button Event Manager será iniciado quando o usuário acessar o Windows.

Quando o Button Event Manager for iniciado, aparece uma mensagem de notificação na área de notificação localizada no lado direito da barra de tarefas.

Ajustar as configurações do botão

Especifique um aplicativo de digitalização de imagens a ser iniciado quando o botão em um scanner é pressionado.

A Janela [Configurações do botão] aparecerá.
