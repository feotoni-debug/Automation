Janela [Ferramenta de configuração do endereço IP]

Altere as configurações da rede de um scanner.
Nome do scanner

Digite um nome do scanner até 64 caracteres.

Os caracteres seguintes estão disponíveis:

  • Caracteres alfanuméricos

  • - (Hífen)

  • _ (Sublinhar)

  • Espaços

    Note que os espaços no início e fim de um nome são excluídos.

A configuração padrão de fábrica para o nome do modelo e o número de série do scanner (Nome do modelo - Número de série).

DICA

  • O número serial do scanner está impresso no rótulo do produto.

    Para maiores detalhes, consulte o Guia do Operador do scanner.

  • Se você habilitar a opção [DNS dinâmico] nas configurações do scanner, insira um nome de scanner com um tamanho de 63 caracteres ou menos.

    Para mais detalhes sobre a opção DNS dinâmico, consulte o Guia do Operador do scanner.

    Recomenda-se não utilizar os seguintes caracteres de meia largura para registrar o nome do scanner no servidor DNS, pois esses caracteres serão convertidos em "-" (hífen).

    • _ (Sublinhar)

    • Espaços

IPv4
Configuração do IPv4

Selecione um método para configurar um endereço IPv4 para um scanner.

  • Automático

    Um endereço IP é atribuído automaticamente a um scanner a partir do servidor DHCP.

    Esta é a configuração padrão de fábrica.

  • Manual

    Atribua um endereço IP manualmente.

Endereço IP

Exibe o endereço IP de um scanner.

Digite um endereço IP para um scanner quando selecionar [Manual] na [Configuração do IPv4].

Máscara de sub-rede

Exibe a máscara de sub-rede para o endereço IP.

Digite uma máscara de sub-rede para o endereço IP quando selecionar [Manual] na [Configuração do IPv4].

Gateway padrão

Exibe o gateway padrão para o endereço IP.

Digite uma gateway padrão para o endereço IP quando selecionar [Manual] na [Configuração do IPv4].

Codificação de rede

Especifique se deseja ou não criptografar as comunicações de rede.

Codificação desligada (HTTP)

Este é um método de transmissão que prioriza a segurança.
