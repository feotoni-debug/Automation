Janela [Definições do IPv6]

Configura um endereço IPv6.
Configuração do IPv6

Selecione um método para configurar um endereço IPv6 para um scanner.

  • Automático

    Um endereço IP é atribuído automaticamente a um scanner a partir do servidor DHCP.

    Esta é a configuração padrão de fábrica.

  • Manual

    Atribua um endereço IP manualmente.

  • Desativar

    Desativa as configurações do endereço IPv6.

Caixa de seleção [Receber pacote RA]

Esta caixa de seleção aparece quando selecionar [Manual] na [Configuração do IPv6].

Selecione isto para ativar um endereço IPv6 que foi gerado automaticamente.

Pode verificar um endereço IPv6 que foi gerado automaticamente em [Endereço IP] em [IPv6] na janela [Ferramenta de configuração do endereço IP].

A caixa de seleção é marcada para a configuração padrão de fábrica.

Endereço IP

Digite um endereço IP para um scanner quando selecionar [Manual] na [Configuração do IPv6].

Extensão do prefixo de subrede

Digite uma extensão do prefixo de subrede para o endereço IP quando selecionar [Manual] na [Configuração do IPv6].

Um valor de 3 a 128 pode ser inserido.

Gateway padrão

Digite uma gateway padrão para o endereço IP quando selecionar [Manual] na [Configuração do IPv6].

Botão [OK]

Fecha a janela.

As alterações são aplicadas à janela [Ferramenta de configuração do endereço IP].

Botão [Cancelar]

Fecha a janela.

As alterações não são aplicadas à janela [Ferramenta de configuração do endereço IP].
