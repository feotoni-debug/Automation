Fluxo da operação

O seguinte mostra o fluxo da operação para usar um aplicativo de digitalização de imagens para digitalizar documentos.

  • Iniciando uma digitalização com um aplicativo de digitalização de imagens

  • Iniciando uma digitalização executando um aplicativo de digitalização de imagens a partir do botão em um scanner

Iniciando uma digitalização com um aplicativo de digitalização de imagens

  • Para fi-8040 ou fi-7300NX

    1. Configure as definições da rede na tela de toque do scanner

      Para maiores detalhes, consulte o Guia do Operador do scanner.

    2. Conecte um scanner em uma rede

      DICA

      Ao usar o fi-7300NX conectado em uma rede que precise de um certificado através de Wi-Fi, o certificado deve ser registrado no scanner antecipadamente. Para maiores detalhes, consulte a seção Registrando certificados em um scanner.

    3. Inicie a Ferramenta de seleção do scanner para selecionar um scanner que deseja usar a partir de um computador

      Para maiores detalhes, consulte a etapa 3 e as etapas subsequentes em Selecionando um scanner que deseja usar.

    4. Em um aplicativo de digitalização de imagem, selecione o scanner conectado a uma LAN com fio ou Wi-Fi

      Os nomes dos scanners conectados a uma LAN com fio ou Wi-Fi são os seguintes:

      • Para o PaperStream IP (TWAIN)/PaperStream IP (TWAIN x64)

        PaperStream IP xxx Net

      • Para PaperStream IP (ISIS) fi-8000 series/PaperStream IP (ISIS) Bundle

        PaperStream_IP xxx Net

      "xxx" indica o nome do modelo do scanner. Para maiores detalhes, consulte a Ajuda do driver do scanner.

      DICA

      Somente fi-7300NX pode ser usado com uma conexão Wi-Fi.

    5. Carregue documentos em um scanner e digitalize-os a partir de um aplicativo de digitalização de imagem

      Para detalhes sobre como carregar um documento, consulte a seção Guia do Operador do scanner.

      DICA

      Mesmo se um scanner for selecionado com a Ferramenta de seleção do scanner, o scanner talvez não apareça no aplicativo de digitalização de imagens que está sendo usado. Para maiores detalhes, consulte a seção Não é possível efetuar uma digitalização a partir do aplicativo de digitalização de imagens.

  • Para os modelos fi-8950, fi-8930, fi-8820, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 ou fi-8250

    1. Conecte um scanner em um dispositivo de rede (como um comutador, um hub ou um router) com um cabo de LAN

      Para maiores detalhes, consulte o Guia do Operador do scanner.

      • Quando um endereço IP é atribuído automaticamente

        Continue com a etapa seguinte.

      • Quando atribuir um endereço IP manualmente

        Inicie a Ferramenta de configuração do endereço IP para atribuir um endereço IP a um scanner.

        Para maiores detalhes, consulte a seção Alterando o endereço IP para um scanner.

    2. Inicie a Ferramenta de seleção do scanner para selecionar um scanner que deseja usar a partir de um computador

      Para maiores detalhes, consulte a etapa 3 e as etapas subsequentes em Selecionando um scanner que deseja usar.

    3. Em um aplicativo de digitalização de imagem, selecione o scanner conectado a uma LAN com fio

      Os nomes dos scanners conectados a uma LAN com fio são os seguintes:

      • Para o PaperStream IP (TWAIN)/PaperStream IP (TWAIN x64)

        PaperStream IP xxx Net

      • Para PaperStream IP (ISIS) fi-8000 Series

        PaperStream_IP xxx Net

      "xxx" indica o nome do modelo do scanner. Para maiores detalhes, consulte a Ajuda do driver do scanner.

    4. Carregue documentos em um scanner e digitalize-os a partir de um aplicativo de digitalização de imagem

      Para detalhes sobre como carregar um documento, consulte a seção Guia do Operador do scanner.

      DICA

      Mesmo se um scanner for selecionado com a Ferramenta de seleção do scanner, o scanner talvez não apareça no aplicativo de digitalização de imagens que está sendo usado. Para maiores detalhes, consulte a seção Não é possível efetuar uma digitalização a partir do aplicativo de digitalização de imagens.

Iniciando uma digitalização executando um aplicativo de digitalização de imagens a partir do botão em um scanner

  • Para fi-8040 ou fi-7300NX

    1. Configure as definições da rede na tela de toque do scanner

      Para maiores detalhes, consulte o Guia do Operador do scanner.

    2. Conecte um scanner em uma rede

      DICA

      Ao usar o fi-7300NX conectado em uma rede que precise de um certificado através de Wi-Fi, o certificado deve ser registrado no scanner antecipadamente. Para maiores detalhes, consulte a seção Registrando certificados em um scanner.

    3. Inicie a Ferramenta de seleção do scanner para selecionar um scanner que deseja usar a partir de um computador

      Para maiores detalhes, consulte a etapa 3 e as etapas subsequentes em Selecionando um scanner que deseja usar.

    4. Inicie o Button Event Manager e especifique um aplicativo de digitalização de imagens a ser iniciado quando o botão no scanner é pressionado

      Para maiores detalhes, consulte a etapa 3 e as etapas subsequentes em Configurando as definições para botões em um scanner.

      ATENÇÃO

      Quando o mesmo scanner for selecionado por mais de um computador, usando a Ferramenta de seleção do scanner, selecione [Ver evento do botão] no menu do Button Event Manager somente no computador que deseja usar com o scanner.

    5. Carregue documentos no scanner e pressione o botão no scanner para digitalizar os documentos

      Para detalhes sobre como carregar um documento, consulte a seção Guia do Operador do scanner.
