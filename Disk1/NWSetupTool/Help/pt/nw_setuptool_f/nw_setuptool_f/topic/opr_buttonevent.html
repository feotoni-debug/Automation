Configurando as definições para botões em um scanner

Esta seção explica como usar o Button Event Manager e especificar um aplicativo de digitalização de imagens para ser iniciado quando um botão em um scanner é pressionado.

ATENÇÃO

Quando o mesmo scanner for selecionado por mais de um computador, usando a Ferramenta de seleção do scanner, selecione [Ver evento do botão] no menu do Button Event Manager somente no computador que deseja usar com o scanner.

DICA

Se usar o Button Event Manager para especificar um aplicativo de digitalização de imagens para o botão de digitalização em um scanner, tome nota do seguinte.

  • Quando o PaperStream ClickScan está em execução

    Independentemente das configurações definidas para o botão de digitalização com o Button Event Manager, uma digitalização é realizada com o PaperStream ClickScan quando o botão de digitalização é pressionado em um scanner.

    Para inicializar outro aplicativo de digitalização de imagem (pressionando o botão de digitalização em um scanner), feche o PaperStream ClickScan. Para maiores detalhes, consulte a Ajuda do PaperStream ClickScan.

  • Quando o PaperStream ClickScan não está em execução e o PaperStream Capture está instalado

    O PaperStream Capture é definido automaticamente para o botão de digitalização em um scanner.

    Se você não definir o PaperStream Capture para o botão de digitalização em um scanner, selecione [Nenhum] ou [Execute o programa seguinte] como [Operação] no Janela [Configurações do botão].

  1. Conecte um scanner em uma rede.

    Para maiores detalhes, consulte o Guia do Operador do scanner.

  2. Ative o scanner a ser selecionado em um aplicativo de digitalização de imagem.

    Inicie a Ferramenta de seleção do scanner e selecione um scanner a ser usado a partir dos scanners conectados em uma rede.

    Para maiores detalhes, consulte a seção Selecionando um scanner que deseja usar.

  3. Configure as definições de digitalização no aplicativo de digitalização de imagem.

    Para mais detalhes, consulte o manual do aplicativo de digitalização de imagens.

  4. Inicie o Button Event Manager.

    Para maiores detalhes, consulte a seção Iniciando o Button Event Manager.

    Quando o Button Event Manager for iniciado, aparece na área de notificação localizada no lado direito da barra de tarefas.

  5. Clique com o botão direito do mouse em .

    A Menu do Button Event Manager aparecerá.

  6. Selecione [Ver evento do botão] no menu.
  7. Clique em [Ajustar as configurações do botão] no menu.

    A Janela [Configurações do botão] aparecerá.

  8. Especifique um aplicativo de digitalização de imagens a ser iniciado quando o botão em um scanner é pressionado.

    Para obter detalhes sobre as configurações, consulte Janela [Configurações do botão].

  9. Clique no botão [OK].
