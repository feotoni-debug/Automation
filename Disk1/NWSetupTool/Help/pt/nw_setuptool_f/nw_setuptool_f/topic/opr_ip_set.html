Alterando o endereço IP para um scanner

Esta seção explica como usar a Ferramenta de configuração do endereço IP para alterar o endereço IP para um scanner.

O endereço IP é exibido na lista de scanners na janela [Ferramenta de seleção do scanner].

O endereço IPv4 ou endereço IPv6 é atribuído automaticamente em um scanner como a configuração padrão de fábrica.

Por exemplo, use a Ferramenta de configuração do endereço IP para alterar o endereço IP de um scanner nos casos seguintes.

  • Quando um scanner não é encontrado na Ferramenta de seleção do scanner

  • Quando a conexão de um scanner em uma rede não usa um servidor DHCP

  • Quando deseja configurar um endereço IP fixo para um scanner

  1. Conecte um scanner em um computador com o cabo USB que é fornecido com o scanner.
  2. Ligue o scanner.

    Para maiores detalhes, consulte o Guia do Operador do scanner.

  3. Inicia a Ferramenta de configuração do endereço IP.

    Para maiores detalhes, consulte a seção Iniciando a Ferramenta de configuração do endereço IP.

    A janela de logon da Ferramenta de configuração do endereço IP é exibida.

    Quando uma senha de administrador não está definida para o scanner, a Janela [Ferramenta de configuração do endereço IP] é exibida. Prossiga para a etapa 5.

  4. Digite a senha de administrador para um scanner e clique no botão [Logon].

    Para obter detalhes sobre a senha de administrador padrão de fábrica, consulte o Guia do Operador do scanner.

    A Janela [Ferramenta de configuração do endereço IP] aparecerá.

  5. Selecione um método para configurar um endereço IP.

    • Endereço IPv4

      Selecione um método para configurar um endereço IP para um scanner em [Configuração do IPv4] em [Rede].

      • Quando selecionar [Automático]

        Prossiga para a etapa 6.

      • Quando selecionar [Manual]

        Digite números apropriados em [Endereço IP], [Máscara de sub-rede] e [Gateway padrão].

    • Endereço IPv6

      1. Clique no botão [Definições do IPv6] em [IPv6] em [Rede].

      2. Selecione um método para configurar um endereço IP para um scanner em [Configuração do IPv6] em Janela [Definições do IPv6].

        • Quando selecionar [Automático] ou [Desativar]

          Clique no botão [OK] e prossiga para a etapa 6.

        • Quando selecionar [Manual]

          Digite números apropriados em [Endereço IP], [Extensão do prefixo de subrede] e [Gateway padrão].

      3. Clique no botão [OK].

  6. Clique no botão [OK].
  7. Desconecte o cabo USB do scanner.
