Não foi encontrado nenhum scanner

Verifique o seguinte:

  • O método de conexão (usado para conectar o scanner) é diferente do método que está definido nas definições do scanner? (fi-7300NX)

  • As configurações da rede do scanner estão configuradas corretamente?

  • O scanner está no meio do processo de início ou processo de inicialização?

  • Outro aplicativo está usando o scanner?

  • As configurações da rede do computador estão configuradas corretamente?

  • O sistema operacional no computador está sendo atualizado ou esperando ser reiniciado?

  • O scanner está conectado na mesma sub-rede de seu computador?

  • As configurações dos dispositivos de rede (como um comutador, um hub ou um router) estão corretas?

  • O status de comunicação entre o scanner e o computador está estável?

Se um scanner não for encontrado após as medidas acima, reinicie o scanner e o computador e, depois, reinicie a Ferramenta de seleção do scanner.

Se um scanner não for exibido no aplicativo de digitalização de imagens, consulte Não é possível efetuar uma digitalização a partir do aplicativo de digitalização de imagens.

O método de conexão (usado para conectar o scanner) é diferente do método que está definido nas definições do scanner? (fi-7300NX)

Solução

Verifique se Wi-Fi ou LAN com fio está configurada para o método de conexão do scanner.

Pode verificar como a seguir.

Na tela de toque do scanner, pressione → [Definições do scanner] → [Como conectar].

As configurações da rede do scanner estão configuradas corretamente?

Solução

  • Para fi-8040 ou fi-7300NX

    Verifique as configurações da rede do scanner.

    Pode verificar como a seguir.

    Na tela de toque do scanner, pressione → [Definições do scanner] → [Rede].

  • Para os modelos fi-8950, fi-8930, fi-8820, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 ou fi-8250

    Use a Ferramenta de configuração do endereço IP para verificar as configurações da rede do scanner.

    Para mais detalhes sobre como iniciar a Ferramenta de configuração do endereço IP, consulte Iniciando a Ferramenta de configuração do endereço IP.

O scanner está no meio do processo de início ou processo de inicialização?

Solução

Verifique se o scanner não está no meio do processo de início ou processo de inicialização.

Para maiores detalhes, consulte o Guia do Operador do scanner.

Outro aplicativo está usando o scanner?

Solução

Saia do outro aplicativo que está usando o scanner.

As configurações da rede do computador estão configuradas corretamente?

Solução

Verifique as configurações de rede do computador.

Para obter detalhes sobre como configurar as configurações de do computador, consulte o manual de seu computador.

O sistema operacional no computador está sendo atualizado ou esperando ser reiniciado?

Solução

Reinicie a Ferramenta de seleção do scanner depois de o sistema operacional no computador ser atualizado ou o computador ser reiniciado.

O scanner está conectado na mesma sub-rede de seu computador?

Mesmo se o scanner estiver conectado na mesma sub-rede de seu computador, talvez ele não seja encontrado.

Solução

Selecione [Procurar a partir do endereço IP do scanner] em Janela [Ferramenta de seleção do scanner] e digite o endereço IP para procurar o scanner.

As configurações dos dispositivos de rede (como um comutador, um hub ou um router) estão corretas?

Solução

Verifique as configurações dos dispositivos de rede (como um comutador, um hub ou um router).

Para obter detalhes sobre como configurar o dispositivo de rede, consulte o manual de seu ponto de acesso sem fio.

O status de comunicação entre o scanner e o computador está estável?

Solução

  • Para fi-8040 ou fi-7300NX

    Verifique o status de comunicação entre o scanner e o computador.

    Pode verificar o status de comunicação entre o scanner e o computador na tela de toque do scanner.

    Pode verificar como a seguir.

    Na tela de toque do scanner, pressione → [Definições do scanner] → [Rede] → [Verificar conexão (Ping)].

  • Para os modelos fi-8950, fi-8930, fi-8820, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 ou fi-8250

    Verifique o status de comunicação entre o scanner e o computador.

    Inicie o aviso de comando em seu computador e execute o comando de ping para verificar o status de comunicação, especificando o endereço IP para o scanner.

    Use a Ferramenta de configuração do endereço IP para verificar o endereço IP para o scanner.

    Para mais detalhes sobre como iniciar a Ferramenta de configuração do endereço IP, consulte Iniciando a Ferramenta de configuração do endereço IP.
