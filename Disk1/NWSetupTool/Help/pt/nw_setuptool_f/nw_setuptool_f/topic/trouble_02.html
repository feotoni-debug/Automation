Não pode executar uma digitalização pressionando o botão no scanner

Verifique o seguinte:

  • O scanner está selecionado na Ferramenta de seleção do scanner?

  • O Button Event Manager foi iniciado?

  • A opção [Ver evento do botão] está selecionada no menu do Button Event Manager?

  • As configurações para o botão no scanner estão corretas?

  • O scanner está sendo usado por outro computador?

O scanner está selecionado na Ferramenta de seleção do scanner?

Solução

Em Janela [Ferramenta de seleção do scanner], verifique se o scanner está selecionado.

O Button Event Manager foi iniciado?

Solução

Verifique se o Button Event Manager foi iniciado.

Quando o Button Event Manager tiver sido for iniciado, aparece na área de notificação localizada no lado direito da barra de tarefas.

Para obter detalhes sobre como iniciar o Button Event Manager, consulte Iniciando o Button Event Manager.

A opção [Ver evento do botão] está selecionada no menu do Button Event Manager?

Solução

Inicie o Button Event Manager e clique com o botão direito no na área de notificação localizada no lado direito da barra de tarefas para exibir Menu do Button Event Manager. Verifique se a opção [Ver evento do botão] está selecionada.

Para obter detalhes sobre como iniciar o Button Event Manager, consulte Iniciando o Button Event Manager.

As configurações para o botão no scanner estão corretas?

Solução

  • Em Janela [Configurações do botão] do Button Event Manager, verifique se a configuração do botão está correta.

  • Verifique se o aplicativo de digitalização de imagens que especificou para o botão no scanner funciona no computador.

O scanner está sendo usado por outro computador?

Solução

Quando o mesmo scanner for selecionado por mais de um computador, usando a Ferramenta de seleção do scanner, selecione [Ver evento do botão] no menu do Button Event Manager somente no computador que deseja usar com o scanner.

Se não puder iniciar uma digitalização após as medidas acima, execute o seguinte:

  • Saia do aplicativo de digitalização da imagem que fica na área de notificação localizada no lado direito da barra de tarefas

  • Desligue o scanner e volte a ligá-lo
