Окно [Настройки кнопки]

Задайте приложение сканирования изображений, которое будет запускаться при нажатии кнопки на сканере.
Выбрать событие

В списке кнопок выберите кнопку на сканере, при нажатии которой будет запускаться приложение сканирования изображений.

СОВЕТ

  • Имена кнопок, отображаемые в списке кнопок, отличаются в зависимости от модели сканера.

    Для получения дополнительной информации смотрите руководство оператора сканера.

  • Если вы используете Button Event Manager для задания приложения сканирования изображений для кнопки сканирования на сканере, обратите внимание на следующее.

    • Если запущен PaperStream ClickScan

      Вне зависимости от настроек, конфигурированных для кнопки сканирования с помощью Button Event Manager, сканирование выполняется с помощью PaperStream ClickScan при нажатии кнопки сканирования на сканере.

      Чтобы запустить другое приложение сканирования изображений (нажатием кнопки сканирования на сканере), выполните выход из PaperStream ClickScan. Для получения дополнительной информации смотрите справку PaperStream ClickScan.

    • Если PaperStream ClickScan не запущен и установлен PaperStream Capture

      PaperStream Capture автоматически задается для кнопки сканирования на сканере.

      Если вы не задали PaperStream Capture для кнопки сканирования на сканере, выберите [Нет] или [Запустить следующую программу] в пункте [Операция].

      Для получения подробной информации о том, как задать кнопку на сканере, смотрите Конфигурация настроек для кнопок на сканере.
