Меню Button Event Manager

Следующие элементы меню отображаются при нажатии правой кнопкой мыши в области уведомлений, расположенной в правом дальнем углу панели задач.
Событие кнопки просмотра

Обнаружение движения кнопки вниз на сканере.

Если эта опция не выбрана, приложение сканирования изображений, которое задано в Окно [Настройки кнопки], не запускается даже при нажатии кнопки на сканере.

ВНИМАНИЕ

Если один и тот же сканер выбирается несколькими компьютерами с помощью Инструмента выбора сканера, выберите [Событие кнопки просмотра] только на компьютере, который вы хотите использовать со сканером.

СОВЕТ

Запустите Software Operation Panel путем нажатия кнопки сканирования на сканере, выберите [Событие кнопки просмотра].

Для получения информации о работе (функциях) сканера при нажатии кнопки на сканере смотрите руководство пользователя сканера.

Запускать этот инструмент при входе

Если выбран этот параметр, Button Event Manager запускается при входе в Windows.

Если запущен Button Event Manager, отобразится уведомление в области уведомлений, расположенной в правом дальнем углу панели задач.
