Измените настройки сети на сканере.
Имя сканера

Введите имя сканера в пределах 64 символов.

Можно использовать следующие символы:

  • Буквенно-числовые символы

  • - (Дефис)

  • _ (Подчеркнутая линия)

  • Пробелы

    Обратите внимание, что пробелы в начале и в конце имени удаляются.

По умолчанию используется имя модели и серийный номер сканера (Имя модели - Серийный номер).

СОВЕТ

  • Серийный номер сканера указан на этикетке изделия.

    Для получения дополнительной информации смотрите руководство оператора сканера.

  • При включении [Динамический DNS] в настройках сканера введите имя сканера длиной не более 63 символа.

    Для получения информации о динамическом DNS смотрите руководство пользователя сканера.

    Рекомендуется не использовать следующие полуширинные символы при регистрации имени сканера на DNS-сервере, поскольку они будут преобразованы в "-" (дефис):

    • _ (Подчеркнутая линия)

    • Пробелы
