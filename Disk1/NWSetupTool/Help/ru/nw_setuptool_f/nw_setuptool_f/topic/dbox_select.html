Окно [Инструмент выбора сканера]

Из подключенных к сети сканеров выберите сканер, который вы хотите использовать с помощью компьютера.
Хотите управлять сканером из приложения?

Отобразится справка.

Список сканеров

Отображение информации о найденных сканерах.

При запуске Инструмента выбора сканера он автоматически выполняет поиск сканеров в заданном для [Метод поиска сканера] диапазоне поиска и отображает названия моделей, названия сканеров и IP-адреса найденных сканеров.

Нажмите имя сканера, который вы хотите использовать с помощью компьютера, чтобы установить флажок. Вы можете выбрать только один сканер.

Если сканер уже выбран, он отобразится в верхней части списка сканеров.

Если сканер, подключенный к сети, не используется, нажмите имя выбранного сканера, чтобы снять флажок.

СОВЕТ

  • Вы также можете дважды щелкнуть сканер в списке сканеров, чтобы выбрать сканер.

    Двойное нажатие сканера позволяет сделать сканер доступным для компьютера и выполнить выход из Инструмента выбора сканера.

  • Для fi-8950, fi-8930, fi-8820, fi-8040, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 или fi-8250 нажатие IP-адреса, отображаемого в [IP-адрес] в списке сканеров, запускает сетевые Настройки сети fi Series (в веб-браузере).

    Для получения сведений о сетевых Настройки сети fi Series (в веб-браузере) смотрите руководство пользователя сканера.

  • Если сканер уже выбран и вы запустили Инструмент выбора сканера или нажали кнопку [Повторить поиск] в окне [Инструмент выбора сканера] на одном из следующих этапов, будет добавлено к выбранному сканеру вместо .

    • Выбранный сканер не подключен в данный момент к сети
    • Выбранный сканер выключен

    • Значение, по которому нее производится поиск сканера, указано в [Диапазон поиска] в [Метод поиска сканера]

      В таком случае если сканер подключен к сети, вы можете использовать сканер как есть.

Метод поиска сканера
Диапазон поиска
IPv4

Поиск сканеров, которые подключены к той же подсети, что и компьютер, с помощью IPv4-адресов.

Это заводская настройка по умолчанию.

IPv6

Поиск сканеров, которые подключены к той же подсети, что и компьютер, с помощью IPv6-адресов.

Для fi-8950, fi-8930, fi-8820, fi-8040, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 или fi-8250 этот параметр можно выбрать для поиска сканеров.

Введите IP-адрес

Выберите этот параметр для поиска сканера путем задания IP-адреса или выберите этот параметр для выбора сканера, подключенного к подсети, отличной от той, к которой подключен компьютер.

В полях ввода введите IP-адрес.

Введите имя

Выберите этот параметр для поиска сканера путем задания имени сканера, зарегистрированного на DNS-сервере.

СОВЕТ

Имя сканера должно быть таким же, как зарегистрированное на DNS-сервере.

В поле ввода введите имя, состоящее из 255 символов.

Можно использовать следующие символы:

  • Буквенно-числовые символы

  • - (Дефис)

  • . (Точка)

Кнопка [Повторить поиск]

Начало поиска сканера.

Не можете найти необходимый сканер?

Отобразится справка.

Кнопка [Задать IP-адрес]

Запуск Инструмента настройки IP-адреса.

Если сканер, который вы хотите использовать с помощью компьютера, не найден, нажмите эту кнопку, чтобы просмотреть имя сканера или IP-адрес сканера.

Чтобы использовать Инструмент настройки IP-адреса, подключите сканер к компьютеру с помощью кабеля USB.

Кнопка [ОК]

Выход из Инструмента выбора сканера.

Изменения сохранятся.

Кнопка [Отмена]

Выход из Инструмента выбора сканера.

Изменения не сохранятся.
