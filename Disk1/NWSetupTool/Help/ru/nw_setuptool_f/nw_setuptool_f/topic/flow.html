Выполнение операции

Далее приводится процесс использования приложения сканирования изображений для сканирования документов.

  • Запуск сканирования из приложения сканирования изображений

  • Запуск сканирования с помощью приложения сканирования изображений нажатием кнопки на сканере

Запуск сканирования из приложения сканирования изображений

  • Для fi-8040 или fi-7300NX

    1. Конфигурация настроек сети на сенсорном экране сканера

      Для получения дополнительной информации смотрите руководство оператора сканера.

    2. Подключение сканера к сети

      СОВЕТ

      При использованоо fi-7300NX, подключенного к сети, которая требует сертификат по Wi-Fi, его необходимо зарегистрировать на сканере заранее. Для получения подробной информации, смотрите Регистрация сертификатов на сканере.

    3. Запустите инструмент выбора сканера, чтобы выбрать сканер для использования на компьютере

      Для получения дополнительной информации смотрите шаг 3 и последующие шаги в Выбор сканера для использования.

    4. В приложении сканирования изображений выберите сканер, подключенный к проводной локальной LAN или Wi-Fi сети

      Имена сканеров, подключенных к проводной локальной LAN или Wi-Fi сети, являются следующими:

      • Для PaperStream IP (TWAIN)/PaperStream IP (TWAIN x64)

        PaperStream IP xxx Net

      • Для PaperStream IP (ISIS) fi-8000 series/PaperStream IP (ISIS) Bundle

        PaperStream_IP xxx Net

      "xxx" обозначает название модели сканера. Дополнительные сведения смотрите в справке драйвера сканера.

      СОВЕТ

      Только fi-7300NX может использоваться с подключением по Wi-Fi.

    5. Загрузите документы в сканер и сканируйте их с помощью приложения сканирования изображений

      Для получения дополнительной информации о загрузке документов смотрите руководство пользователя сканера.

      СОВЕТ

      Даже если сканер выбран с помощью Инструмента выбора сканера, сканер может не отображаться в используемом приложении сканирования изображений. Для получения подробной информации смотрите Невозможно выполнение сканирования с помощью приложения сканирования изображений.

  • Для fi-8950, fi-8930, fi-8820, fi-8190, fi-8290, fi-8170, fi-8270, fi-8150 или fi-8250

    1. Подключите сканер к сетевому устройству (например, концентратору, коммутатору или маршрутизатору) с помощью кабеля LAN

      Для получения дополнительной информации смотрите руководство оператора сканера.

      • Если IP-адрес назначается автоматически

        Перейдите к следующему шагу.

      • Если IP-адрес назначается вручную

        Запустите Инструмент настройки IP-адреса, чтобы назначить сканеру IP-адрес.

        Для получения подробной информации, смотрите Изменение IP-адреса сканера.

    2. Запустите инструмент выбора сканера, чтобы выбрать сканер для использования на компьютере

      Для получения дополнительной информации смотрите шаг 3 и последующие шаги в Выбор сканера для использования.

    3. В приложении сканирования изображений выберите сканер, подключенный к проводной локальной сети LAN

      Имена сканеров, подключенных к проводной локальной сети LAN, являются следующими:

      • Для PaperStream IP (TWAIN)/PaperStream IP (TWAIN x64)

        PaperStream IP xxx Net

      • Для PaperStream IP (ISIS) fi-8000 Series

        PaperStream_IP xxx Net

      "xxx" обозначает название модели сканера. Дополнительные сведения смотрите в справке драйвера сканера.

    4. Загрузите документы в сканер и сканируйте их с помощью приложения сканирования изображений

      Для получения дополнительной информации о загрузке документов смотрите руководство пользователя сканера.

      СОВЕТ

      Даже если сканер выбран с помощью Инструмента выбора сканера, сканер может не отображаться в используемом приложении сканирования изображений. Для получения подробной информации смотрите Невозможно выполнение сканирования с помощью приложения сканирования изображений.

Запуск сканирования с помощью приложения сканирования изображений нажатием кнопки на сканере

    1. Конфигурация настроек сети на сенсорном экране сканера

      Для получения дополнительной информации смотрите руководство оператора сканера.

    2. Подключение сканера к сети

      СОВЕТ

      При использованоо fi-7300NX, подключенного к сети, которая требует сертификат по Wi-Fi, его необходимо зарегистрировать на сканере заранее. Для получения подробной информации, смотрите Регистрация сертификатов на сканере.

    3. Запустите инструмент выбора сканера, чтобы выбрать сканер для использования на компьютере

      Для получения дополнительной информации смотрите шаг 3 и последующие шаги в Выбор сканера для использования.

    4. Запустите Button Event Manager и задайте приложение сканирования изображений для запуска при нажатии кнопки на сканере

      Для получения дополнительной информации смотрите шаг 3 и последующие шаги в Конфигурация настроек для кнопок на сканере.

      ВНИМАНИЕ

      Если один и тот же сканер выбирается несколькими компьютерами с помощью Инструмента выбора сканера, выберите [Событие кнопки просмотра] в меню Button Event Manager только на компьютере, который вы хотите использовать со сканером.

    5. Загрузите документы в сканер и нажмите кнопку на сканере для сканирования документов

      Для получения дополнительной информации о загрузке документов смотрите руководство пользователя сканера.
