Конфигурация настроек для кнопок на сканере

В данном разделе описывается использование Button Event Manager и процесс задания приложения сканирования изображений для запуска при нажатии кнопки на сканере.

ВНИМАНИЕ

Если один и тот же сканер выбирается несколькими компьютерами с помощью Инструмента выбора сканера, выберите [Событие кнопки просмотра] в меню Button Event Manager только на компьютере, который вы хотите использовать со сканером.

СОВЕТ

Если вы используете Button Event Manager для задания приложения сканирования изображений для кнопки сканирования на сканере, обратите внимание на следующее.

  • Если запущен PaperStream ClickScan

    Вне зависимости от настроек, конфигурированных для кнопки сканирования с помощью Button Event Manager, сканирование выполняется с помощью PaperStream ClickScan при нажатии кнопки сканирования на сканере.

    Чтобы запустить другое приложение сканирования изображений (нажатием кнопки сканирования на сканере), выполните выход из PaperStream ClickScan. Для получения дополнительной информации смотрите справку PaperStream ClickScan.

  • Если PaperStream ClickScan не запущен и установлен PaperStream Capture

    PaperStream Capture автоматически задается для кнопки сканирования на сканере.

    Если вы не задали PaperStream Capture для кнопки сканирования на сканере, выберите [Нет] или [Запустить следующую программу] в пункте [Операция] в Окно [Настройки кнопки].

  1. Подключите сканер к сети.

    Для получения дополнительной информации смотрите руководство оператора сканера.

  2. Активируйте сканер для выбора в приложении сканирования изображений.

    Запустите Инструмент выбора сканера и выберите сканер для использования из списка сканеров, подключенных к сети.

    Для получения подробной информации, смотрите Выбор сканера для использования.

  3. Конфигурируйте настройки сканирования в изображении сканирования изображений.

    Для получения дополнительной информации смотрите руководство к приложению сканирования изображения.

  4. Запустите Button Event Manager.

    Для получения подробной информации, смотрите Запуск Button Event Manager.

    Если запущен Button Event Manager, отобразится в области уведомлений, расположенной в правом дальнем углу панели задач.

  5. Нажмите правой кнопкой мыши.

    Отобразится Меню Button Event Manager.

  6. Выберите [Событие кнопки просмотра] в меню.
  7. Нажмите [Конфигурация настроек кнопки] в меню.

    Отобразится Окно [Настройки кнопки].

  8. Задайте приложение сканирования изображений, которое будет запускаться при нажатии кнопки на сканере.

    Для получения дополнительной информации о настройках смотрите Окно [Настройки кнопки].

  9. Нажмите кнопку [OK].
