Изменение IP-адреса сканера

В данном разделе описывается процесс использования Инструмента настройки IP-адреса для изменения IP-адреса сканера.

IP-адрес отображается в списке сканеров в окне [Инструмент выбора сканера].

IPv4 или IPv6-адрес назначаются сканеру автоматически как заводская настройка по умолчанию.

Например, используйте Инструмент настройки IP-адреса для изменения IP-адреса сканера в следующих случаях.

  • Если сканер не найден в Инструменте выбора сканера

  • При подключении сканера к сети, где не используется сервер DHCP

  • Если вы хотите задать фиксированный IP-адрес сканеру

  1. Подключите сканер к компьютеру с помощью кабеля USB, который прилагается к сканеру.
  2. Включите сканер.

    Для получения дополнительной информации смотрите руководство оператора сканера.

  3. Запуск Инструмента настройки IP-адреса.

    Для получения подробной информации, смотрите Запуск Инструмента настройки IP-адреса.

    Отобразится окно входа в Инструмент настройки IP-адреса.

    Если для сканера не задан пароль администратора, отобразится Окно [Инструмент настройки IP-адреса]. Перейдите к шагу 5.

  4. Введите пароль администратора сканера и нажмите кнопку [Вход].

    Для получения дополнительной информации о пароле администратора по умолчанию смотрите руководство пользователя сканера.

    Отобразится Окно [Инструмент настройки IP-адреса].

  5. Выберите способ задания IP-адреса.

    • IPv4-адрес

      Выберите способ задания IP-адреса сканера в пункте [Конфигурация IPv4] в [Сеть].

      • При выборе [Авто]

        Перейдите к шагу 6.

      • При выборе [Вручную]

        Введите соответствующие числа в пунктах [IP-адрес], [Маска подсети] и [Шлюз по умолчанию].

    • IPv6-адрес

      1. Нажмите кнопку [Настройки IPv6] в [IPv6] в [Сеть].

      2. Выберите способ задания IP-адреса сканера в пункте [Конфигурация IPv6] в Окно [Настройки IPv6].

        • При выборе [Авто] или [Отключить]

          Нажмите кнопку [OK] и перейдите к шагу 6.

        • При выборе [Вручную]

          Введите соответствующие числа в пунктах [IP-адрес], [Длина префикса подсети] и [Шлюз по умолчанию].

      3. Нажмите кнопку [ОК].

  6. Нажмите кнопку [ОК].
  7. Отключите кабель USB от сканера.
