Инструмент настройки IP-адреса

В данном разделе описываются сообщения об ошибках, которые могут отображаться при использовании Инструмента настройки IP-адреса, и приводится их решение.
  • Подключите сканер к компьютеру с помощью кабеля USB.
  • Подключайте только один сканер.
  • Ошибка коммуникации.
  • В имени сканера содержатся неподдерживаемые символы.
  • Зарезервированный Ip-адрес не может быть указан в качестве IP-адреса.
  • Зарезервированный адрес не может быть указан для маски подсети.
  • IP-адрес или маска подсети недействительны.
  • IP-адрес имеет неверный формат.
  • Длина префикса подсети имеет неверный формат.
  • Зарезервированный адрес не может использоваться для шлюза по умолчанию.
  • Шлюз по умолчанию имеет неверный формат.
  • Шлюз по умолчанию или маска подсети недействительны.
  • Не выполнен ввод имени сканера.
  • Этот сканер используется другим пользователем или приложением.
  • Сбой запуска программы.
  • Сбой при входе в систему.
  • Файл справки не найден.
