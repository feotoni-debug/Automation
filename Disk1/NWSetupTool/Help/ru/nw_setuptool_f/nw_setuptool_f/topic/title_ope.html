Использование

В данном разделе описывается эксплуатация каждого инструмента в Network Setup Tool for fi Series.

Поддерживаемые модели сканера отличаются в зависимости от инструмента, который используется для модели. Для получения информации о моделях сканера, которые поддерживаются каждым инструментом, смотрите Поддерживаемые модели сканера.

ВНИМАНИЕ

Если сканер выполняет сканирование, настройки невозможно конфигурировать с помощью Инструмента выбора сканера, Инструмента настройки IP-адреса и Инструмента регистрации сертификатов.
