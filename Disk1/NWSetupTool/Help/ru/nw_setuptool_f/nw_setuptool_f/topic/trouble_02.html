Невозможно выполнить сканирование нажатием кнопки на сканере

Проверьте следующее:

  • Выбран ли сканер в Инструменте выбора сканера?

  • Запущен ли Button Event Manager?

  • Выбрано ли [Событие кнопки просмотра] в меню Button Event Manager?

  • Правильно ли выполнены настройки кнопки на сканере?

  • Используется ли сканер на другом компьютере?

Выбран ли сканер в Инструменте выбора сканера?

Решение

В Окно [Инструмент выбора сканера] убедитесь, что сканер выбран.

Запущен ли Button Event Manager?

Решение

Убедитесь, что Button Event Manager запущен.

Если Button Event Manager запущен, отобразится в области уведомлений, расположенной в правом дальнем углу панели задач.

Для получения дополнительной информации о запуске Button Event Manager смотрите Запуск Button Event Manager.

Выбрано ли [Событие кнопки просмотра] в меню Button Event Manager?

Решение

Запустите Button Event Manager и нажмите правой кнопкой мыши в области уведомлений, расположенной в правом дальнем углу панели задач, для отображения Меню Button Event Manager. Убедитесь, что выбран [Событие кнопки просмотра].

Для получения дополнительной информации о запуске Button Event Manager смотрите Запуск Button Event Manager.

Правильно ли выполнены настройки кнопки на сканере?

Решение

  • В Окно [Настройки кнопки] Button Event Manager убедитесь, что кнопка настроена правильно.

  • Убедитесь, что заданное для кнопки на сканере приложение сканирования изображений запущено на компьютере.

Используется ли сканер на другом компьютере?

Решение

Если один и тот же сканер выбирается несколькими компьютерами с помощью Инструмента выбора сканера, выберите [Событие кнопки просмотра] в меню Button Event Manager только на компьютере, который вы хотите использовать со сканером.

Если вы не сможете начать сканирование после выполнения указанных выше действий, выполните следующее:

  • Выйдите из приложения сканирования изображения, которое отображено в области уведомлений, расположенной в правом дальнем углу панели

  • Выключите сканер и снова включите его
