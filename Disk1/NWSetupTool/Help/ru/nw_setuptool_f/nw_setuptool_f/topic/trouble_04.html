Настроена ли на прокси-сервере настройка прокси WinHTTP?

Решение

Измените настройки прокси WinHTTP, чтобы вы имели доступ к сканеру с компьютера.

Измените настройки прокси WinHTTP по следующей процедуре.

  1. Запустите окно командной строки как пользователь с правами администратора компьютера.

  2. Выполните следующую команду для проверки имени прокси-сервера и доступных номеров портов.

    netsh winhttp show proxy

    СОВЕТ

    Имя прокси-сервера и доступные номера портов отобразятся следующим образом.

    "Имя прокси-сервера: Номера портов"

  3. Выполните одну из следующих команд.

    • Если прокси-сервер уже задан

      Конфигурируйте настройку, чтобы компьютер мог получить доступ к сканеру без использования прокси-сервера.

      netsh winhttp set proxy proxy-server="XXXXXX:YYYY" bypass-list=ZZZ.ZZZ.ZZZ.ZZZ

      XXXXXX: Имя прокси-сервера

      YYYY: Список номеров портов для использования

      ZZZ.ZZZ.ZZZ.ZZZ: IP-адрес для сканера (*1)(*2)

    • Если прокси-сервер не задан

      При сбросе настроек компьютер, возможно, сможет получить доступ к сканеру.

      netsh winhttp reset proxy
*1:

Вы можете проверить IP-адрес сканера на сенсорном экране или панели управления сканера или в Инструменте настройки IP-адреса.
*2:

Здесь формат IPv4-адреса использован в качестве примера.

Для IPv6-адреса используется следующий формат.

ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ
