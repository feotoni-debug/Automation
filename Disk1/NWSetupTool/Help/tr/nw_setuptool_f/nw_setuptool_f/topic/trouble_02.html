Tarayıcıdaki Düğmeye Basarak Tarama Yapılamıyor

Şunları kontrol edin:

  • Tarayıcı, Tarayıcı Seçme Aracı'nda seçilmiş mi?

  • Button Event Manager başlatıldı mı?

  • Button Event Manager'ın menüsünde [Tuş olayını izle] seçilmiş mi?

  • Tarayıcıdaki düğme ayarları doğru mu?

  • Tarayıcı başka bir bilgisayar tarafından mı kullanılıyor?

Tarayıcı, Tarayıcı Seçme Aracı'nda seçilmiş mi?

Çözüm

[Tarayıcı Seçme Aracı] Penceresi öğesinde tarayıcının seçilmiş olduğunu kontrol edin.

Button Event Manager başlatıldı mı?

Çözüm

Button Event Manager'ın başlatıldığını kontrol edin.

Button Event Manager başlatıldığında görev çubuğunun en sağında bulunan bildirim alanında gösterilir.

Button Event Manager'ın başlatılmasıyla ilgili ayrıntılar için bkz Button Event Manager'ı başlatma.

Button Event Manager'ın menüsünde [Tuş olayını izle] seçilmiş mi?

Çözüm

Button Event Manager'ı başlatın ve Button Event Manager'ın menüsü öğesini görüntülemek için görev çubuğunun en sağında bulunan bildirim alanında öğesine sağ tıklayın. [Tuş olayını izle] öğesinin seçilmiş olduğunu kontrol edin.

Button Event Manager'ın başlatılmasıyla ilgili ayrıntılar için bkz Button Event Manager'ı başlatma.

Tarayıcıdaki düğme ayarları doğru mu?

Çözüm

  • Button Event Manager'ın [Tuş ayarları] Penceresi öğesinde tuş ayarının doğru olduğunu kontrol edin.

  • Tarayıcıdaki düğme için belirlediğiniz görüntü tarama uygulamasının bilgisayarda çalışıp çalışmadığını kontrol edin.

Tarayıcı başka bir bilgisayar tarafından mı kullanılıyor?

Çözüm

Tarayıcı Seçme Aracı kullanılarak aynı tarayıcı birden fazla bilgisayar tarafından seçilmişse, sadece tarayıcıyı birlikte kullanmak istediğiniz bilgisayar üzerindeki Button Event Manager menüsünde [Tuş olayını izle] seçeneğini seçin.

Yukarıdaki önlemler alındıktan sonra bir tarama işlemini başlatamıyorsanız, aşağıdakileri yapın:

  • Görev çubuğunun sağ kenarında bulunan bildirim alanındaki görüntü tarama uygulamasından çıkın

  • Tarayıcıyı kapatın ve tekrar açın
