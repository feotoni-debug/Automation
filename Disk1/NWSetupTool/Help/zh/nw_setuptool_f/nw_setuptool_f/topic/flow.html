操作流程

以下为使用图像扫描应用程序扫描文档时的操作流程。

  • 在图像扫描应用程序中进行扫描

  • 使用按下扫描仪上的按钮后启动的图像扫描应用程序进行扫描

在图像扫描应用程序中进行扫描

  • 对于fi-8040或fi-7300NX

    1. 在扫描仪触摸屏上配置网络设置

      详情请参阅扫描仪的操作指南。

    2. 将扫描仪连接至网络

      提示

      使用通过Wi-Fi连接到需要证书的网络的fi-7300NX时，必须事先在扫描仪上注册证书。详情请参阅在扫描仪上注册证书。

    3. 启动扫描仪选择工具选择想要在电脑上使用的扫描仪

      详情请参阅选择想要使用的扫描仪的步骤3及其之后的步骤。

    4. 在图像扫描应用程序中，选择已连接到有线LAN或Wi-Fi的扫描仪

      连接到有线LAN或Wi-Fi的扫描仪的名称如下：

      • 对于PaperStream IP (TWAIN)/PaperStream IP (TWAIN x64)

        PaperStream IP xxx Net

      • 对于PaperStream IP (ISIS) fi-8000 series/PaperStream IP (ISIS) Bundle

        PaperStream_IP xxx Net

      "xxx"表示扫描仪的机型名称。详情请参阅扫描仪驱动程序的帮助。

      提示

      仅fi-7300NX可使用Wi-Fi连接。

    5. 将文档放入扫描仪并通过图像扫描应用程序进行扫描

      有关如何放入文档的详情，请参阅扫描仪的操作指南。

      提示

      即使通过扫描仪选择工具选择了扫描仪，扫描仪也可能不会出现在正在使用的图像扫描应用程序中。详情请参阅无法从图像扫描应用程序执行扫描。

  • 对于fi-8950、fi-8930、fi-8820、fi-8190、fi-8290、fi-8170、fi-8270、fi-8150或fi-8250

    1. 通过LAN电缆将扫描仪连接至网络设备（例如交换机、集线器或路由器）

      详情请参阅扫描仪的操作指南。

      • 已自动分配IP地址时

        前往下一步。

      • 手动分配IP地址时

        启动IP地址设置工具为扫描仪分配IP地址。

        详情请参阅更改扫描仪的IP地址。

    2. 启动扫描仪选择工具选择想要在电脑上使用的扫描仪

      详情请参阅选择想要使用的扫描仪的步骤3及其之后的步骤。

    3. 在图像扫描应用程序中，选择已连接到有线LAN的扫描仪

      连接到有线LAN的扫描仪的名称如下：

      • 对于PaperStream IP (TWAIN)/PaperStream IP (TWAIN x64)

        PaperStream IP xxx Net

      • 对于PaperStream IP (ISIS) fi-8000 Series

        PaperStream_IP xxx Net

      "xxx"表示扫描仪的机型名称。详情请参阅扫描仪驱动程序的帮助。

    4. 将文档放入扫描仪并通过图像扫描应用程序进行扫描

      有关如何放入文档的详情，请参阅扫描仪的操作指南。

      提示

      即使通过扫描仪选择工具选择了扫描仪，扫描仪也可能不会出现在正在使用的图像扫描应用程序中。详情请参阅无法从图像扫描应用程序执行扫描。

使用按下扫描仪上的按钮后启动的图像扫描应用程序进行扫描

      详情请参阅扫描仪的操作指南。

      提示

      使用通过Wi-Fi连接到需要证书的网络的fi-7300NX时，必须事先在扫描仪上注册证书。详情请参阅在扫描仪上注册证书。

    3. 启动扫描仪选择工具选择想要在电脑上使用的扫描仪

      详情请参阅选择想要使用的扫描仪的步骤3及其之后的步骤。

    4. 启动Button Event Manager并指定按下扫描仪上的按钮后启动的图像扫描应用程序

      详情请参阅为扫描仪上的按钮配置设置的步骤3及其之后的步骤。

      注意

      在多台电脑上使用扫描仪选择工具选择了相同的扫描仪时，请仅在想要使用扫描仪的电脑上选择Button Event Manager菜单中的[监视按钮事件]。

    5. 将文档放入扫描仪，然后按下扫描仪上的按钮扫描文档

      有关如何放入文档的详情，请参阅扫描仪的操作指南。
