为扫描仪上的按钮配置设置

本节将说明如何使用Button Event Manager并指定按下扫描仪上的按钮后启动的图像扫描应用程序。

注意

在多台电脑上使用扫描仪选择工具选择了相同的扫描仪时，请仅在想要使用扫描仪的电脑上选择Button Event Manager菜单中的[监视按钮事件]。

提示

如果使用Button Event Manager为扫描仪上的扫描按钮指定图像扫描应用程序，请注意以下要点。

  • 当PaperStream ClickScan正在运行时

    无论使用Button Event Manager为扫描按钮配置的设置为何，按下扫描仪上的扫描按钮时均会通过PaperStream ClickScan执行扫描。

    若要（通过按下扫描仪上的扫描按钮）启动其他图像扫描应用程序，请退出PaperStream ClickScan。详情请参阅PaperStream ClickScan帮助。

  • 当PaperStream ClickScan未在运行且安装了PaperStream Capture时

    自动为扫描仪上的扫描按钮设置PaperStream Capture。

    如果您不为扫描仪上的扫描按钮设置PaperStream Capture，请针对[按钮设置]窗口中的[操作]选择[无效]或[运行以下程序]。

  1. 将扫描仪连接至网络。

    详情请参阅扫描仪的操作指南。

  2. 在图像扫描应用程序中启用将要选择的扫描仪。

    启动扫描仪选择工具并从已连接到网络的扫描仪中选择要使用的扫描仪。

    详情请参阅选择想要使用的扫描仪。

  3. 在图像扫描应用程序中配置扫描设置。

    详情请参阅图像扫描应用程序的指南。

  4. 启动Button Event Manager。

    详情请参阅启动Button Event Manager。

    启动Button Event Manager后，将出现在位于任务栏最右端的通知区域中。

  5. 右键单击。

    将出现Button Event Manager菜单。

  6. 选择菜单上的[监视按钮事件]。
  7. 单击菜单上的[配置按钮设置]。

    将出现[按钮设置]窗口。

  8. 指定要在按下扫描仪上的按钮后启动的图像扫描应用程序。

    有关设置的详情，请参阅[按钮设置]窗口。

  9. 单击[确定]按钮。
