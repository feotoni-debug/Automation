概述

Network Setup Tool for fi Series是一款应用程序，用于将fi Series的图像扫描仪连接至网络以便使用扫描仪。

Network Setup Tool for fi Series包含以下工具。

支持的扫描仪机型因用于该机型的工具而异。请事先确认正在使用的扫描仪机型名称是各工具支持的扫描仪机型名称之一。有关各工具支持的扫描仪机型的详情，请参阅支持的扫描仪机型。

扫描仪选择工具

此工具用于选择想要在电脑上使用的扫描仪。

可从已连接到网络的多台扫描仪中选择其中一台。

选择fi-8950、fi-8930、fi-8820、fi-8040、fi-8190、fi-8290、fi-8170、fi-8270、fi-8150或fi-8250时，还可执行以下操作。

  • 通过[扫描仪选择工具]窗口（在网页浏览器中）启动fi Series网络设置，以配置扫描仪设置

  • 从电脑上启动Software Operation Panel，以配置扫描仪设置

有关fi Series网络设置（在网页浏览器中）和Software Operation Panel的详情，请参阅扫描仪的操作指南。

IP地址设置工具

此工具用于设置IP地址、扫描仪名称、安全性相关信息和其他网络信息。

证书注册工具

此工具用于在扫描仪上注册证书，以便通过Wi-Fi将扫描仪连接至需要证书的网络。

在扫描仪上注册证书后，请在扫描仪的触摸屏上配置Wi-Fi设置。

可以注册的证书如下：

  • 客户证书：PKCS#12格式文件（*.p12、*.pfx）

  • CA证书：CA证书文件（*.cer、*.crt、*.der、*.pem）

Button Event Manager

此工具用于指定想要在按下扫描仪上的按钮后启动的图像扫描应用程序。

需使用扫描仪选择工具设置已连接到网络的扫描仪，以在电脑中使用。
