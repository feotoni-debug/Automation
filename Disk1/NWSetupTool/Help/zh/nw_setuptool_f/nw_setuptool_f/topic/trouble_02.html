无法通过按下扫描仪上的按钮执行扫描

请检查以下项目：

  • 是否已在扫描仪选择工具中选择了该扫描仪？

  • 是否已启动Button Event Manager？

  • 是否已在Button Event Manager的菜单中选择了[监视按钮事件]？

  • 扫描仪上的按钮设置是否正确？

  • 其他电脑是否正在使用该扫描仪？

是否已在扫描仪选择工具中选择了该扫描仪？

解决方案

请在[扫描仪选择工具]窗口中确认已选择了该扫描仪。

是否已启动Button Event Manager？

解决方案

确认Button Event Manager已启动。

启动Button Event Manager后，将出现在位于任务栏最右端的通知区域中。

有关如何启动Button Event Manager的详情，请参阅启动Button Event Manager。

是否已在Button Event Manager的菜单中选择了[监视按钮事件]？

解决方案

启动Button Event Manager，然后右键单击位于任务栏最右端通知区域中的以显示Button Event Manager菜单。确认已选择了[监视按钮事件]。

有关如何启动Button Event Manager的详情，请参阅启动Button Event Manager。

扫描仪上的按钮设置是否正确？

解决方案

  • 在Button Event Manager的[按钮设置]窗口中确认已正确设置了按钮。

  • 确认为扫描仪上按钮指定的图像扫描应用程序在电脑上运行。

其他电脑是否正在使用该扫描仪？

解决方案

在多台电脑上使用扫描仪选择工具选择了相同的扫描仪时，请仅在想要使用扫描仪的电脑上选择Button Event Manager菜单中的[监视按钮事件]。

如采取上述措施后仍无法开始扫描，请执行以下操作：

  • 退出位于任务栏最右端的通知区域中的图像扫描应用程序

  • 关闭扫描仪的电源后再重新打开电源
