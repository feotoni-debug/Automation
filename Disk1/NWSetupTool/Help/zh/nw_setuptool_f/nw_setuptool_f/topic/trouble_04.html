是否已为WinHTTP代理设置代理服务器？

解决方案

更改WinHTTP代理设置，以便您可以从电脑访问扫描仪。

按照以下步骤更改WinHTTP代理设置。

  1. 在电脑上以具有管理员权限的用户身份启动指令提示窗口。

  2. 运行以下指令，查看要使用的代理服务器名称和端口号码。

    netsh winhttp show proxy

    提示

    要使用的代理服务器名称和端口号码将如下显示。

    "代理服务器名称：端口号码"

  3. 运行以下指令之一。

    • 已设置代理服务器时

      配置设置，使电脑无需使用代理服务器即可访问扫描仪。

      netsh winhttp set proxy proxy-server="XXXXXX:YYYY" bypass-list=ZZZ.ZZZ.ZZZ.ZZZ

      XXXXXX：代理服务器名称

      YYYY：要使用的端口号码

      ZZZ.ZZZ.ZZZ.ZZZ：扫描仪的IP地址（*1）（*2）

    • 未设置代理服务器时

      如果重设设置，电脑也许就能访问扫描仪。

      netsh winhttp reset proxy
*1：

可以在扫描仪的触摸屏或操作面板上，或在IP地址设置工具中查看扫描仪的IP地址。
*2：

此处以IPv4地址格式为例。

IPv6地址使用以下格式。

ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ
