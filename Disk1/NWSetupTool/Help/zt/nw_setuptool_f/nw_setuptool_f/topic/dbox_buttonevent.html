[按鈕設定] 視窗

指定在按下掃描器上的按鈕時所啟動的影像掃描應用程式。
選擇事件

由按鈕清單中選擇按鈕，以指定在按下掃描器上的按鈕時所啟動的影像掃描應用程式。

提示

  • 按鈕清單中顯示的按鈕名稱依據掃描器機型而定。

    關於詳細資料，請參閱掃描器的《操作指南》。

  • 若使用 Button Event Manager 指定掃描器按鈕的影像掃描應用程式，請參閱下述。

    • PaperStream ClickScan 執行中

      無論使用 Button Event Manager 為掃描按鈕指定何種設定，在按下掃描器上的掃描按鈕時，將會使用 PaperStream ClickScan 執行掃描。

      若要 (在按下掃描器上的掃描按鈕時) 啟動其他影像掃描應用程式，請結束 PaperStream ClickScan。關於詳細資訊，請參閱 PaperStream ClickScan 說明。

    • PaperStream ClickScan 非執行中但已安裝 PaperStream Capture 時

      掃描器上的掃描按鈕將自動設定為 PaperStream Capture。

      若不將掃描器上的掃描按鈕設定為 PaperStream Capture，請在 [操作] 中選擇 [無] 或 [執行以下程式]。

      關於如何設定掃描器上的按鈕的詳細資訊，請參閱 指定掃描器上的按鈕設定。

操作
啟動 [PaperStream Capture]

選擇此項可啟動 PaperStream Capture。

依據您使用的掃描器而定，文件設定檔名稱將顯示於觸控螢幕或操作面板上。

關於詳細資訊，請參閱《PaperStream Capture 說明》。

執行以下程式

選擇此項可執行您自選的程式。

請指定要執行程式的路徑。

[瀏覽] 按鈕

會顯示 [請選擇應用程式] 視窗。

請指定要執行的程式。

參數

最多可將參數指定為 255 個字元。

關於參數的詳細資訊，請參閱要執行程式的手冊。

無

選擇此項將不執行任何程式。
