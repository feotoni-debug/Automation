Button Event Manager 功能表

在工作列右端的通知區域中的 上按一下滑鼠右鍵，將會顯示以下功能表項目。
監看按鈕事件

將偵測掃描器上的按鈕的下壓動作。

若未選擇此項，在按下掃描器上的按鈕時，您在 [按鈕設定] 視窗 中指定的影像掃描應用程式不會啟動。

注意事項

若有超過一台電腦使用掃描器選擇工具來選擇同一台掃描器，請只在要使用掃描器的該台電腦上選擇 [監看按鈕事件]。

提示

若要透過按下掃描器上的掃描按鈕來啟動 Software Operation Panel，請選取 [監看按鈕事件]。

關於按下掃描器上的掃描按鈕時，掃描器如何操作 (功能) 的詳細資訊，請參閱掃描器《操作指南》。

登入時啟動本工具

若選擇此項，在登入 Windows 時，將會啟動 Button Event Manager。

Button Event Manager 啟動時，通知訊息將顯示於工作列右端的通知區域中。

指定按鈕的設定

指定在按下掃描器上的按鈕時所啟動的影像掃描應用程式。

會出現 [按鈕設定] 視窗。

說明

會顯示說明。

版本資訊

會顯示版本資訊。

結束

會結束 Button Event Manager。
