變更掃描器的網路設定。
掃描器名稱

輸入 64 個字元以內的掃描器名稱。

可使用以下字元：

  • 英數字元

  • 「-」(連字號)

  • 「_」(底線)

  • 空格

    請注意，在名稱開頭與結尾的空格會被刪除。

出廠預設值為掃描器的機型名稱和序號 (機型名稱 - 序號)。

提示

  • 掃描器的序號印在產品標籤上。

    關於詳細資料，請參閱掃描器的《操作指南》。

  • 如果您啟用掃描器設定中的 [動態 DNS]，請輸入掃描器名稱，長度不超過 63 個字元。

    關於動態 DNS 的詳細資料，請參閱您掃描器的《操作指南》。

    建議您在 DNS 伺服器上登錄掃描器名稱時，不要使用下列半形字元，因為這些字元將會轉換為「-」(連字號)。

    • 「_」(底線)

    • 空格

IPv4 設定

選擇設定掃描器 IPv4 位址的方式。

  • 自動

    DHCP 伺服器將自動指派 IP 位址給掃描器。

    這是出廠預設設定。

    手動指派 IP 位址。
