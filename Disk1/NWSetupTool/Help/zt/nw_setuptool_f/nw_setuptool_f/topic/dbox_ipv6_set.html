[IPv6 設定] 視窗

設定 IPv6 位址。
IPv6 設定

選擇設定掃描器的 IPv6 位址的方式。

  • 自動

    DHCP 伺服器將自動指派 IP 位址給掃描器。

    這是出廠預設設定。

  • 手動

    手動指派 IP 位址。

  • 不啟用

    不啟用 IPv6 位址設定。

[接收路由器通告封包] 核取方塊

若在 [IPv6 設定] 中選擇 [手動]，將會出現此核取方塊。

選擇此項以啟用自動生成的 IPv6 位址。

您可在 [IP 位址設定工具] 視窗的 [IPv6] 下的 [IP 位址] 中，確認自動生成的 IPv6 位址。

在出廠預設值設定中，此核取方塊為選取。

IP 位址

若在 [IPv6 設定] 中選擇 [手動]，請輸入掃描器的 IP 位址。

子網路首碼長度

若在 [IPv6 設定] 中選擇 [手動]，請輸入 IP 位址的子網路首碼長度。

可輸入 3 到 128 的值。

預設閘道

若在 [IPv6 設定] 中選擇 [手動]，請輸入 IP 位址的預設閘道。

[確定] 按鈕

關閉視窗。

變更將會套用至 [IP 位址設定工具] 視窗。

[取消] 按鈕

關閉視窗。

變更不會套用至 [IP 位址設定工具] 視窗。
