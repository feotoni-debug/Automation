[掃描器選擇工具] 視窗

由連線至網路的掃描器中，選擇要在電腦上使用的掃描器。
您要由應用程式操作掃描器嗎？

會顯示說明。

掃描器清單

會顯示搜尋到的掃描器資訊。

啟動掃描器選擇工具時，該工具將自動在 [搜尋掃描器的方法] 所設定的搜尋範圍內搜尋掃描器，並顯示找到的掃描器機型名稱、掃描器名稱以及掃描器的 IP 位址。

由電腦按一下您要用的掃描器名稱來選擇核取方塊。僅可選擇一台掃描器。

若掃描器已被選擇，掃描器將會顯示在掃描器清單最上方。

若未使用連線至網路的掃描器，按一下所選掃描器的名稱來清除打勾標記。

提示

  • 您也可在掃描器清單中按兩下掃描器來選擇該掃描器。

    按兩下掃描器可讓電腦使用該掃描器，並結束掃描器選擇工具。

  • 若使用 fi-8950、fi-8930、fi-8820、fi-8040、fi-8190、fi-8290、fi-8170、fi-8270、fi-8150 或 fi-8250，按一下掃描器清單上的 [IP 位址] 中所顯示的 IP 位址，將會 (在網頁瀏覽器上) 啟動 fi Series 網路設定。

    關於 (網頁瀏覽器上的) fi Series 網路設定的詳細資訊，請參閱掃描器的操作指南。

  • 若已選擇掃描器並啟動掃描器選擇工具，或在下述任一狀態下在 [掃描器選擇工具] 視窗中按一下 [再次搜尋] 按鈕，所選掃描器將會新增 而非 。

    • 所選掃描器未連線至網路
    • 所選掃描器的電源已關閉

    • 已在 [搜尋掃描器的方法] 下的 [搜尋範圍] 中指定了不搜尋所選掃描器的值

      在此情形下，若所選掃描器連線至網路，您可就這樣使用該掃描器。

搜尋掃描器的方法
搜尋範圍
IPv4

將搜尋使用 IPv4 位址連線到與電腦相同子網路的掃描器。

這是出廠預設設定。

IPv6

將搜尋使用 IPv6 位址連線到與電腦相同子網路的掃描器。

若使用 fi-8950、fi-8930、fi-8820、fi-8040、fi-8190、fi-8290、fi-8170、fi-8270、fi-8150 或 fi-8250，您可選擇此項來搜尋掃描器。

輸入 IP 位址

選此項指定掃描器的 IP 位址來搜尋掃描器，或選此項來使用連線到與電腦不同子網路的掃描器。

在輸入欄位中輸入 IP 位址。

輸入名稱

選擇此項來指定已登錄於 DNS 伺服器上的掃描器名稱來搜尋掃描器。

提示

掃描器名稱必須為已登錄於 DNS 伺服器上的名稱。

以 255 個以內的字元在輸入欄位中輸入名稱。

可使用以下字元：

  • 英數字元

  • 「-」(連字號)

  • .(句號)

[再次搜尋] 按鈕

會開始搜尋掃描器。

找不到您要找的掃描器嗎？

會顯示說明。

[設定 IP 位址] 按鈕

啟動 IP 位址設定工具。

若找不到您要在電腦上使用的掃描器，按一下此項可檢查掃描器名稱或掃描器的 IP 位址。

若要使用 IP 位址設定工具，必須透過 USB 纜線將掃描器連線至電腦。

[確定] 按鈕

結束掃描器選擇工具。

變更已儲存。

[取消] 按鈕

結束掃描器選擇工具。

變更未儲存。
