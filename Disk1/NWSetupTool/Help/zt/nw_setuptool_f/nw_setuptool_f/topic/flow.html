操作流程

以下說明使用影像掃描應用程式掃描文件的操作流程。

  • 由影像掃描應用程式開始掃描

  • 由掃描器上的按鈕執行影像掃描應用程式來開始掃描

由影像掃描應用程式開始掃描

  • 若使用 fi-8040 或 fi-7300NX

    1. 在掃描器的觸控螢幕上指定網路設定

      關於詳細資料，請參閱掃描器的《操作指南》。

    2. 請將掃描器連線到網路

      提示

      若透過 Wi-Fi 連線至需要憑證的網路來使用 fi-7300NX，必須預先在掃描器上登錄憑證。關於詳細資訊，請參閱 在掃描器上登錄憑證。

    3. 啟動掃描器選擇工具來選擇要在電腦上使用的掃描器

      關於詳細資訊，請參閱 選擇要使用的掃描器 中的步驟 3 以及後續步驟。

    4. 在影像掃描應用程式中，選擇連線至有線區域網路或 Wi-Fi 的掃描器

      連線至有線區域網路或 Wi-Fi 的掃描器的名稱如下：

      • 若使用 PaperStream IP (TWAIN)/PaperStream IP (TWAIN x64)

        PaperStream IP xxx Net

      • 若使用 PaperStream IP (ISIS) fi-8000 Series/PaperStream IP (ISIS) Bundle

        PaperStream_IP xxx Net

      「xxx」代表掃描器機型名稱。關於詳細資訊，請參閱掃描器驅動程式的說明。

      提示

      僅限 fi-7300NX 可透過 Wi-Fi 連線來使用。

    5. 在掃描器中載入文件並由影像掃描應用程式掃描

      關於如何載入文件的詳細資料，請參閱您掃描器的《操作指南》。

      提示

      即使使用掃描器選擇工具選擇掃描器，掃描器可能不會出現在正在使用的影像掃描應用程式中。關於詳細資訊，請參閱 無法由影像掃描應用程式執行掃描。

  • 若使用 fi-8950、fi-8930、fi-8820、fi-8190、fi-8290、fi-8170、fi-8270、fi-8150 或 fi-8250

    1. 使用區域網路纜線，將掃描器連線至網路裝置 (如交換器、集線器或路由器)

      關於詳細資料，請參閱掃描器的《操作指南》。

      • 已自動指派 IP 位址時

        繼續到下一步。

      • 您手動指派 IP 位址時

        啟動 IP 位址設定工具來指派掃描器的 IP 位址。

        關於詳細資訊，請參閱 變更掃描器的 IP 位址。

    2. 啟動掃描器選擇工具來選擇要在電腦上使用的掃描器

      關於詳細資訊，請參閱 選擇要使用的掃描器 中的步驟 3 以及後續步驟。

    3. 在影像掃描應用程式中，選擇連線至有線區域網路的掃描器

      連線至有線區域網路的掃描器的名稱如下：

      • 若使用 PaperStream IP (TWAIN)/PaperStream IP (TWAIN x64)

        PaperStream IP xxx Net

      • 若使用 PaperStream IP (ISIS) fi-8000 Series

        PaperStream_IP xxx Net

      「xxx」代表掃描器機型名稱。關於詳細資訊，請參閱掃描器驅動程式的說明。

    4. 在掃描器中載入文件並由影像掃描應用程式掃描

      關於如何載入文件的詳細資料，請參閱您掃描器的《操作指南》。

      提示

      即使使用掃描器選擇工具選擇掃描器，掃描器可能不會出現在正在使用的影像掃描應用程式中。關於詳細資訊，請參閱 無法由影像掃描應用程式執行掃描。

由掃描器上的按鈕執行影像掃描應用程式來開始掃描

  • 若使用 fi-8040 或 fi-7300NX

    1. 在掃描器的觸控螢幕上指定網路設定

      關於詳細資料，請參閱掃描器的《操作指南》。

    2. 請將掃描器連線到網路

      提示

      若透過 Wi-Fi 連線至需要憑證的網路來使用 fi-7300NX，必須預先在掃描器上登錄憑證。關於詳細資訊，請參閱 在掃描器上登錄憑證。

    3. 啟動掃描器選擇工具來選擇要在電腦上使用的掃描器

      關於詳細資訊，請參閱 選擇要使用的掃描器 中的步驟 3 以及後續步驟。

    4. 啟動 Button Event Manager 並指定在按下掃描器上的按鈕時所啟動的影像掃描應用程式

      關於詳細資訊，請參閱 指定掃描器上的按鈕設定 中的步驟 3 以及後續步驟。

      注意事項

      若有超過一台電腦使用掃描器選擇工具來選擇同一台掃描器，請只在要搭配使用掃描器的該台電腦上，選擇 Button Event Manager 功能表上的 [監看按鈕事件]。

    5. 在掃描器中載入文件，並按下掃描器上的按鈕來掃描文件

      關於如何載入文件的詳細資料，請參閱您掃描器的《操作指南》。
