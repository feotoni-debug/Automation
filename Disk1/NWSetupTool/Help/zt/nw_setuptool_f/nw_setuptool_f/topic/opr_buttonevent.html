指定掃描器上的按鈕設定

本節說明如何使用 Button Event Manager 以及指定在按下掃描器上的按鈕時所啟動的影像掃描應用程式。

注意事項

若有超過一台電腦使用掃描器選擇工具來選擇同一台掃描器，請只在要搭配使用掃描器的該台電腦上，選擇 Button Event Manager 功能表上的 [監看按鈕事件]。

提示

若使用 Button Event Manager 指定掃描器按鈕的影像掃描應用程式，請參閱下述。

  • PaperStream ClickScan 執行中

    無論使用 Button Event Manager 為掃描按鈕指定何種設定，在按下掃描器上的掃描按鈕時，將會使用 PaperStream ClickScan 執行掃描。

    若要 (在按下掃描器上的掃描按鈕時) 啟動其他影像掃描應用程式，請結束 PaperStream ClickScan。關於詳細資訊，請參閱 PaperStream ClickScan 說明。

  • PaperStream ClickScan 非執行中但已安裝 PaperStream Capture 時

    掃描器上的掃描按鈕將自動設定為 PaperStream Capture。

    若不將掃描器上的掃描按鈕設定為 PaperStream Capture，請在 [按鈕設定] 視窗 的 [操作] 中選擇 [無] 或 [執行以下程式]。

  1. 請將掃描器連線到網路。

    關於詳細資料，請參閱掃描器的《操作指南》。

  2. 啟用可在影像掃描應用程式中選擇的掃描器。

    啟動掃描器選擇工具，並由連線到網路的掃描器中選擇要使用的掃描器。

    關於詳細資訊，請參閱 選擇要使用的掃描器。

  3. 指定影像掃描應用程式中的掃描設定。

    關於詳細資訊，請參閱該影像掃描應用程式的使用手冊。

  4. 啟動 Button Event Manager。

    關於詳細資訊，請參閱 啟動 Button Event Manager。

    Button Event Manager 啟動時， 將顯示於位於工作列右端的通知區域中。

  5. 在 上按右鍵。

    會出現 Button Event Manager 功能表。

  6. 在功能表上選擇 [監看按鈕事件]。
  7. 在功能表上按一下 [指定按鈕的設定]。

    會出現 [按鈕設定] 視窗。

  8. 指定在按下掃描器上的按鈕時所啟動的影像掃描應用程式。

    關於設定的詳細資料，請參閱 [按鈕設定] 視窗。

  9. 按一下 [確定] 按鈕。
