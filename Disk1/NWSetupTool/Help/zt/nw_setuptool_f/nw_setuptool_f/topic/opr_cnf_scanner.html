選擇要使用的掃描器

本節說明如何使用掃描器選擇工具以便由電腦中選擇要使用的掃描器。
  1. 請將掃描器連線到網路。

    關於詳細資料，請參閱掃描器的《操作指南》。

  2. 啟動掃描器選擇工具。

    關於詳細資訊，請參閱 啟動掃描器選擇工具。

    會出現 [掃描器選擇工具] 視窗。

    提示

    啟動掃描器選擇工具時，該工具將自動在 [搜尋掃描器的方法] 所設定的搜尋範圍內搜尋掃描器。

  3. 由掃描器清單中，選擇要在電腦上使用的掃描器。

    已選掃描器旁將顯示打勾標記。

    提示

    若您要用的掃描器未顯示在掃描器清單上，請依照以下程序搜尋掃描器。

    • 掃描器連線到與電腦相同的子網路時

      在 [搜尋掃描器的方法] 下的 [搜尋範圍] 中，選擇 [IPv4] 或 [IPv6]，並按下 [再次搜尋] 按鈕

    • 掃描器連線到與電腦不同的子網路時

      在 [搜尋掃描器的方法] 下的 [搜尋範圍] 中，選擇 [輸入 IP 位址] 或 [輸入名稱]，並輸入 IP 位址或名稱，然後按一下 [再次搜尋] 按鈕

  4. 按一下 [確定] 按鈕。
提示

  • 您也可在掃描器清單中按兩下掃描器來選擇該掃描器。

    按兩下掃描器可讓電腦使用該掃描器，並結束掃描器選擇工具。

  • 若在 [搜尋掃描器的方法] 下的 [搜尋範圍] 中指定 [輸入 IP 位址] 或 [輸入名稱]，請確認在輸入欄位中輸入 IP 位址或名稱，然後按一下 [確定] 按鈕。
