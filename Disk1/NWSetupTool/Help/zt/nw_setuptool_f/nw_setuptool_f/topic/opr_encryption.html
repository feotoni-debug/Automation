加密網路通訊

本節說明如何使用 IP 位址設定工具來加密網路上的通訊。
  1. 用掃描器隨附的 USB 纜線將掃描器連接到電腦。
  2. 開啟掃描器電源。

    關於詳細資料，請參閱掃描器的《操作指南》。

  3. 啟動 IP 位址設定工具。

    關於詳細資訊，請參閱 啟動 IP 位址設定工具。

    出現 IP 位址設定工具的登入視窗。

    若掃描器未設定管理員密碼，會出現 [IP 位址設定工具] 視窗。繼續到步驟 5。

  4. 輸入掃描器的管理員密碼，並按一下 [登入] 按鈕。

    關於出廠預設管理員密碼的詳細資料，請參閱掃描器的《操作指南》。

    會出現 [IP 位址設定工具] 視窗。

  5. 在 [安全性] 中，將 [網路加密] 選為 [加密 (HTTPS)]。
  6. 按一下 [確定] 按鈕。
