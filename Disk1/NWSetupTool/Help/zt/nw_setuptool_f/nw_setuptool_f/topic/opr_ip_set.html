變更掃描器的 IP 位址

本節說明如何使用 IP 位址設定工具來變更掃描器的 IP 位址。

IP 位址顯示於 [掃描器選擇工具] 視窗的掃描器清單中。

出廠預設值會自動將 IPv4 位址或 IPv6 位址指派至掃描器。

例如，在以下情形使用 IP 位址設定工具以變更掃描器的 IP 位址。

  • 在掃描器選擇工具中找不到掃描器時

  • 將掃描器連線到不使用 DHCP 伺服器的網路時

  • 要為掃描器設定固定 IP 位址時

  1. 用掃描器隨附的 USB 纜線將掃描器連接到電腦。
  2. 開啟掃描器電源。

    關於詳細資料，請參閱掃描器的《操作指南》。

  3. 啟動 IP 位址設定工具。

    關於詳細資訊，請參閱 啟動 IP 位址設定工具。

    出現 IP 位址設定工具的登入視窗。

    若掃描器未設定管理員密碼，會出現 [IP 位址設定工具] 視窗。繼續到步驟 5。

  4. 輸入掃描器的管理員密碼，並按一下 [登入] 按鈕。

    關於出廠預設管理員密碼的詳細資料，請參閱掃描器的《操作指南》。

    會出現 [IP 位址設定工具] 視窗。

  5. 選擇設定 IP 位址的方式。

    • IPv4 位址

      在 [網路] 下的 [IPv4 設定] 中，選擇設定掃描器 IP 位址的方式。

      • 選擇 [自動] 時

        前進至步驟 6。

      • 選擇 [手動] 時

        在 [IP 位址]、[子網路遮罩] 及 [預設閘道] 中輸入適當的數字。

    • IPv6 位址

      1. 在 [網路] 下的 [IPv6] 中，按一下 [IPv6 設定] 按鈕。

      2. 在 [IPv6 設定] 視窗 的 [IPv6 設定] 中，選擇設定掃描器 IP 位址的方式。

        • 選擇 [自動] 或 [不啟用] 時

          按一下 [確定] 按鈕，並前進至步驟 6。

        • 選擇 [手動] 時

          在 [IP 位址]、[子網路首碼長度] 及 [預設閘道] 中輸入適當的數字。

      3. 按一下 [確定] 按鈕。

  6. 按一下 [確定] 按鈕。
  7. 從掃描器拔下 USB 纜線。
