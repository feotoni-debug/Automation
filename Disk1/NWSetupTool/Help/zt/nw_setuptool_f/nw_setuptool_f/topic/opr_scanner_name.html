變更掃描器名稱

本節說明如何使用 IP 位址設定工具來變更掃描器名稱。

掃描器名稱顯示於 [掃描器選擇工具] 視窗的掃描器清單中。

掃描器名稱的出廠預設值為掃描器的機型名稱及序號 (機型名稱 - 序號)。

掃描器的序號印在產品標籤上。

關於詳細資料，請參閱掃描器的《操作指南》。

  1. 用掃描器隨附的 USB 纜線將掃描器連接到電腦。
  2. 開啟掃描器電源。

    關於詳細資料，請參閱掃描器的《操作指南》。

  3. 啟動 IP 位址設定工具。

    關於詳細資訊，請參閱 啟動 IP 位址設定工具。

    出現 IP 位址設定工具的登入視窗。

    若掃描器未設定管理員密碼，會出現 [IP 位址設定工具] 視窗。繼續到步驟 5。

  4. 輸入掃描器的管理員密碼，並按一下 [登入] 按鈕。

    關於出廠預設管理員密碼的詳細資料，請參閱掃描器的《操作指南》。

    會出現 [IP 位址設定工具] 視窗。

  5. 在 [掃描器名稱] 中輸入適當的字元。

    可用字元為英數字元、「-」(連字號)、「_」(底線) 及空格。

    最多可設定 64 個字元。

    提示

    如果您啟用掃描器設定中的 [動態 DNS]，請輸入掃描器名稱，長度不超過 63 個字元。

    關於動態 DNS 的詳細資料，請參閱您掃描器的《操作指南》。

    建議您在 DNS 伺服器上登錄掃描器名稱時，不要使用下列半形字元，因為這些字元將會轉換為「-」(連字號)。

    • 「_」(底線)

    • 空格

  6. 按一下 [確定] 按鈕。
  7. 從掃描器拔下 USB 纜線。
