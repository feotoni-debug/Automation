IP 位址設定工具

本節說明在您使用 IP 位址設定工具時可能會顯示的錯誤訊息，以及如何解決錯誤的方法。
  • 請使用 USB 纜線將掃描器連線至電腦。
  • 請僅連線一台掃描器。
  • 發生通訊錯誤。
  • 掃描器名稱含有不支援的字元。
  • 無法指定保留位址作為 IP 位址。
  • 無法指定保留位址作為子網路遮罩。
  • IP 位址或子網路遮罩無效。
  • IP 位址的格式不正確。
  • 子網路首碼長度的格式不正確。
  • 無法指定保留位址作為預設閘道。
  • 預設閘道的格式不正確。
  • 預設閘道或子網路遮罩無效。
  • 未指定掃描器名。
  • 其他使用者或應用程式正在使用本台掃描器。
  • 無法啟動程式。
  • 登入失敗。
  • 找不到說明檔案。
