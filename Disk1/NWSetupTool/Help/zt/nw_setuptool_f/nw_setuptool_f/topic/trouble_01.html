找不到掃描器

檢查以下事項：

  • (用於連線掃描器的) 連線方式是否與掃描器設定中的設定不同？(fi-7300NX)

  • 是否已正確指定掃描器的網路設定？

  • 掃描器是否正在啟動中或初始化期間？

  • 其他應用程式是否正在使用掃描器？

  • 是否已正確指定電腦的網路設定？

  • 電腦是否正在更新作業系統或等待重新啟動？

  • 掃描器是否連線到與電腦相同子網路？

  • 網路裝置 (如交換器、集線器或路由器) 的設定是否正確？

  • 掃描器和電腦之間的通訊狀態是否穩定？

若採取以上措施後仍舊找不到掃描器，請重新啟動掃描器和電腦，然後重新啟動掃描器選擇工具。

掃描器若未顯示於影像掃描應用程式中，請參閱 無法由影像掃描應用程式執行掃描。

(用於連線掃描器的) 連線方式是否與掃描器設定中的設定不同？(fi-7300NX)

解決方案

檢查掃描器的連線方式已設定為 Wi-Fi 或有線區域網路。

您可如下進行檢查。

在掃描器觸控螢幕上，按下 → [掃描器設定] → [如何連線]。

是否已正確指定掃描器的網路設定？

解決方案

  • 若使用 fi-8040 或 fi-7300NX

    檢查掃描器的網路設定。

    您可如下進行檢查。

    在掃描器觸控螢幕上，按下 → [掃描器設定] → [網路]。

  • 若使用 fi-8950、fi-8930、fi-8820、fi-8190、fi-8290、fi-8170、fi-8270、fi-8150 或 fi-8250

    使用 IP 位址設定工具來檢查掃描器的網路設定。

    關於如何啟動 IP 位址設定工具的詳細資訊，請參閱 啟動 IP 位址設定工具。

掃描器是否正在啟動中或初始化期間？

解決方案

確認掃描器並非啟動中或初始化期間。

關於詳細資料，請參閱掃描器的《操作指南》。

其他應用程式是否正在使用掃描器？

解決方案

結束其他正在使用掃描器的應用程式。

是否已正確指定電腦的網路設定？

解決方案

檢查電腦的網路設定。

關於如何指定電腦的網路設定的詳細資訊，請參閱電腦的使用手冊。

電腦是否正在更新作業系統或等待重新啟動？

解決方案

待電腦更新作業系統或電腦重新啟動後，請重新啟動掃描器選擇工具。

掃描器是否連線到與電腦相同子網路？

即使掃描器連線到與電腦相同子網路，仍有可能找不到該掃描器。

解決方案

在 [掃描器選擇工具] 視窗 中選擇 [由掃描器的 IP 位址搜尋]，並輸入 IP 位址來搜尋掃描器。

網路裝置 (如交換器、集線器或路由器) 的設定是否正確？

解決方案

檢查網路裝置 (如交換器、集線器或路由器) 的設定。

關於如何設定網路裝置的詳細資訊，請參閱網路裝置的使用手冊。

掃描器和電腦之間的通訊狀態是否穩定？

解決方案

  • 若使用 fi-8040 或 fi-7300NX

    檢查掃描器和電腦之間的通訊狀態。

    您可在掃描器觸控螢幕上，檢查掃描器和電腦之間的通訊狀態。

    您可如下進行檢查。

    在掃描器觸控螢幕上，按下 → [掃描器設定] → [網路] → [檢查連線 (Ping)]。

  • 若使用 fi-8950、fi-8930、fi-8820、fi-8190、fi-8290、fi-8170、fi-8270、fi-8150 或 fi-8250

    檢查掃描器和電腦之間的通訊狀態。

    在電腦上啟動命令提示字元，並指定掃描器的 IP 位址以執行 PING 命令來檢查通訊狀態。

    使用 IP 位址設定工具來檢查掃描器的 IP 位址。

    關於如何啟動 IP 位址設定工具的詳細資訊，請參閱 啟動 IP 位址設定工具。
