按下掃描器上的按鈕無法執行掃描

檢查以下事項：

  • 是否已在掃描器選擇工具中選擇掃描器？

  • 是否已啟動 Button Event Manager？

  • 是否已在 Button Event Manager 功能表上選擇 [監看按鈕事件]？

  • 掃描器上的按鈕設定是否正確？

  • 是否有其他電腦正在使用掃描器？

是否已在掃描器選擇工具中選擇掃描器？

解決方案

在 [掃描器選擇工具] 視窗 檢查已選擇掃描器。

是否已啟動 Button Event Manager？

解決方案

檢查已啟動 Button Event Manager。

Button Event Manager 啟動時， 將顯示於位於工作列右端的通知區域中。

關於如何啟動 Button Event Manager 的詳細資訊，請參閱 啟動 Button Event Manager。

是否已在 Button Event Manager 功能表上選擇 [監看按鈕事件]？

解決方案

啟動 Button Event Manager 並在工作列右端的通知區域中的 上按一下滑鼠右鍵，以顯示 Button Event Manager 功能表。檢查已選擇 [監看按鈕事件]。

關於如何啟動 Button Event Manager 的詳細資訊，請參閱 啟動 Button Event Manager。

掃描器上的按鈕設定是否正確？

解決方案

  • 在 Button Event Manager 的 [按鈕設定] 視窗 中，檢查按鈕設定正確。

  • 檢查您為掃描器上的按鈕所指定的影像掃描應用程式是否有在電腦上執行。

是否有其他電腦正在使用掃描器？

解決方案

若有超過一台電腦使用掃描器選擇工具來選擇同一台掃描器，請只在要搭配使用掃描器的該台電腦上，選擇 Button Event Manager 功能表上的 [監看按鈕事件]。

若採取以上措施後仍無法啟動掃描，請執行以下作業：

  • 結束常駐於工作列右端的通知區域中的影像掃描應用程式

  • 關閉掃描器的電源再將其重新開啟
