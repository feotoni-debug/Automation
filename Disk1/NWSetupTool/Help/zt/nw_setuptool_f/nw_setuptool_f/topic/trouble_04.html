WinHTTP 的 Proxy 設定是否已設定 Proxy 伺服器？

解決方案

變更 WinHTTP 的 Proxy 設定以便由電腦存取掃描器。

按照以下程序變更 WinHTTP 的 Proxy 設定。

  1. 以具有該電腦管理員權限的身分，啟動命令提示字元視窗。

  2. 執行以下命令，以檢查 Proxy 伺服器名稱以及將使用的連接埠號碼。

    netsh winhttp show proxy

    提示

    Proxy 伺服器名稱以及將使用的連接埠號碼會顯示如下。

    "Proxy 伺服器名稱：連接埠號碼"

  3. 執行以下其中一個命令。

    • 已設定 Proxy 伺服器時

      將設定指定為不使用 Proxy 伺服器即可由電腦存取掃描器。

      netsh winhttp set proxy proxy-server="XXXXXX:YYYY" bypass-list=ZZZ.ZZZ.ZZZ.ZZZ

      XXXXXX：Proxy 伺服器名稱

      YYYY：將使用的連接埠號碼

      ZZZ.ZZZ.ZZZ.ZZZ：掃描器的 IP 位址 (*1)(*2)

    • 未設定 Proxy 伺服器時

      若重設設定，電腦或許就可存取掃描器。

      netsh winhttp reset proxy
*1：

您可在掃描器的觸控螢幕或操作面板上，或在 IP 位址設定工具中檢查掃描器的 IP 位址。
*2：

此處以 IPv4 位址的格式為範例。

若為 IPv6 位址，將會使用以下格式。

ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ:ZZZZ
