  • 錯誤訊息
    • 掃描器選擇工具
      • 無法修改設定檔。
      • 由於發生未預期的錯誤而無法處理。
      • IP 位址無效。輸入正確的 IP 位址。
      • 無法載入設定檔。
      • 無法啟動程式。
      • 找不到說明檔案。
      • 名稱不正確。請輸入正確的名稱。
    • IP 位址設定工具
      • 請使用 USB 纜線將掃描器連線至電腦。
      • 請僅連線一台掃描器。
      • 發生通訊錯誤。
      • 掃描器名稱含有不支援的字元。
      • 無法指定保留位址作為 IP 位址。
      • 無法指定保留位址作為子網路遮罩。
      • IP 位址或子網路遮罩無效。
      • IP 位址的格式不正確。
      • 子網路首碼長度的格式不正確。
      • 無法指定保留位址作為預設閘道。
      • 預設閘道的格式不正確。
      • 預設閘道或子網路遮罩無效。
      • 未指定掃描器名。
      • 其他使用者或應用程式正在使用本台掃描器。
      • 無法啟動程式。
      • 登入失敗。
      • 找不到說明檔案。
    • 憑證登錄工具
      • 無法連線至掃描器。
      • 無法取得憑證資訊。
      • 無法移除憑證。
      • 無法登錄憑證。
      • 密碼不正確。
    • Button Event Manager
      • 由於發生未預期的錯誤而無法處理。
      • 找不到說明檔案。
  • 疑難排解

    • 按下掃描器上的按鈕無法執行掃描
